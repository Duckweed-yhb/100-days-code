# Day 54 · 栈与堆

## 今日目标
- 搞清楚栈（stack）与托管堆（heap）分别放什么
- 理解方法调用时栈帧的变化
- 知道为什么值类型快、引用类型要 GC

## 学习内容

### 栈：后进先出

栈存：

- 方法的参数、局部变量（值类型）
- 引用类型变量本身（这个 8 字节引用）

方法一调用就压栈帧，方法返回就弹出，**自动、极快、不用 GC**。

```csharp
void A()
{
    int x = 10;          // x 在栈上
    B();
}
void B()
{
    string s = "hi";     // s 引用在栈上，"hi" 对象在堆上
}
```

### 托管堆：对象住这里

`new` 出来的对象在堆上：

```csharp
Student s = new Student { Name = "A" };
//       └──────────────┘
//        这个对象在堆上
// s 这个变量本身在栈上，存着堆上对象的地址
```

堆上的对象由 GC 自动回收。

### 栈 vs 堆

| 对比 | 栈 | 堆 |
|---|---|---|
| 分配速度 | 极快（挪指针） | 较慢 |
| 回收 | 方法返回自动弹 | GC 定期回收 |
| 大小 | 小（几 MB） | 大（GB） |
| 适合 | 小、短生命周期的值 | 大、长生命周期的对象 |

### 装箱与拆箱

值类型转成引用类型叫**装箱**，有性能开销：

```csharp
int x = 42;
object boxed = x;          // 装箱：在堆上包一个对象
int back = (int)boxed;      // 拆箱
```

避免在热路径里反复装箱（比如用 `ArrayList` 装 int）。用 `List<int>`（泛型）就不装箱。

## 核心重点
- 栈存局部值与引用本身；方法返回自动回收
- 堆存 new 出来的对象；GC 管
- 引用变量在栈，对象在堆
- 装箱拆箱有开销，用泛型避免
- 理解内存模型才能写高性能代码
