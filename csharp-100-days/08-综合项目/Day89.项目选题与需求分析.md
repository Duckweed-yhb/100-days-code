## 学习内容

### 推荐项目：个人记账 Web API

理由：足够小但五脏俱全——有实体、有 CRUD、有统计、有用户维度、有 Web 接口、能测试。

### 功能需求

1. **用户**：注册、登录（今天先简化，固定一个用户）；
2. **账目**：一笔支出/收入，字段：金额、类别、备注、日期；
3. **分类**：餐饮、交通、娱乐、工资……
4. **查询**：按月、按类别、按日期范围查账；
5. **统计**：月支出总额、分类占比、环比。

### 非功能需求

- SQLite 存储，免装数据库；
- 异步 API，支持 CancellationToken；
- 结构化日志；
- 关键服务有单元测试；
- 配置走 appsettings.json。

### 项目结构（预告）

```
Budget/
  Budget.Api/          Web 项目
  Budget.Core/         实体与接口
  Budget.Infrastructure/ EF Core
  Budget.Tests/        测试
```

今天先不写代码，把需求想清楚。

### 用什么衡量完成

- 能用 Swagger 加一笔账；
- 能按月查询并统计；
- 测试全绿；
- dotnet publish 能跑。

## 核心重点
- 项目要小而完整，别贪大
- 先写需求再写代码
- 实体、接口、统计三个模块
- 12 天每天做一点
- 完成比完美重要
