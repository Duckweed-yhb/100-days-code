# C# - 100天从新手到大师

> 这是一套从零开始、自编原创的 C# 学习路线，基于 .NET 8 与 C# 12 稳定特性，按"语法基础 → 面向对象 → 集合与 LINQ → 委托事件异步 → .NET 平台与内存 → 数据访问与 Web → 并发与工程化 → 综合项目"八阶段递进。建议工作日每天投入 1~1.5 小时，周末用于复盘本周内容并动手做小项目，100 天后具备独立开发后端服务与桌面/控制台应用的能力。

## 阶段总览

| 阶段 | 天数 | 主题 |
|---|---|---|
| 01-C#基础 | Day01~13 | .NET与C#介绍、环境、变量与类型、运算符、流程控制、方法、数组、字符串、控制台程序 |
| 02-面向对象 | Day14~25 | 类与对象、构造、属性、封装、继承、多态、接口、抽象类、static |

| 06-数据访问与Web开发 | Day64~75 | ADO.NET、EF Core、LINQ to Entities、ASP.NET Core基础、Web API、依赖注入 |

## 怎么用

1. **按顺序学**：每天一个文件，不要跳。前面是后面的地基，尤其是面向对象与异步。
2. **手敲代码**：每个 ```` ```csharp ```` 代码块都自己敲一遍并跑通，不要复制粘贴。
3. **做完练习再打卡**：每篇末尾的"练习/任务"必须动手完成，再勾"打卡清单"。
4. **周末复盘**：每阶段最后一天是练习/项目日，用来把本周知识点串起来；周日回头看本周打卡。
5. **刷题**：从 Day25 开始每天配一道 LeetCode/经典算法题（用 C# 解），巩固语言熟练度。

## 目录约定

- 根目录下按阶段分 8 个文件夹，命名形如 `01-C#基础`、`02-面向对象`，两位序号 + 中文主题。
- 每个阶段文件夹内放该阶段的 Day 文件，命名形如 `Day01.认识C#与.NET环境安装.md`，即 `Day` + 两位数字 + 中文句号 `.` + 当天主题短句。
- Day 编号从 01 连续到 100，跨文件夹累计，不重复、不断号。
- 每个 Day 文件统一包含：今日目标、学习内容、核心重点、练习/任务、（Day25 起）今日刷题、打卡清单。

## 为什么学 C#

C# 由微软于 2000 年发布，如今随 .NET 统一平台跨 Windows、Linux、macOS 运行。它是一门**静态类型、类型安全、面向对象**的现代语言，同时吸收了函数式、异步编程等特性：

| 领域 | 典型应用 |
|---|---|
| 后端 Web | ASP.NET Core，高性能 Web API 与微服务 |
| 桌面客户端 | WPF、WinForms、MAUI 跨端应用 |
| 游戏开发 | Unity 引擎事实上的脚本语言 |
| 云原生 | Azure 一等公民，容器与云服务生态完整 |
| 移动/跨平台 | .NET MAUI 一套代码出 Android/iOS/桌面 |

语法优雅、工具链成熟（Visual Studio / VS Code + dotnet CLI）、就业面广，是性价比极高的第二门主力语言。
