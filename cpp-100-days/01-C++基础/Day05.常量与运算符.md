## 学习内容

### 用 const 定义常量

不想让值被修改，就在类型前加 `const`：

```cpp
const double PI = 3.14159265;
// PI = 3.0;   // 编译报错：不能给 const 赋值
```

习惯：**所有"固定不变"的量都加 const**，既防手滑改错，也让读代码的人一眼知道这是常量。

C++ 里还可以用 `#define PI 3.14` 定义宏常量，但现代 C++ 更推荐 `const`，因为它有类型、在调试器里可见。

### 算术运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `+` `-` `*` `/` | 加减乘除 | `7 / 2 == 3`（整数除法截断） |
| `%` | 取余 | `7 % 2 == 1` |
| `++` `--` | 自增自减 | `i++` 先用后加，`++i` 先加后用 |

注意整数除法：`7 / 2` 在 C++ 里是 `3`，不是 `3.5`。要得到小数，至少有一个操作数是浮点：`7.0 / 2`。

### 关系与逻辑运算符

```cpp
int a = 3, b = 5;
bool r1 = (a < b);        // true
bool r2 = (a == b);       // false，注意是 == 不是 =
bool r3 = (a < b) && (b > 0);   // 逻辑与
bool r4 = (a > b) || (b < 0);   // 逻辑或
bool r5 = !(a == b);             // 逻辑非
```

新手第一大坑：把判断相等的 `==` 写成赋值 `=`。编译器有时不会报错，但是逻辑全错。

### 位运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `&` | 按位与 | 清某位 |
| `\|` | 按位或 | 置某位 |
| `^` | 按位异或 | 翻转某位 |
| `~` | 按位取反 | |
| `<<` `>>` | 左移/右移 | `1 << 3 == 8` |

位运算在底层、竞赛、嵌入式里非常常用。例如判断奇偶：`(n & 1) == 0` 是偶数。

### 赋值与复合赋值

```cpp
int x = 10;
x += 5;     // x = 15
x *= 2;     // x = 30
x %= 7;     // x = 2
```

### 类型转换

隐式转换会自动发生（小类型→大类型）：

```cpp
int i = 3;
double d = i;       // 自动变成 3.0
```

显式转换（C++ 风格）：

```cpp
double pi = 3.14;
int n = static_cast<int>(pi);   // n = 3
```

现代 C++ 推荐用 `static_cast<T>(...)` 而不是 C 风格的 `(T)...`，因为它更显眼、编译器检查更严。

## 核心重点
- `const T x = ...` 定义只读常量，推荐给所有不变量加上
- 整数除法会截断，要小数就用浮点
- 相等判断用 `==`，不要写成 `=`
- 位运算 `& | ^ ~ << >>` 底层常用
- 显式转换用 `static_cast<T>(...)`
