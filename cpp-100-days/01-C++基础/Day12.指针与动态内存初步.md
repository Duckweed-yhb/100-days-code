# Day 12 · 指针与动态内存初步

## 今日目标
- 理解指针的本质：保存地址的变量
- 学会 `new` / `delete` 在堆上申请与释放内存
- 认识内存泄漏与悬空指针两个大坑

## 学习内容

### 指针是什么

指针变量保存的是**另一个变量的内存地址**：

```cpp
int x = 42;
int* p = &x;       // p 保存 x 的地址
std::cout << p;    // 输出一个地址，如 0x61fe14
std::cout << *p;   // 解引用：输出 42
```

- `&x`：取 x 的地址；
- `*p`：取 p 指向的那个变量。

### nullptr

空指针表示"现在不指向任何东西"：

```cpp
int* p = nullptr;
// *p = 10;    // 运行崩溃：不能解引用空指针
```

C++11 起用 `nullptr` 代替 C 时代的 `NULL`，类型更安全。

### 栈与堆

程序内存分几块：

| 区域 | 存放 | 生命周期 |
|---|---|---|
| 栈 stack | 局部变量、函数参数 | 出作用域自动回收 |
| 堆 heap | `new` 出来的对象 | 直到 `delete` 才释放 |
| 全局/静态区 | 全局变量、static 变量 | 整个程序运行期间 |

普通局部变量在栈上，自动回收；想在函数退出后还活着，或者大小运行时才知道，就要用堆。

### new 与 delete

```cpp
int* p = new int(42);    // 在堆上申请一个 int，值为 42
// ... 使用 *p
delete p;                // 释放
p = nullptr;             // 好习惯：避免悬空
```

申请数组：

```cpp
int* arr = new int[100];     // 申请 100 个 int
// ...
delete[] arr;                // 注意是 delete[]，不是 delete
```

### 两个大坑

1. **内存泄漏**：`new` 了却不 `delete`，程序跑得越久占内存越多。
2. **悬空指针**：`delete p` 之后还继续用 `*p`，行为未定义。

```cpp
int* p = new int(1);
delete p;
*p = 100;     // 错！p 已经悬空
```

现代 C++ 用智能指针（Day52）自动管理内存，从根本上避免这两个坑。今天先理解原理。

### 指针与数组回顾

```cpp
int* arr = new int[5]{1, 2, 3, 4, 5};
for (int i = 0; i < 5; ++i) std::cout << arr[i];
delete[] arr;
```

`new[]` 出来的数组必须用 `delete[]` 释放，配对不能错。

## 核心重点
- 指针保存地址，`&` 取地址，`*` 解引用
- `nullptr` 表示空指针
- 栈变量自动回收，堆变量要 `new` / `delete` 配对
- `new T[]` 必须配 `delete[]`
- 内存泄漏与悬空指针是两大坑，以后用智能指针解决
