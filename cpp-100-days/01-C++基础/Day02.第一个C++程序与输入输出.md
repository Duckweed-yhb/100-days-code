## 学习内容

### cout 输出的多种用法

`std::cout` 配合 `<<` 可以连续输出任意类型的数据：

```cpp
#include <iostream>

int main() {
    int age = 20;
    double height = 1.75;
    std::cout << "年龄：" << age << " 岁，身高：" << height << " 米\n";
    return 0;
}
```

几点说明：

- `<<` 可以一个接一个串起来，像流水线一样把内容送进输出流；
- 字符串用双引号 `"..."`，单个字符用单引号 `'...'`；
- `\n` 是换行符，写在字符串里即可。

### endl 与 '\n' 的区别

两者都能换行，但有细微差别：

| 写法 | 作用 |
|---|---|
| `std::endl` | 换行 **并刷新** 输出缓冲区 |
| `'\n'` | 只换行，不主动刷新 |

频繁输出大量内容时，`endl` 会因为反复刷新而变慢，工程代码里更常用 `'\n'`。初学阶段两者都能跑通。

### cin 读取输入

`std::cin` 配合 `>>` 从键盘读取数据：

```cpp
#include <iostream>

int main() {
    int a, b;
    std::cout << "请输入两个整数，用空格隔开：";
    std::cin >> a >> b;                  // 连续读两个数
    std::cout << a << " + " << b << " = " << a + b << '\n';
    return 0;
}
```

注意：`>>` 会自动跳过空格、Tab、换行，所以用户输入 `3 5`、`3\n5` 都能正确读到 `a=3, b=5`。

### 一个完整的小程序：摄氏转华氏

```cpp
#include <iostream>

int main() {
    double celsius;
    std::cout << "请输入摄氏温度：";
    std::cin >> celsius;
    double fahrenheit = celsius * 9.0 / 5.0 + 32.0;
    std::cout << celsius << "℃ = " << fahrenheit << "℉\n";
    return 0;
}
```

输入 `37`，应输出约 `98.6`。

### 注释

C++ 支持两种注释：

- 单行注释：`// 这是注释`
- 多行注释：`/* 这一段都是注释 */`

写代码时多用注释解释"为什么这么做"，而不是"这行在做什么"。

## 核心重点
- `std::cout << ...` 输出，`std::cin >> ...` 输入，`<<` 和 `>>` 都能连续串接
- `std::endl` 会刷新缓冲区，`'\n'` 只换行；高性能输出优先用 `'\n'`
- `cin >>` 自动跳过空白符
- 字符串用双引号，字符用单引号
- 注释分 `//` 与 `/* */` 两种
