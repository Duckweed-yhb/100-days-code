## 学习内容

### 常用基本类型

| 类型 | 含义 | 典型大小（以实现为准） | 示例 |
|---|---|---|---|
| `int` | 整数 | 4 字节 | `int a = 10;` |
| `short` | 短整数 | 2 字节 | `short s = 3;` |
| `long` | 长整数 | 至少 4 字节 | `long l = 100000L;` |
| `long long` | 更长整数 | 至少 8 字节 | `long long ll = 1LL << 60;` |
| `float` | 单精度浮点 | 4 字节 | `float f = 1.5f;` |
| `double` | 双精度浮点 | 8 字节 | `double d = 3.14;` |
| `char` | 单个字符 | 1 字节 | `char c = 'A';` |
| `bool` | 布尔 | 通常 1 字节 | `bool ok = true;` |

注意：C++ 标准只规定"至少多大"，具体字节数可以用 `sizeof` 查看。

```cpp
#include <iostream>
int main() {
    std::cout << "int 占 " << sizeof(int) << " 字节\n";
    std::cout << "double 占 " << sizeof(double) << " 字节\n";
}
```

### 变量的声明与初始化

C++ 提倡"定义时就给初值"：

```cpp
int a;            // 未初始化，值不确定（局部变量是垃圾值）
int b = 5;        // 拷贝初始化
int c(10);        // 直接初始化
int d{20};        // 列表初始化（C++11 起，最推荐）
double e = 3.14;
```

列表初始化 `{...}` 有个好处：**不允许窄化转换**，例如 `int x{3.14};` 会编译报错，而 `int x = 3.14;` 会悄悄丢掉小数。这是 C++ 里防 bug 的常用手段。

###  signed 与 unsigned

整型默认带符号（`signed`），可以加 `unsigned` 表示只存非负数：

```cpp
unsigned int n = 100;     // 只能 >= 0
```

新手常见坑：把有符号数和无符号数比较，结果会出乎意料。初学阶段除非明确知道要"只用非负"，否则老老实实用 `int`。

### 字面量后缀

- `10` 是 `int`；
- `10L` 是 `long`；
- `10LL` 是 `long long`；
- `3.14` 是 `double`；
- `3.14f` 是 `float`；
- `'A'` 是 `char`；
- `true` / `false` 是 `bool`。

### auto 类型推导（先认识一下）

C++11 起可以让编译器自动推导类型：

```cpp
auto x = 10;        // x 是 int
auto y = 3.14;      // y 是 double
auto s = 1.5f;      // s 是 float
```

今天先会用即可，Day56 会专门讲。

## 核心重点
- 常用类型：int / long long / double / char / bool
- 变量尽量在定义时初始化，推荐用 `T x{...}` 列表初始化
- `sizeof(T)` 查看类型字节数
- 不要随便用 `unsigned`，有符号无符号比较是经典坑
- `auto` 让编译器自动推导类型
