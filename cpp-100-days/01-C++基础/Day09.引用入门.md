# Day 09 · 引用入门

## 今日目标
- 理解引用是什么、和指针有什么区别
- 会用引用作函数参数，替代指针
- 理解常量引用 `const T&` 的价值

## 学习内容

### 引用就是"别名"

引用（reference）变量是另一个变量的**别名**：对引用操作就是对原变量操作。

```cpp
#include <iostream>

int main() {
    int a = 10;
    int& ra = a;     // ra 是 a 的别名
    ra = 20;         // 等于 a = 20
    std::cout << a;  // 20
}
```

要点：

- 引用在定义时**必须初始化**：`int& ra;` 是错的；
- 一旦绑定到某个变量，就不能再改绑到别的变量。

### 引用 vs 指针

| 对比 | 引用 | 指针 |
|---|---|---|
| 必须初始化 | 是 | 否 |
| 能否为空 | 不能 | 能（nullptr） |
| 能否改绑 | 不能 | 能 |
| 语法 | `ra` 直接用 | `*p` 解引用 |

引用更安全、更简洁，能用引用就别用指针。

### 引用作函数参数

用引用代替指针做"在函数里改外面变量"的事：

```cpp
void swap(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 3, y = 5;
    swap(x, y);        // 直接传变量，不需要 &
    // x == 5, y == 3
}
```

对比 Day07 用指针版本：调用处不用写 `&x`，函数内不用写 `*a`，清爽很多。

### 常量引用 const T&

传递大对象时，值拷贝很贵。用 `const T&` 既能避免拷贝，又能保证不被修改：

```cpp
#include <string>

// 传 string 常量引用：不拷贝、不可改
void printLength(const std::string& s) {
    std::cout << s.size() << '\n';
    // s = "xxx";   // 错：const 引用不能改
}
```

经验法则：

- 小对象（int、double 等）：直接传值；
- 大对象（string、容器、自定义类）：传 `const T&`。

### 引用作返回值

函数可以返回引用，常用于"链式调用"：

```cpp
int& bigger(int& a, int& b) {
    return (a > b) ? a : b;
}

int main() {
    int x = 3, y = 5;
    bigger(x, y) = 100;   // 相当于 y = 100
}
```

注意：**不要返回局部变量的引用**——函数一返回，局部变量就销毁了，引用变成悬空。

## 核心重点
- 引用是变量的别名，定义时必须初始化，之后不能改绑
- 能用引用就别用指针：更安全、语法更简洁
- `T&` 作参数可在函数内修改实参
- `const T&` 传大对象：避免拷贝又只读
- 绝不要返回局部变量的引用
