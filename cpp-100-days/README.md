# C++ - 100天从新手到大师

> 本套路线从零开始，用 100 天带你走完 C++ 基础语法、面向对象、STL、现代 C++、并发与工程化，并以一个综合项目收尾。建议工作日每天投入 1~1.5 小时：先读知识点、再手敲代码、最后做当日练习；周末用来复盘本周内容并完成阶段小项目。

## 阶段总览

| 阶段 | 天数 | 主题 |
|---|---|---|
| 01-C++基础 | Day01~13 | 与 C 的关系、环境、输入输出、命名空间、类型、运算符、流程控制、函数、引用、const |
| 02-类与对象 | Day14~25 | 类定义、构造析构、拷贝构造、运算符重载、static、友元、this、对象生命周期 |
| 03-继承与多态 | Day26~37 | 继承、虚函数、纯虚函数、抽象类、多态、虚析构、接口、组合 |
| 04-STL与泛型 | Day38~50 | 模板、vector、string、deque、list、stack、queue、priority_queue、set、map、迭代器、算法、lambda |
| 05-内存与现代C++ | Day51~63 | 深浅拷贝、智能指针、移动语义、右值引用、auto/decltype、C++11/14/17 特性、异常 |
| 06-文件流与工程化 | Day64~75 | 文件流、字符串流、多文件工程、命名空间组织、CMake、代码规范、单元测试 |
| 07-并发与设计模式 | Day76~88 | std::thread、线程同步、atomic、网络编程、常用设计模式 |
| 08-综合项目 | Day89~100 | 综合项目、重构、性能优化、总结复盘 |

## 怎么用

1. **按顺序学**：每天一个 `.md` 文件，先读"今日目标"和"学习内容"，把示例代码手敲一遍并编译运行。
2. **动手练**：每篇末尾有"练习/任务"，至少完成必做项；Day25 起附带"今日刷题"，挑 1~2 道在 LeetCode 上提交。
3. **打勾打卡**：每篇底部"打卡清单"当天完成后逐条打勾，保持节奏比单日学得多更重要。
4. **阶段复盘**：每个阶段最后一天是综合练习/小项目，务必停下来把前一阶段串起来做个东西，再进入下一阶段。
5. **环境**：建议使用 g++（支持 C++17）或 Visual Studio 2022；编译时加上 `-std=c++17` 选项。

## 目录约定

- 仓库根目录下按阶段建文件夹，命名为 `NN-主题`（`NN` 为两位阶段序号，如 `01-C++基础`）。
- 每个阶段文件夹内存放当天的学习笔记，文件名格式为 `DayNN.主题.md`：
  - `NN` 为两位天数编号，从 `01` 连续到 `100`；
  - `主题` 是当天内容的一句话概括，与文件内 H1 标题中的主题完全一致；
  - 例如 `04-STL与泛型/Day40.vector动态数组.md` 对应标题 `# Day 40 · vector动态数组`。
- 每篇 Day 文件固定小节顺序：`今日目标` → `学习内容` → `核心重点` → `练习/任务` →（Day25 起）`今日刷题` → `打卡清单`。

## 为什么学 C++

C++ 是在 C 之上扩展出来的一门多范式语言：既支持面向过程，又支持面向对象、泛型编程，现代 C++ 还引入了智能指针、移动语义、lambda 等设施。它广泛用于游戏引擎、操作系统、嵌入式高频交易、数据库、编译器、科学计算等对性能要求极高的领域。学会 C++，你不仅能写出高性能程序，还能真正理解对象模型、内存布局与编译期计算——这些是很多上层语言"藏起来"的东西。
