# Day 69 · 编译模型与链接

## 今日目标
- 理解编译的四个阶段
- 搞懂什么是"定义只能有一次"
- 学会处理常见链接错误

## 学习内容

### 编译的四个阶段

1. **预处理**：处理 `#include`、`#define`；
2. **编译**：生成汇编；
3. **汇编**：生成目标文件 `.o` / `.obj`；
4. **链接**：把目标文件 + 库拼成可执行文件。

### 声明 vs 定义

- 声明：告诉编译器"有这个东西"；
- 定义：真正分配内存/实现函数体。

```cpp
extern int globalVar;        // 声明
int globalVar = 10;          // 定义
```

### 单定义规则 ODR

**一个实体在整个程序里只能有一次定义。**

错例：在头文件里写 `int g = 0;`，两个 .cpp 都 include 这个头文件，链接时就会报"重复定义"。

正确做法：

- 头文件里 `extern int g;` 声明；
- 某个 .cpp 里 `int g = 0;` 定义。

### inline 函数例外

`inline` 函数可以在多个头文件里重复定义（只要每个定义都一样），所以模板函数、短小的 header-only 函数都加 inline。

### 常见链接错误

- `undefined reference to xxx`：函数声明了但没定义；
- `multiple definition of xxx`：同一个东西定义了多次。

### 静态成员变量

类内 `static int count_;` 只是声明，必须在某个 .cpp 里 `int MyClass::count_ = 0;` 定义。

## 核心重点
- 编译四阶段：预处理、编译、汇编、链接
- 声明可多次，定义只能一次（ODR）
- 头文件里放声明，源文件里放定义
- inline 函数例外，可在头文件里定义
- 链接错误 = 缺定义或重复定义
