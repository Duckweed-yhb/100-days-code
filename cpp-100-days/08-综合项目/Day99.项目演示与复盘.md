# Day 99 · 项目演示与复盘

## 今日目标
- 完整演示项目功能
- 复盘项目过程中踩过的坑
- 列出可改进点

## 学习内容

### 完整演示流程

1. `cmake --build .` 编译；
2. 启动 `./todo`；
3. add 5 个任务；
4. list 看全部；
5. done 其中两个；
6. list pending 看未完成；
7. quit 退出；
8. 查看 tasks.csv；
9. 重新启动，任务还在；
10. 跑 `./test_todo` 全过。

### 复盘：我们用了什么

| 知识点 | 在哪里用了 |
|---|---|
| class/封装 | Task、TaskStore、Persistence |
| 构造/析构 | 类的初始化 |
| STL | vector、string、algorithm |
| 智能指针 | 可选：用 unique_ptr 管理 Shape |
| 多文件 | .h/.cpp 分离 |
| CMake | 构建 |
| 文件流 | CSV 持久化 |
| 单元测试 | test_todo |
| lambda | sort/copy_if |
| 现代 C++ | auto、range-for、emplace |

### 踩过的坑

- CSV 逗号分隔没处理转义；
- nextId_ 在加载后没更新；
- 命令分发里 cin 失败导致死循环；
- 头文件卫士漏写。

### 可改进点

- 任务分类/标签；
- 命令行参数解析（argc/argv）；
- 彩色输出；
- 多用户/加密；
- 图形界面。

这些都是以后可以扩展的方向。

## 核心重点

- 踩坑是正常的，记录下来
- 演示比文档重要
