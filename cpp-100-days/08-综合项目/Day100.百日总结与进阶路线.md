## 学习内容

### 100 天路线回顾

| 阶段 | 你学会了什么 |
|---|---|
| 01-C++基础 | 语法、函数、引用、const、指针、动态内存 |
| 02-类与对象 | 封装、构造析构、拷贝、运算符重载、static、friend、this |
| 03-继承与多态 | 继承、虚函数、抽象类、多态、虚析构、切片、RTTI |
| 04-STL与泛型 | 模板、vector/string/map/set、迭代器、algorithm、lambda |
| 05-内存与现代C++ | 深浅拷贝、智能指针、移动语义、auto、异常、RAII |
| 06-文件流与工程化 | fstream、sstream、多文件、CMake、测试、调试 |
| 07-并发与设计模式 | thread、mutex、atomic、future、socket、单例/工厂/观察者 |
| 08-综合项目 | 一个完整命令行 todo 管理器 |

### 你现在具备的能力

- 能独立写多文件 C++ 工程；
- 能用 STL 解决算法题；
- 懂对象模型、内存管理、RAII；
- 能写多线程程序；
- 能把一个想法拆成模块实现出来。

### 接下来学什么

**方向一：深入语言**

- C++17/20 新特性（如果还没学）；
- 模板元编程；
- 内存模型与无锁编程；
- 阅读《Effective C++》《More Effective C++》。

**方向二：系统与底层**

- Linux 系统编程；
- 网络编程深入（epoll、reactor）；
- 数据库内核；
- 操作系统课程（OSTEP）。

**方向三：应用领域**

- 游戏开发：Unreal Engine；
- 高频交易：低延迟；
- 嵌入式：裸机/RTOS；
- 图形学：OpenGL/Vulkan。

**方向四：算法与竞赛**

- LeetCode 刷到 300 题；
- Codeforces 上分；
- NOIP/ACM 真题。

### 保持节奏

- 每周写一个小程序；
- 每月读一本经典书；
- 每季度做一个稍大的项目；
- 把代码放 GitHub，写 blog 记录。

### 结语

100 天只是起点。C++ 是一门越学越深的语言，但你已经具备了继续学下去的所有基础：查文档、写代码、调 bug、做工程。

继续往前走，别停。
