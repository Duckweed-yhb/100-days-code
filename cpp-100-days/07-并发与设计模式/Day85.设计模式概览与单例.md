### 设计模式是什么

前人总结的、面向对象设计中反复出现的问题的典型解法。GoF 23 种是经典，今天只讲最常用的几种。

### 单例模式

一个类全局只有一个实例，并提供一个访问点。

```cpp
class Logger {
public:
    static Logger& instance() {
        static Logger inst;     // C++11 起局部 static 线程安全
        return inst;
    }
    void log(const std::string& msg) {
        std::cout << msg << '\n';
    }
private:
    Logger() = default;
    Logger(const Logger&) = delete;
    Logger& operator=(const Logger&) = delete;
};

int main() {
    Logger::instance().log("hello");
}
```

要点：

- 构造函数私有；
- 删除拷贝；
- 静态局部变量（Meyers 单例）；
- C++11 起局部 static 初始化线程安全。

### 什么时候用单例

- 全局配置；
- 日志器；
- 资源管理器。

### 什么时候别用单例

单例本质是全局变量，滥用会让代码难测试。能依赖注入就别单例。

### 常见模式清单（了解）

| 模式 | 用途 |
|---|---|
| 单例 | 全局唯一实例 |
| 工厂 | 封装对象创建 |
| 观察者 | 发布订阅 |
| 策略 | 算法可替换 |
| 装饰器 | 动态加功能 |
| 适配器 | 接口转换 |
