# Day 35 · 向上转型与对象切片

## 今日目标
- 理解派生类对象可以当作基类对象用
- 识别"对象切片"bug
- 学会安全的向下转换

## 学习内容

### 向上转型

派生类是一种基类，所以可以把派生类对象赋给基类指针/引用：

```cpp
Dog d;
Animal* p = &d;       // 向上转型：Derived* -> Base*
Animal& r = d;        // 引用也行
```

向上转型是**安全、隐式**的，因为 Dog 一定是 Animal。

### 对象切片（slicing）

危险的是把派生类对象**按值**赋给基类对象：

```cpp
Dog d;
Animal a = d;     // 切片！Dog 里 Dog 特有的部分被切掉了
```

`a` 是一个完整的 Animal 对象，它把 d 里"Dog 那部分"切掉，只保留 Animal 子对象。这就是**对象切片**。

### 切片 + 多态失效

```cpp
void f(Animal a) {       // 按值传参，会切片
    a.speak();           // 永远调 Animal::speak
}

Dog d;
f(d);                    // 切了！多态失效
```

修复方法：按基类**引用或指针**传参：

```cpp
void f(Animal& a) { a.speak(); }   // 不切片，多态生效
```

### 向下转换

基类指针转回派生类指针，叫向下转换，必须显式：

```cpp
Animal* p = new Dog;
Dog* dp = static_cast<Dog*>(p);    // 你确定 p 真的指向 Dog 时
```

不确定时用 `dynamic_cast`（Day36 讲），它会在运行时检查。

### 经验法则

- 多态函数参数一律用 `Base&` 或 `Base*`，不要用 `Base` 按值；
- 不要把派生类对象按值塞进基类变量。

## 核心重点
- 向上转型：派生类指针/引用 -> 基类，安全隐式
- 对象切片：派生类按值赋给基类对象，多余部分被切掉
- 切片后多态失效
- 多态函数参数用引用/指针，不要按值
- 向下转换要显式 cast
