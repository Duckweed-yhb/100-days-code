# Java - 100 天学习路线（从 0 基础到大厂）

> 一份面向零基础、按「天」推进的 Java 学习路线。改编自一位 **26 届学长**（秋招前已拿腾讯、字节、淘天、美团、蚂蚁、小红书、得物、拼多多等大厂 offer，四段大厂实习）的 B 站视频文案《Java 学习路线》，按 100 天拆解成可逐日打卡执行的学习计划。
>
> 建议节奏：**工作日 1~1.5 小时 / 天**，周末适当加量。**算法从 Day20 起每日贯穿**；项目集中在最后 5 天（Day96~100），但项目思维建议从前一阶段收尾时就同步酝酿。

## 为什么用这套路线

- **经过实践检验**：来自真实大厂 offer 持有者的个人经验 + 对自身走过的弯路改良后的路线，并非博眼球的"全网最好"，而是"经过实践"的版本
- **八股四大件**（MySQL、Redis、JVM、JUC）与算法、项目并重，重要程度数值全部来自原文案
- 所有视频链接（BV 号）、书籍推荐、算法刷法、项目理念均忠实保留原文案，未作改动

## 怎么用

1. 按 Day01 → Day100 顺序推进，每天一篇，先读「今日目标」再开始
2. 每天完成「练习/任务」并勾选「打卡清单」；Day20 起每天固定完成「今日刷题」
3. **刷题只刷力扣四套题单**：hot100、LeetCode 75、面试经典150、高频SQL50题（基础版），按分类刷、简单→中等→困难、5 分钟没思路直接看题解、反复刷
4. **八股采用"深度 + 记录"**：坚决不背，对每个知识点学深，并记录自己的思考
5. **项目放在最后阶段启动**：知识沉淀越多，你对项目各个技术栈的理解越不一样，更容易形成自己的思考与亮点
6. 姊妹篇（上期视频）《大三的我是如何拿下三段大厂实习？》：https://www.bilibili.com/video/BV1Z1XQYmE1h ，含"学多久、会忘记怎么办"等问题的解答，建议先看完两期视频再带着问题来

## 目录约定

- 每个阶段一个数字前缀文件夹：`01-主题/`、`02-主题/` …（共 8 个阶段）
- 每天一个文件：`DayNN.主题.md`（NN 为两位序号 01..100，主题为当天内容一句话）
- 每篇结构统一：`今日目标 → 学习内容 → 核心重点 → 练习/任务 →（Day20 起）今日刷题 → 打卡清单`
