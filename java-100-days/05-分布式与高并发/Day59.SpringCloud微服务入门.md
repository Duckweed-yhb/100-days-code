## 核心重点

- 单体架构的痛点：模块耦合、部署笨重、技术栈受限
- 微服务架构：按业务拆分、独立部署、独立数据库
- SpringCloud 与 SpringBoot 的关系（SpringCloud 基于 SpringBoot）
- 服务注册与发现：Eureka、Nacos 的基本作用
- 服务提供者（Provider）与服务消费者（Consumer）
- 远程调用的基本概念（HTTP / RPC）
- 服务集群与负载均衡的直觉理解
- 微服务常见组件清单（网关、配置中心、熔断器等，先混个脸熟）
