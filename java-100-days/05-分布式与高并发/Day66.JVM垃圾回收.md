## 核心重点

- 引用计数法的缺陷：循环引用无法回收
- 可达性分析：从 GC Roots 出发，不可达的对象被判为可回收
- GC Roots 候选：虚拟机栈中引用的对象、静态属性引用、常量引用、native 引用
- 四种引用：强引用、软引用、弱引用、虚引用
- 标记-清除：有碎片
- 标记-复制：适合新生代，无碎片但浪费空间
- 标记-整理：适合老年代，无碎片但移动成本高
- 分代收集：新生代用复制算法，老年代用标记-清除或标记-整理
- Minor GC（新生代）、Full GC（整堆 + 方法区）的触发场景
