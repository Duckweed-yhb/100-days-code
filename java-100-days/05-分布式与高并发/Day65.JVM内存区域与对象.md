## 核心重点

- 程序计数器：线程私有，记录当前线程执行的字节码行号
- Java 虚拟机栈：线程私有，栈帧（局部变量表、操作数栈、动态链接、方法出口）
- 本地方法栈：为 native 方法服务
- 堆：线程共享，对象主要分配在这里，GC 主战场
- 方法区：线程共享，存类信息、常量、静态变量
- JDK7 → JDK8：永久代（PermGen）被元空间（Metaspace）取代，使用本地内存
- 对象创建过程：类加载检查 → 分配内存 → 零值初始化 → 对象头设置
- 对象内存布局：对象头（Mark Word + 类型指针）、实例数据、对齐填充
- 直接内存：NIO 用到，不在 JVM 运行时数据区内
