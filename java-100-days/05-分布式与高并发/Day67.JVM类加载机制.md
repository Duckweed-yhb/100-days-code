## 核心重点

- 类加载生命周期：加载 → 验证 → 准备 → 解析 → 初始化 → 使用 → 卸载
- 验证：确保 Class 文件格式符合 JVM 规范
- 准备：给静态变量分配内存并设零值（`static int a = 1` 在这里先变 0）
- 解析：符号引用替换为直接引用
- 初始化：执行 `<clinit>`，真正给静态变量赋初值
- 启动类加载器（Bootstrap）：加载 `rt.jar` 等核心库
- 扩展类加载器（Extension / Platform）：加载 `ext` 目录
- 应用程序类加载器（Application）：加载 classpath 下的类
- 双亲委派：收到加载请求先委托给父加载器，父加载不了再自己加载
- 双亲委派的好处：避免类被重复加载、核心库被篡改
