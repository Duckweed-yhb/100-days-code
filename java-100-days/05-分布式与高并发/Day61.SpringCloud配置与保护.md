## 核心重点

- 多服务配置分散在各工程里的痛点
- Nacos Config：把配置抽到 Nacos，各服务统一拉取
- 配置热更新：改 Nacos 上的配置，服务不重启生效
- 服务雪崩：一个下游服务挂了，把上游一层层拖垮
- 熔断：错误率 / 慢调用比例到阈值后直接短路
- 降级：兜底返回默认值，不让请求卡死
- Feign Fallback：远程调用失败时走的兜底逻辑
- Sentinel 与 Hystrix 的大致定位（Hystrix 已停止维护）
