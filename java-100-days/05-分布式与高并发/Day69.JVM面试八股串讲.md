## 核心重点

- 串行收集器 Serial：单线程，客户端小堆
- 并行收集器 Parallel：多线程吞吐优先，JDK8 默认
- CMS（Concurrent Mark Sweep）：低停顿，标记-清除，有碎片
- G1：整堆分 Region，可预测停顿，JDK9+ 默认
- ZGC / Shenandoah：超低停顿大堆收集器，了解即可
- 常见八股：JVM 内存区域、GC Roots、什么情况会 OOM
- 常见八股：类加载过程、双亲委派为什么这么设计
- 常见八股：CMS 与 G1 的区别
- 回答套路：先给结论 → 展开 2-3 个要点 → 举一个自己项目/调试中的例子
