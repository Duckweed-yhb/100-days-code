## 核心重点

- 慢查询日志与执行计划（`EXPLAIN`）的作用
- 索引失效的常见场景：对索引列做函数运算、违反最左前缀、`LIKE` 以 % 开头等
- 常见优化思路：避免 `SELECT *`、合理使用索引、减少回表
- 锁的基本分类：表锁与行锁
- 共享锁（S 锁）与排他锁（X 锁）
- 意向锁的基本概念
- 间隙锁与 Next-Key Lock（InnoDB 解决幻读的手段）
