## 核心重点

- InnoDB 存储引擎：支持事务、行锁、外键，是 MySQL 默认引擎
- redo log：崩溃恢复，保证持久性
- undo log：事务回滚与 MVCC 快照读
- binlog：Server 层日志，用于主从复制与数据恢复
- 主从复制：主库写、从库读，异步同步
- 读写分离：写走主库、读走从库，分摊压力
- 分库分表：数据量过大时的水平拆分思路（分片键、扩容问题）
- MySQL 阶段整体回顾：SQL 基础 → 事务 → 索引 → 优化与锁 → 引擎与架构
