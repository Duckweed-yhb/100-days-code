## 核心重点

- 算法就是写题，可能出现在面试和笔试中
- 面试：核心代码模式（非绝对）——直接实现函数就行
- 笔试：一定是 ACM 模式——需要自己处理输入输出
- ACM 模式在 Java 里靠 `Scanner` 读入、`System.out.println()` 输出
- 写题通常在非 IDE 环境下进行，不能随时查类有哪些方法，所以要熟悉 Java 常用 API
