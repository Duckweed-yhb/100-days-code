## 学习内容

  - 源文案无单条视频
- 今日进度：把「怎么刷 / 何时刷 / 重要性」三件事一次理清
- 源文案关于怎么刷的说明：**按分类刷，对于一个分类下，从简单-中等-困难的顺序去刷，一道题五分钟没思路，直接看题解，不要犹豫，因为不是你从0到1想出来的才叫成长，而是你踩在前人的肩膀上，能够举一反三，这才叫成长，好比你让一个小学生求导数……所以不要觉得看题解很羞耻，直接看就完事，但你一定要从题解获得成长，而不是走马观花，你应该把思考问题的时间花在思考题解上！**
- 源文案关于配套视频的说明：**除此之外，可以看"灵茶山艾府"的一套基础算法精讲，基本上是对标hot100题单里的题，非常推荐去看，每个视频简介里的课后作业也可以做做（https://space.bilibili.com/206214/lists/842776?type=season）**
- 源文案关于反复刷的说明：**其次是需要反复刷，来回刷，刷到能够看到题就默写的程度，只刷上面的题单，刷完一遍刷第二遍，刷完第二遍刷第三遍，就我个人而言，我把"hot100"刷了四五遍了，现在刷一遍只需要一天半就能刷完一百题。**
- 源文案关于何时刷的说明：**在学完JavaSE的集合后，熟悉集合的基本操作后，再去稍微了解下常见数据结构……就可以刷题了……算法是个长期的过程，题目量不需要刷很多，但要反复刷，所以需要较早开始，但不需要投入太多的时间。**

## 核心重点

- 怎么刷：按分类刷；一个分类内按 简单 → 中等 → 困难 顺序
- 一道题 5 分钟没思路，直接看题解，不要犹豫，不要觉得羞耻
- 成长 = 踩在前人肩膀上举一反三，而不是从 0 到 1 自己硬想
- 看题解也要有收获：把思考时间花在思考题解上，不能走马观花
- 配套视频：灵茶山艾府「基础算法精讲」，对标 hot100，视频简介里的课后作业也做
- 反复刷：只刷上面那几个题单，一遍刷完刷第二遍、第三遍，刷到看到题能默写
- 何时开始：学完 JavaSE 集合、熟悉集合基本操作、稍微了解常见数据结构后即可开始
- 算法是长期过程：题量不需要多，但要反复刷，早开始、不投入太多时间

重要性（源文案判断）：

- **不要去系统地学什么数据结构、系统地学习算法，直接刷题入手**
- 算法的唯一用处就是为了筛选人，实际工作根本用不到
- 面试：面了 30 多场大厂面试，**90% 的算法都是"hot100"题库里的原题，一个字都不改的原题**；剩下 10% 吃透 hot100、有一定算法思维后也能做出来
- 笔试：不会出原题，一般 3-4 题，但**其实就是走个过场**，人家不看笔试成绩，仍看简历决定约不约面，除非是 0 题选手
- 笔试一般写出 1 题即可，简历好时写出半题都没事（按通过用例比例算成绩，可能出现小数）；**压根没有什么笔试挂，只有简历挂**；笔试第一题基本是签到题
- 综上：算法没必要刷太多，面试提前告诉你题库，笔试又不看成绩，走个过场而已
