## 核心重点

- 「八股」指面试中面试官问的前面学过的知识，因问答较死板、类似八股取士而得名
- 八股只是调侃，不是真的死记硬背；现在很多问题非常灵活
- 即使是常见八股，回答也能和别人不一样，能体现自己的思考，拉开差距
- 死背八股过不了这一关，极不建议死背
- 应对方法：「深度 + 记录」结合
  - 深度：对市面上的八股来源进行深度学习，而非表面背诵
  - 记录：把自己的思考记录下来
- 广度获取知识：在学习过程中会接触到各种八股来源，都可以保留下来
