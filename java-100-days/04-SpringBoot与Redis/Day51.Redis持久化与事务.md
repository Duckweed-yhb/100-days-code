## 核心重点

- 为什么要持久化：Redis 是内存数据库，宕机数据会丢
- RDB：在特定时间点把数据快照存盘，体积小、恢复快
- AOF：以日志形式记录每条写命令，数据更完整、文件更大
- RDB 与 AOF 的取舍与同时开启时的加载优先级
- Redis 事务的概念：一次性、按顺序执行一组命令
- 事务相关命令：`MULTI`、`EXEC`、`DISCARD`、`WATCH`
- Redis 事务「不保证原子性」的特点（与 MySQL 事务区分）
- 这些都是面试八股常考点，先记住名词与结论
