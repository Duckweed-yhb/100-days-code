> 阶段：04-SpringBoot与Redis ｜ 重要程度：4.2 ｜ 源视频：https://www.bilibili.com/video/BV15b4y1a7yG/

## 今日目标

- 掌握 SpringBoot 整合数据库的基本流程：数据源、JDBC / 持久层框架
- 能完成从 Controller 到数据库的一次完整增删改查
- 为后面 Redis、黑马点评项目打下数据访问基础

- **源路线**：SpringBoot 建议 4-5 天学完，重要程度 **4.2**

## 核心重点

- 数据库连接配置：url / username / password / 驱动
- 起步依赖引入对应的数据库访问组件
- 内置连接池（如 HikariCP）的自动装配
- JdbcTemplate 的基本增删改查用法
- 整合持久层框架（如 MyBatis）的 mapper 接口扫描
- 事务管理：`@Transactional` 的基本使用
- 实体类与表结构的映射关系

## 练习/任务

1. 配置好数据源，连上自己的 MySQL 库
2. 写一个能真正读写数据库的接口（查询 / 新增一条记录）
3. 在一个方法上加 `@Transactional`，体会事务的作用
4. 跟不跟敲结合自己情况：数据能正确落库、能查出来就算达标
