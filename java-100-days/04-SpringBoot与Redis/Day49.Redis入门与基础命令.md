## 核心重点

- Redis 是什么：基于内存的键值（key-value）存储，单线程模型概念
- 常见使用场景：缓存、秒杀、分布式锁等（后面项目会大量用到）
- 安装、启动服务与客户端连接
- 通用命令：`KEYS`、`DEL`、`EXISTS`、`EXPIRE`、`TTL`
- string 类型基础命令：`SET`、`GET`、`INCR`、`DECR`
- key 的命名规范与过期时间概念
- 命令行客户端的基本交互方式

## 练习/任务

1. 安装并启动 Redis，客户端能连上并执行 `PING` 返回 `PONG`

3. 给某个 key 设置过期时间，用 `TTL` 观察剩余时间变化
