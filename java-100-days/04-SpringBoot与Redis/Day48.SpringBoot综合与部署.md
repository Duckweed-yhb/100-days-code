## 核心重点

- 阶段回顾：自动配置、起步依赖、配置文件、Web 接口、数据访问
- 工程打包：打成可执行 jar 包
- 命令行 `java -jar` 启动运行
- 内嵌服务器的好处：无需外部 Tomcat，开箱即跑
- 多环境打包 / 启动时指定 profile
- 版本选择：SpringBoot2 和 SpringBoot3 没啥区别，底层是差不多的，按课程版本学即可
- 面试定位：用得相对少，但一定得会，不必深挖底层原理
