## 核心重点

- string：最基础，缓存对象、计数器、分布式锁常见
- hash：存储对象的多个字段，适合存用户信息等
- list：有序可重复，可做消息队列、栈、榜单等
- set：无序不重复，可做标签、共同好友、去重
- zset：有序集合，带分数，可做排行榜、热搜榜单
- 各类型的代表命令（如 `HSET/HGET`、`LPUSH/RPOP`、`SADD/SMEMBERS`、`ZADD/ZRANGE`）
- 按业务场景选型的思维：什么需求用什么结构
