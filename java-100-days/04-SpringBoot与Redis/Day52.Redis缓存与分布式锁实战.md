## 核心重点

- 缓存作用：把热点数据放进 Redis，减少数据库压力
- 缓存的基本读写流程：先查缓存，未命中再查库并回写
- 缓存穿透：查询不存在的数据，请求直穿到数据库
- 缓存击穿：热点 key 过期瞬间大量请求打到数据库
- 缓存雪崩：大量 key 同时过期或 Redis 宕机
- 分布式锁要解决的问题：多实例下的并发互斥
- 基于 Redis 的分布式锁：`SET NX EX` 加锁、释放锁的基本思路
- Java 客户端操作 Redis：StringRedisTemplate 常见 API
