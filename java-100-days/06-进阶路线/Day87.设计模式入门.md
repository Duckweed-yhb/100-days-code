## 核心重点

- 设计模式的目的：可维护、可扩展、可复用
- 常见设计原则名词：单一职责、开闭原则、依赖倒置、里氏替换
- 单例模式：饿汉式、懒汉式、双重检查锁（DCL）
- 工厂模式：简单工厂、工厂方法、抽象工厂分别解决什么问题
- 策略模式：把一组可互换的算法封装起来
- 观察者模式：事件订阅 / 发布通知
- 代理模式：静态代理与动态代理（和 Day81 Spring AOP 呼应）
- 责任链模式：请求沿着一条链传递（SpringMVC 的拦截器链就是例子）
- 适配器模式与装饰器模式的区别
