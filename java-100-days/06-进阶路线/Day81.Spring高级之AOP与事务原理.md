## 核心重点

- AOP 的核心概念：Aspect、Pointcut、Advice、JoinPoint
- 通知类型：前置、后置、环绕、异常、最终通知分别在什么时机执行
- JDK 动态代理（基于接口）与 CGLIB 代理（基于子类）的区别
- Spring 默认在什么情况下选 JDK 代理、什么情况下选 CGLIB
- `@Transactional` 基于 AOP 代理实现：方法被调用时先开启事务、正常返回提交、抛异常回滚
- 事务失效的常见场景：自调用、非 public 方法、异常被 catch 吞掉、异常类型不匹配
- 事务传播行为（Propagation）：REQUIRED、REQUIRES_NEW 等名词了解即可
- 事务隔离级别与数据库隔离级别的对应关系
