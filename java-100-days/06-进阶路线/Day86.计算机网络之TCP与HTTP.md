## 核心重点

- TCP 三次握手为什么是三次（不是两次）
- TCP 四次挥手为什么是四次
- TCP 靠什么保证可靠：序列号、确认应答、超时重传、滑动窗口
- 拥塞控制名词：慢启动、拥塞避免、快重传、快恢复
- UDP 与 TCP 的区别：无连接、不保证可靠、开销小
- HTTP 请求报文结构：请求行、请求头、请求体
- 常见状态码：200、301、302、304、400、401、403、404、500、502、504
- HTTP/1.1 与 HTTP/2 的主要区别（多路复用等名词）
- HTTPS 大致流程：对称加密 + 非对称加密 + 数字证书
