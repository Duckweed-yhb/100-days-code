## 核心重点

- 死锁的四个必要条件：互斥、持有并等待、不可剥夺、循环等待
- 死锁处理思路：预防、避免（银行家算法名词）、检测与恢复、忽略
- 文件系统名词：inode、目录项、硬链接、软链接（了解即可）
- 阻塞 IO 与非阻塞 IO 的区别
- IO 多路复用：select / poll / epoll 名词，epoll 为什么更高效
- 五种 IO 模型的整体分类（同步阻塞、同步非阻塞、IO 多路复用、信号驱动、异步）
- 零拷贝（Zero-Copy）解决什么问题：减少内核态与用户态之间的数据拷贝
- 磁盘调度与读写基本概念（了解即可）
