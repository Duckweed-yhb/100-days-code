## 核心重点

- 进程与线程的区别：进程是资源分配的最小单位，线程是 CPU 调度的最小单位
- 进程状态：新建、就绪、运行、阻塞、终止之间的切换
- CPU 调度算法名词：先来先服务、短作业优先、时间片轮转、高优先级调度
- 进程间通信（IPC）：管道、消息队列、共享内存、信号量等名词
- 并发与并行的区别
- 虚拟内存的作用：让每个进程以为自己独占内存
- 分页与分段的区别：分页对程序员透明、段按逻辑划分
- 缺页中断与页面置换（只作名词了解）
