## 核心重点

- 一次网页请求的整体链路：浏览器 → DNS → 网关 → 路由器 → 服务器
- 网络分层模型名词：应用层、传输层、网络层、网络接口层
- DNS 做什么：把域名解析成 IP 地址
- MAC 地址与 IP 地址的区别：一个是网卡身份证，一个是逻辑地址
- 网关与路由器在链路中起什么作用
- 数据包在每一层是怎么被「加头 / 去头」的（封装与解封装）
- 交换机与路由器的区别（交换机内网转发、路由器跨网转发）
- 服务器收到请求后大致如何把响应再发回来
