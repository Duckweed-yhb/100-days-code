## 核心重点

- 创建型模式：单例、工厂方法、抽象工厂、建造者、原型
- 结构型模式：适配器、桥接、组合、装饰器、外观、享元、代理
- 行为型模式：责任链、命令、迭代器、中介者、备忘录、观察者、状态、策略、模板方法、访问者
- 重点中的重点：单例、工厂、策略、观察者、代理、责任链
- 每个模式至少记住一个「真实框架里的例子」（如 Spring AOP = 代理、Spring 事件 = 观察者）
- 设计模式不是银弹：不要为了用模式而用模式
- 代码可读性 > 模式套得花里胡哨
