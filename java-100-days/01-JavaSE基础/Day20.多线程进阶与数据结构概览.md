## 核心重点

- `synchronized` 同步方法与同步代码块
- `Lock` 接口与 `ReentrantLock` 基本用法
- 线程安全问题与解决思路
- 线程池概念与 `Executors` 基本使用
- 常见数据结构特点：单端队列、双端队列、优先队列、栈、二叉树、二叉搜索树
- Java 对应实现类：`ArrayDeque`、`LinkedList`、`PriorityQueue` 等
