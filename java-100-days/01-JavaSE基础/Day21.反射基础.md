## 核心重点

- 反射：在运行时动态获取类信息、动态调用对象的成员
- 获取 Class 对象三种方式：`类名.class`、`对象.getClass()`、`Class.forName("全类名")`
- `Constructor`：通过反射获取构造方法并 `newInstance()` 创建对象
- `Field`：获取成员变量，`set()` / `get()` 读写值
- `Method`：获取成员方法，`invoke()` 调用
- 反射可以访问私有成员（`setAccessible(true)` 取消权限检查，了解）
- 反射是后面框架（如 Spring）的底层原理，现在先会用
