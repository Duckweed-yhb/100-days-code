## 核心重点

- 算术运算符：+ - * / %，自增自减 `++` `--`
- 赋值运算符：=、+=、-= 等（隐含强转）
- 比较运算符与逻辑运算符：==、!=、&&、||、!
- 三元运算符：`条件 ? 值1 : 值2`
- `Scanner` 键盘录入基本用法
- 分支：if / if-else / if-else if-else、switch（case 穿透）
- 循环：for、while、do-while 三种格式与执行顺序
- `break` 跳出当前循环、`continue` 跳过本次

## 练习/任务

1. 用 Scanner 录入两个数，用三元运算符输出较大值
2. 用 for 循环打印 1-100 的偶数和
3. 用嵌套循环打印一个直角三角形星星图案
4. 分别用 break 和 continue 改写同一个循环，观察输出差异
