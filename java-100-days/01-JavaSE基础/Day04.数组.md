## 核心重点

- 数组定义格式：`数据类型[] 变量名`
- 动态初始化（只给长度）与静态初始化（直接给元素）
- 索引从 0 开始，长度用 `数组.length` 获取
- 常见操作：遍历、求和、求最大值/最小值
- 数组索引越界异常 `ArrayIndexOutOfBoundsException`
- 二维数组的定义与遍历
- 数组作为方法参数与返回值的基本认知

## 练习/任务

1. 静态初始化一个班级分数数组，遍历并打印每个元素
2. 动态初始化一个长度为 5 的 int 数组，赋值后求总和与平均值
3. 在数组中找最大值，并打印其索引
4. 故意访问一个越界索引，观察异常信息
