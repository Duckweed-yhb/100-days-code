## 核心重点

- 封装：成员变量用 `private` 隐藏，对外提供 `getXxx` / `setXxx`
- `super` 表示父类空间，调用父类构造/方法/属性
- 继承 `extends`：子类拥有父类非 private 的成员；Java 只支持单继承
- 方法重写（Override）：子类方法与父类声明一致，`@Override` 注解
- 多态：父类引用指向子类对象（`父类 对象 = new 子类()`）
- 多态成员访问特点：编译看左边、运行看右边（方法）
- 向上转型自动、向下转型需强转，配合 `instanceof` 判断
- 重写 vs 重载的区别
