## 核心重点

- JDK（开发工具包）、JRE（运行环境）、JVM（虚拟机）三者的关系
- 环境变量 `JAVA_HOME` 与 `PATH` 的配置
- 主类结构：`public class 类名` 与文件名一致
- 程序入口：`public static void main(String[] args)`
- 输出语句：`System.out.println()`
- 三种注释：单行 `//`、多行 `/* */`、文档 `/** */`
- 代码规范：类名大驼峰、变量名小驼峰、缩进与花括号对齐

## 练习/任务

1. 下载安装 JDK，配置环境变量，命令行运行 `java -version` 和 `javac -version` 验证
2. 用 IDEA（或 VS Code）新建项目，编写并运行 Hello World
3. 尝试修改输出内容、添加注释，感受「编译 → 运行」的流程
4. 不用写很多代码：前期以熟悉语法和规范为主
