# Day 96 · 项目定位与简历要求

> 阶段：08-项目实战 ｜ 重要程度：源文案未标注 ｜ 源视频：源文案无单条视频（本阶段为项目理念篇）

## 今日目标

- 搞清楚面试官考察项目时「核心考察的到底是什么」
- 明确简历上项目数量的硬性要求：几个、有没有实习分别怎么算
- 理解「实习也可以属于项目当中」，但实习产出与项目思维的区别
- 对本阶段接下来几天要建立的项目观有整体预期

## 学习内容

- **本阶段定位**：源文案开篇即抛出问题——「项目核心考察是什么？」；本阶段不写教程级技术内容，只建立项目理念与规划
  - 源文案说明：实习也可以属于项目当中，里面的思维是一样的，但仍然会有一些不一样的地方，比如实习该如何做产出等等，有关实习部分可以去看我上一期视频，这里主要还是讲项目
- 今日要点：先立住「简历项目数量」这条硬标准，再谈后面怎么选、怎么做、怎么答
- 源文案提示：**项目的话，首先，简历上至少要有两个项目，有实习的话，可以适当减少至一个。没实习的话，一定至少两个**

## 核心重点

- 项目面试的核心考察点：不是项目本身多牛，而是你对项目的思考与理解（详见后续 Day）
- 简历项目数量底线：至少两个项目
- 有实习：可适当减少至一个
- 没实习：一定至少两个，没有讨价还价余地
- 实习与项目的关系：实习也可以算进项目里，思维是相通的
- 实习的差异点：如「该如何做产出」这类问题，源文案指引去看上一期视频，不在本阶段展开

## 练习/任务

1. 拿出自己的简历草稿，对照「至少两个项目」这条硬标准，数一下目前写了几个
2. 判断自己属于「有实习」还是「没实习」，据此确认本阶段需要补齐的项目数量
3. 列一个待办：哪些项目已经能写进简历、哪些还只是学过没沉淀
4. 本阶段不敲代码：以梳理简历与项目认知为主

## 今日刷题

- 面试前 hot100 快速反复刷，保持手感，每天 **2-3 道**
- 题单：力扣 hot100（已刷过多遍，目标是看到题能默写）
- 策略：分类刷、反复刷——刷完一遍刷第二遍，刷到能够看到题就默写的程度
- 不追新题、不抠难题，重点是把已经会的练到肌肉记忆
