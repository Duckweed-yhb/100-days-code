# Day 98 · 项目选择之避开烂大街

> 阶段：08-项目实战 ｜ 重要程度：源文案未标注 ｜ 源视频：源文案无单条视频（本阶段为项目理念篇）

## 今日目标

- 理解为什么源文案「极力不推荐」烂大街、人手一份的项目
- 明白哪怕把烂大街项目重构得再熟，为什么也难过简历关
- 记住那句核心判断：「项目无罪，但用的人多了就有罪了」
- 在选项目时主动避开同质化严重的方向

## 学习内容

- **立场声明**：源文案不推荐具体项目，但有一个非常重要、极力强调的避坑点
  - 源文案原文：有个非常重要的点，就是我极力不推荐大家用市面上我们所谓的烂大街的项目，就是说人手一份的项目
- 今日要点：哪怕你对烂大街项目理解极深、改得极多，也救不回它带来的负面影响
  - 源文案原文：即使说，你对这个烂大街的项目，有自己非常非常非常独特的理解，甚至说你基于你自己的理解，对代码重构了90%以上，这个项目就像你亲生儿子一样熟悉，你如数家珍，也没用
- 为什么没用：问题不在你理解深不深，而在项目本身的「竞争环境」
  - 源文案原文：因为你很难过简历筛，并且面试官大概率对项目不感兴趣，还没开问就没第一印象了

## 核心重点

- 极力不推荐：市面上烂大街、人手一份的项目
- 即便独特理解 + 重构 90% 以上 + 如数家珍，依然没用
- 原因一：很难过简历筛（HR / 筛选阶段直接被刷）
- 原因二：面试官对项目不感兴趣，还没开问就没了第一印象
- 金句：**项目无罪，但用的人多了就有罪了**
- 与 Day97 的关系：亮点重要没错，但烂大街项目连「被听到亮点」的机会都很难拿到

## 练习/任务

1. 复盘自己目前打算写进简历的项目，判断是否属于「人手一份」的烂大街项目
2. 如果是，思考如何在方向 / 改造上拉开与大多数人的差距（方向见明天 Day99）
3. 记牢「项目无罪，但用的人多了就有罪了」，选项目前先过一遍这条
4. 不点名任何具体项目：只判断同质化程度，不在这里罗列项目名

## 今日刷题

- 面试前 hot100 快速反复刷，保持手感，每天 **2-3 道**
- 题单：力扣 hot100（已刷过多遍，目标是看到题能默写）
- 策略：分类刷、反复刷——刷完一遍刷第二遍，刷到能够看到题就默写的程度
- 选项目纠结时，不如先把手感题刷了，思路往往更清楚
