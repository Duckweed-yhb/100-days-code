# Day 97 · 项目思维与面试亮点

> 阶段：08-项目实战 ｜ 重要程度：源文案未标注 ｜ 源视频：源文案无单条视频（本阶段为项目理念篇）

## 今日目标

- 理解面试官「真正想看到想听到」的到底是什么
- 明白为什么源文案不推荐任何具体项目（高并发、外卖商城、轮子、自研都不是考察点）
- 学会面对「项目上线了吗、qps 多少」这类问题时大方、坦诚的应答思路
- 建立「亮点比项目本身重要」的项目思维

## 学习内容

- **核心观点**：源文案明确——不会推荐具体的某个项目，因为无论你是所谓的高并发项目，还是所谓的外卖商城经典烂大街项目，还是所谓的轮子项目，亦或是自研项目等等，都不是面试官想考察的项目的点
  - 源文案原文：不会说你是少见的、听起来牛逼哄哄的项目，就一定比那些用烂大街项目的人厉害，然后对你多看两眼，不是这样的
  - 源文案原文：项目真正的作用、面试官真正想看到想听到的，是你对项目的自己的思考、你独特的理解、你创新的地方
- 今日要点：只要对项目有自己的理解、有自己创新的点，面试时就完全不会怕
- 源文案给的标准应答示例（可直接体会其话术思路）：

  > 比如面试官问你："你这个项目有上线吗？qps多少？"有的人一听就怕了，实际上你完完全全可以大大方方的承认："是这样的面试官，我这个项目是网上的一个开源学习项目，然后我就是拉取了代码进行学习，主要还是出于探索学习目的，所以并没有上线，但在我学习的过程中，我发现原有项目有几个点存在问题，那出于学习目的，我肯定是对这几个点进行了深入思考的，最终我基于这个开源学习项目有了基于我自己见解的一些修改，比如第一点......"

## 核心重点

- 项目的真正作用：体现你的思考、理解与创新，而非项目名头
- 少见 / 听起来牛逼的项目 ≠ 一定被高看一眼
- 危险反面：写了个天花乱坠的项目，面试官一问「哪些是你自己做的」就懵了
- 常见翻车：背了很多文档、准备了很多可能被深挖的点，结果啥也答不出来
- 正确姿态：大方承认项目来自开源学习、没上线，再讲自己发现的问题与修改点
- 面试问项目的真正意义：需要有能体现你价值、体现你思考、体现你技术、体现你思维的亮点
- 结论：亮点与你是外卖也好、商城也罢无关，关键是亮点本身

## 练习/任务

1. 把上面那段「开源学习项目」应答示例读顺，用自己的话复述一遍坦诚应答的思路
2. 对着自己简历上的每个项目，写下「我自己做的、有思考的点」分别是什么
3. 自问：如果面试官问「哪些是你自己做的」，我能不能不背文档地讲出来
4. 不追求项目高大上，只追求每个项目都能讲出自己的理解与创新
