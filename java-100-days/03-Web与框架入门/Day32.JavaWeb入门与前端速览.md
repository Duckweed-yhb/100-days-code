## 核心重点

- B/S 架构与 C/S 架构的区别
- HTTP 请求 / 响应的基本过程（浏览器 ↔ 服务器）
- Web 服务器（Tomcat）的作用初步认识
- HTML 基本结构：`html`、`head`、`body`
- 常用标签：标题、段落、列表、超链接、图片
- 表单标签：`form`、`input`、`button`，表单数据如何提交给后端
- CSS 基本选择器（标签、类、id）与常用样式属性
- 前端部分只做「看得懂」层面的速览，不深究
