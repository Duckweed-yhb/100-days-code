## 核心重点

- 远程仓库的作用：备份与多人协作
- 在 GitHub / Gitee 上新建一个空远程仓库
- `git remote add origin 地址` 关联远程仓库
- SSH key 的生成与添加到远程平台（免密推送）
- `git push -u origin master/main` 首次推送
- `git clone 地址` 克隆远程仓库到本地
- `git pull` 拉取远程最新代码
- 分支概念：`git branch` / `git checkout -b` / `git merge`

## 练习/任务

1. 在 GitHub（或 Gitee）上新建一个空仓库，把昨天的本地项目 push 上去
2. 在网页上直接改一行文件，再在本地 `git pull` 拉下来，观察远程修改如何同步到本地
3. 故意在本地和远程改同一个文件的同一行，`git pull` 制造冲突，手动编辑解决后再次 commit / push
4. 新建一个分支，在分支上改代码，合并回主分支，熟悉分支操作
5. **一定一定要动手实践**：远程推送、拉取、冲突解决都要真做一遍，不要跳过
