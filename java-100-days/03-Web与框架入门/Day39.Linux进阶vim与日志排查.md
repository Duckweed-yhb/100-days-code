## 核心重点

- vim 三种模式：普通模式、插入模式、命令行模式
- 基本操作：`i` 插入、`Esc` 退出插入、`:wq` 保存退出、`:q!` 不保存退出
- 光标移动：`gg` / `G` / `行号 gg`
- 日志常见位置：`/var/log/`、应用自己的 `logs/` 目录
- `tail -f xxx.log` 实时跟踪日志输出
- `tail -n 行数 xxx.log` 看末尾若干行
- `grep "关键字" xxx.log` 在日志里搜关键字
- 管道 `|`：把前一个命令的输出交给后一个命令处理，如 `ps -ef | grep java`
- `find / -name "文件名"` 在系统中找文件
- 压缩与下载：`tar`、`wget`、`curl` 基本用法

## 练习/任务

1. 用 vim 打开一个文件，输入一段文字，保存退出，再用 `cat` 看内容确认
2. 用 `:set nu` 显示行号，跳到指定行，练习 vim 基本编辑
3. 自己生成一个大日志文件（循环 echo 几千行），用 `tail -f` 跟踪，另开窗口往里写内容
4. 用 `grep` 在日志里搜一个错误关键字，再用管道组合 `grep | tail` 看最后几条错误
5. 用 `find` 在系统里找一个指定名字的文件
6. **一定一定要动手实践**：vim 和日志命令都要在真实机器上练熟
