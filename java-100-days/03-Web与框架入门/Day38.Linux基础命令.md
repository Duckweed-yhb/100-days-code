## 核心重点

- Linux 与 Windows 的区别：纯命令行、多用户、服务器主流系统
- 远程登录：`ssh 用户名@IP`
- 目录结构：`/` 根目录、`/root`、`/home`、`/etc`、`/usr`、`/var`
- 目录命令：`pwd`、`ls -l`、`cd`、`mkdir`
- 文件命令：`touch`、`cp`、`mv`、`rm`
- 查看文件：`cat`、`more`、`less`、`head`、`tail`
- 文件权限：`chmod`、`chown`，`rwx` 含义
- 进程与端口：`ps -ef`、`netstat -tlnp`、`kill`
- 系统信息：`df -h`、`free -h`、`top`

## 练习/任务

1. 本地装一个虚拟机（或用一台云服务器），用 `ssh` 登录进去
2. 在 `/home` 下建一个自己的目录，在里面新建 / 复制 / 移动 / 删除文件
3. 用 `ls -l` 看一个文件的权限，用 `chmod` 改一次权限
4. 用 `ps -ef | grep java` 查一下进程，用 `netstat` 看一下监听端口
5. **一定一定要动手实践**：以上每一条都要在真实 Linux 机器上敲一遍
