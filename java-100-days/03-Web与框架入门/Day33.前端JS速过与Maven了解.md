## 核心重点

- JS 基本语法：变量、数据类型、函数
- DOM 操作：通过 id / class 找到页面元素并修改内容
- 表单校验：提交前用 JS 检查输入是否合法
- Maven 是什么：项目构建与依赖管理工具
- `pom.xml` 的作用，`<groupId>` / `<artifactId>` / `<version>` 坐标
- 依赖的引入方式：在 `<dependencies>` 里写坐标
- Maven 仓库概念：本地仓库、中央仓库、镜像
- IDEA 中创建 Maven 项目、刷新依赖（reload）
