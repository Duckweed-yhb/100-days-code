# Day 86 · 双指针与前缀和

## 学习内容

### 双指针类型

1. **左右指针**：从两端向中间（反转数组、两数之和有序数组）
2. **快慢指针**：同起点不同速（移除元素、环检测）
3. **滑动窗口**：昨天学过

### 两数之和（有序数组）

数组已升序，找两个数和为 target：

```c
int left = 0, right = n - 1;
while (left < right) {
    int s = a[left] + a[right];
    if (s == target) return left, right;
    else if (s < target) left++;
    else right--;
}
```

O(n)，比哈希表还省空间。

### 三数之和

枚举第一个数，剩下两个用双指针。O(n²)。

### 前缀和

`prefix[i] = a[0] + ... + a[i-1]`。区间 [l, r) 和 = `prefix[r] - prefix[l]`。

```c
int prefix[N+1] = {0};
for (int i = 0; i < n; i++) prefix[i+1] = prefix[i] + a[i];

// 求 [l, r] 闭区间和：
int sum = prefix[r+1] - prefix[l];
```

预处理 O(n)，每次区间查询 O(1)。

### 差分数组

频繁给区间 [l, r] 加 v，最后求数组。差分数组 O(1) 区间修改。

## 核心重点
- 双指针：左右、快慢、窗口
- 有序数组两数之和 O(n)
- 前缀和 O(1) 区间和查询
- 差分数组 O(1) 区间修改
- 双指针+前缀和是数组题神器
