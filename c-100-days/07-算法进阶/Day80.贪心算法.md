# Day 80 · 贪心算法

## 今日目标
- 理解贪心思想
- 掌握常见贪心题

## 学习内容

### 贪心是什么

每一步都做当前看起来最好的选择，期望全局最优。不像 DP 考虑所有可能。

### 找零问题

用最少纸币数凑 amount，纸币面额 1、5、10、20。贪心：每次用最大面额。

```c
int bills[] = {20, 10, 5, 1};
int count = 0;
for (int i = 0; i < 4; i++) {
    count += amount / bills[i];
    amount %= bills[i];
}
```

对人民币面额成立。但如果面额是 1、3、4，凑 6，贪心会 4+1+1=3 张，最优是 3+3=2 张。**贪心不一定对！**

### 活动选择

n 个活动各有开始结束时间，同一时间只能参加一个，选最多活动。贪心：每次选结束最早的。

### 跳跃游戏

数组每个位置是最大跳跃长度，问能否到最后。贪心：维护最远能到哪。

```c
int max_reach = 0;
for (int i = 0; i < n; i++) {
    if (i > max_reach) return 0;
    max_reach = max(max_reach, i + nums[i]);
}
return 1;
```

### 贪心 vs DP

- 贪心：每步局部最优，O(n) 快，但要证明正确性
- DP：考虑所有情况，O(n²) 慢，但稳妥

拿不准时用 DP，别贪心想当然。

## 核心重点
- 贪心每步选当前最优
- 不是所有问题贪心都对
- 活动选择：选结束最早
- 跳跃游戏：维护最远可达
- 贪心要证明正确性，否则用 DP
