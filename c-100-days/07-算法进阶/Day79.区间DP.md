## 学习内容

### 区间 DP

状态是区间 `dp[i][j]`，表示子数组/子串 [i, j] 的最优解。从短区间推长区间。

典型题：矩阵链乘法、石子合并。

**石子合并**：把相邻两堆合并，代价等于两堆和，求最小总代价。

```c
// 枚举区间长度
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            dp[i][j] = min(dp[i][j],
                           dp[i][k] + dp[k+1][j] + sum(i,j));
        }
    }
}
```

### 状态压缩 DP

当 n 很小（≤20），用一个整数的二进制位表示"哪些已选"，作为 DP 的一维。

比如旅行商问题 TSP：`dp[mask][i]` 表示已访问集合 mask、当前在 i 的最小代价。今天建立概念即可。

### DP 题型总结

| 类型 | 状态 |
|---|---|
| 线性 DP | dp[i] |
| 二维 DP | dp[i][j] |
| 背包 | dp[j] 容量 |
| 区间 DP | dp[i][j] 区间 |
| 状态压缩 | dp[mask][...] |
| 树形 DP | dp[节点] |

## 核心重点
- 区间 DP：枚举长度、起点、断点
- 状态压缩用位掩码表示集合
- DP 题型很多，核心是状态+转移
- n 小考虑状态压缩
- 区间 DP O(n³)
