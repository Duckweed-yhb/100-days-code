## 学习内容

### 01 背包

n 个物品，每个有重量 w[i] 和价值 v[i]，背包容量 W，每个物品只能选一次，求最大价值。

状态 `dp[i][j]` = 前 i 个物品、容量 j 时的最大价值：

```
dp[i][j] = max(dp[i-1][j],           // 不选第 i 个
               dp[i-1][j-w[i]] + v[i]) // 选第 i 个
```

### 空间优化到一维

```c
int dp[W+1] = {0};
for (int i = 0; i < n; i++) {
    for (int j = W; j >= w[i]; j--) {   // 逆序！
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```

逆序是为了保证每个物品只用一次。

### 完全背包

物品可以无限次选。把内层循环改成正序：

```c
for (int i = 0; i < n; i++) {
    for (int j = w[i]; j <= W; j++) {   // 正序
        dp[j] = max(dp[j], dp[j-w[i]] + v[i]);
    }
}
```

### 01 vs 完全

| 问题 | 物品数 | 内层顺序 |
|---|---|---|
| 01 背包 | 每个一次 | 逆序 |
| 完全背包 | 无限次 | 正序 |

### 典型例题

- 分割等和子集：看能否装满 W/2
- 零钱兑换：最少硬币数凑 amount

## 核心重点
- 01 背包：dp[j] = max(dp[j], dp[j-w]+v)
- 01 背包一维优化要逆序遍历
- 完全背包正序遍历
- 背包是 DP 最经典模型
- 状态转移靠"选或不选"
