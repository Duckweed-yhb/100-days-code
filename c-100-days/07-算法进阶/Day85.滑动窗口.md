## 学习内容

### 什么是滑动窗口

维护一个窗口 [left, right]，right 右扩，满足条件时 left 右缩。所有操作 O(n)。

### 模板

```c
int left = 0;
for (int right = 0; right < n; right++) {
    // 把 right 加入窗口
    while (窗口满足收缩条件) {
        // 更新答案
        // 把 left 移出窗口
        left++;
    }
}
```

### 最小覆盖子串

给 S 和 T，找 S 中最短的包含 T 所有字符的子串。

思路：
- right 右移直到窗口包含所有 T 字符
- left 右缩直到不能再缩，更新答案
- 重复

### 长度最小的子数组

和 >= target 的最短连续子数组：

```c
int sum = 0, left = 0, ans = INT_MAX;
for (int right = 0; right < n; right++) {
    sum += a[right];
    while (sum >= target) {
        ans = min(ans, right - left + 1);
        sum -= a[left++];
    }
}
```

### 无重复字符的最长子串

窗口内字符不重复，重复就缩 left。

## 核心重点
- 滑动窗口 = 左右指针
- right 扩，left 缩
- 所有元素最多进/出窗口一次，O(n)
- 适合"连续子串/子数组"问题
- 模板背下来
