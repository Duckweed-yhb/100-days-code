## 学习内容

### 最大子数组和

给定数组，求连续子数组最大和。

状态：`dp[i]` = 以 i 结尾的最大和。

转移：要么接前面 `dp[i-1] + a[i]`，要么从 i 重新开始 `a[i]`：

```c
dp[i] = max(a[i], dp[i-1] + a[i]);
ans = max(dp[i])
```

O(n)。

### 最长上升子序列 LIS

求最长严格递增子序列长度（不要求连续）。

`dp[i]` = 以 i 结尾的 LIS 长度：

```c
for (int i = 0; i < n; i++) {
    dp[i] = 1;
    for (int j = 0; j < i; j++) {
        if (a[j] < a[i] && dp[j] + 1 > dp[i]) {
            dp[i] = dp[j] + 1;
        }
    }
}
```

O(n²)。（O(n log n) 版本用二分，后面学。）

### 最长公共子序列 LCS

两个序列求最长公共子序列。二维 DP：

```c
dp[i][j] = s1[i]==s2[j] ? dp[i-1][j-1]+1
                        : max(dp[i-1][j], dp[i][j-1])
```

### 线性 DP 特点

- 状态是一维或二维下标
- 转移从前面状态推过来
- 按顺序遍历

## 核心重点
- 最大子数组和：dp[i] = max(a[i], dp[i-1]+a[i])
- LIS：dp[i] 枚举前面所有更小元素
- LCS：二维 DP，相等则对角+1
- 状态定义要清晰
- 转移方程靠"最后一步怎么选"推导
