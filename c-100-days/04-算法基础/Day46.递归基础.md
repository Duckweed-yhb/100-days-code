## 学习内容

### 递归是什么

一个函数直接或间接调用自己，就是递归。递归的核心思想：**把大问题拆成同结构的小问题**。

### 递归三要素

1. **基线条件**：什么时候停止（最小子问题）
2. **递归条件**：怎么把大问题拆小
3. **返回值**：子问题的结果怎么组合成大问题的答案

### 阶乘

```c
int fact(int n) {
    if (n <= 1) return 1;        // 基线条件
    return n * fact(n - 1);      // 递归条件
}
```

fact(5) = 5 × fact(4) = 5 × 4 × fact(3) = ... = 5 × 4 × 3 × 2 × 1

### 斐波那契

```c
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

注意：朴素递归 Fibonacci 有大量重复计算，是 O(2ⁿ)。后面学动态规划会优化成 O(n)。

### 递归的执行栈

每次函数调用压栈一层，碰到基线条件后层层返回。递归深度太深会栈溢出。

### 递归 vs 迭代

递归代码简洁，但有函数调用开销。能写递归的都能改循环，反之亦然。树的遍历天然递归最简洁。

### 递归思维训练

写递归不要跳进细节，要相信"子问题已经解决"：
- 假设 `fact(n-1)` 已经正确返回 (n-1)!
- 那 `fact(n) = n × fact(n-1)` 就对了
- 再保证 n=1 时正确

这叫"递归思维"——不要人脑模拟调用栈。

## 核心重点
- 递归 = 自己调自己
- 三要素：基线条件、递归条件、返回值组合
- 基线条件必须有，否则无限递归栈溢出
- 递归代码简洁但有调用开销
- 相信子问题已解决，不要跳进细节
