## 学习内容

### 分治：快排的核心

选一个基准元素 pivot，把数组分成两半：左边都比 pivot 小，右边都比 pivot 大。然后递归排序左右两半。

### 实现

```c
void quick_sort(int *a, int left, int right) {
    if (left >= right) return;

    int pivot = a[left];     // 选最左元素作基准
    int i = left, j = right;

    while (i < j) {
        while (i < j && a[j] >= pivot) j--;
        a[i] = a[j];
        while (i < j && a[i] <= pivot) i++;
        a[j] = a[i];
    }
    a[i] = pivot;            // pivot 归位

    quick_sort(a, left, i - 1);
    quick_sort(a, i + 1, right);
}
```

调用：`quick_sort(a, 0, n-1);`

### 挖坑法解释

1. 把 `a[left]` 挖出来存到 pivot，位置空了
2. 从右往左找第一个比 pivot 小的，挖到左边空位
3. 从左往右找第一个比 pivot 大的，挖到右边空位
4. 相遇时把 pivot 放进去

### 复杂度

- 平均：O(n log n)，每层 O(n)，共 log n 层
- 最坏：每次 pivot 选得极差（如已有序时选最左），退化成 O(n²)

### 优化

- **随机选 pivot**：避免有序数组退化
- **三数取中**：选左、中、右三个值的中位数
- **小数组切换插入排序**：递归到长度 < 16 时用插入
- **三路快排**：处理大量重复元素时更快

### 三路快排思路

把数组分成 < pivot、= pivot、> pivot 三段。等于 pivot 的不用再递归，有大量重复元素时性能大幅提升。

## 核心重点
- 快排 = 选基准 + 分区 + 递归
- 平均 O(n log n)，最坏 O(n²)
- 挖坑法是经典分区写法
- 随机 pivot 避免退化
- 小数组切插入排序是标准优化
