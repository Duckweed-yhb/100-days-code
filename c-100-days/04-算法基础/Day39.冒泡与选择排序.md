## 学习内容

### 排序是算法入门的第一课

排序把杂乱数据变成有序，后续查找、去重、合并都会简单。工程中大量数据在进主算法前都要先排序。

### 冒泡排序

两两比较，大的往后冒：

```c
void bubble_sort(int *a, int n) {
    for (int i = 0; i < n - 1; i++) {
        int swapped = 0;
        for (int j = 0; j < n - 1 - i; j++) {
            if (a[j] > a[j+1]) {
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
                swapped = 1;
            }
        }
        if (!swapped) break;   // 一轮没交换说明已有序
    }
}
```

每轮把当前最大的"冒泡"到末尾。加 `swapped` 优化后，最好情况（已有序）O(n)，最坏 O(n²)。

### 选择排序

每轮选最小的放到前面：

```c
void select_sort(int *a, int n) {
    for (int i = 0; i < n - 1; i++) {
        int min_idx = i;
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[min_idx]) min_idx = j;
        }
        int t = a[i]; a[i] = a[min_idx]; a[min_idx] = t;
    }
}
```

### 对比

| 排序 | 最好 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 冒泡 | O(n) | O(n²) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 |

稳定排序：相等元素排序后相对顺序不变。冒泡稳定，选择不稳定（跳跃交换可能改顺序）。

### 什么时候用

这两种排序都是教学用，实际工程用快排或归并。但理解它们是理解更复杂排序的基础。

## 核心重点
- 冒泡：相邻比较，大的后移
- 选择：每轮选最小放前面
- 都是 O(n²)，小规模数据可用
- 冒泡加 swapped 提前退出可达 O(n)
- 稳定与不稳定是排序的重要性质
