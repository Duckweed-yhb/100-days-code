## 学习内容

### 堆是什么

堆是完全二叉树，分两种：
- 大顶堆：每个节点 >= 子节点，堆顶是最大值
- 小顶堆：每个节点 <= 子节点，堆顶是最小值

### 数组表示堆

完全二叉树可以存在数组里：节点 i 的左孩子是 `2i+1`，右孩子是 `2i+2`，父节点是 `(i-1)/2`。

### 上浮与下沉

插入新元素：放到末尾，上浮到合适位置。
删除堆顶：用末尾元素替换堆顶，下沉到合适位置。

### 堆排序

1. 把数组建造成大顶堆
2. 堆顶（最大值）与末尾交换
3. 剩余部分下沉调整
4. 重复

```c
void heapify(int *a, int n, int i) {
    int largest = i;
    int l = 2*i + 1, r = 2*i + 2;
    if (l < n && a[l] > a[largest]) largest = l;
    if (r < n && a[r] > a[largest]) largest = r;
    if (largest != i) {
        int t = a[i]; a[i] = a[largest]; a[largest] = t;
        heapify(a, n, largest);
    }
}

void heap_sort(int *a, int n) {
    // 建堆
    for (int i = n/2 - 1; i >= 0; i--) heapify(a, n, i);
    // 逐个取出
    for (int i = n - 1; i > 0; i--) {
        int t = a[0]; a[0] = a[i]; a[i] = t;
        heapify(a, i, 0);
    }
}
```

堆排序时间 O(n log n)，原地 O(1)，但不稳定。

### 计数排序

当数据范围不大时（如成绩 0~100），开一个计数数组数每个值出现几次，再按顺序输出：

```c
void count_sort(int *a, int n) {
    int count[101] = {0};
    for (int i = 0; i < n; i++) count[a[i]]++;
    int k = 0;
    for (int v = 0; v <= 100; v++) {
        for (int j = 0; j < count[v]; j++) {
            a[k++] = v;
        }
    }
}
```

时间 O(n + k)，k 是值域大小。数据范围小、整数、可预测时极快。

### 排序算法总结

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 冒泡 | n² | n² | 1 | 是 |
| 选择 | n² | n² | 1 | 否 |
| 插入 | n² | n² | 1 | 是 |
| 希尔 | n^1.3 | n² | 1 | 否 |
| 快排 | n log n | n² | log n | 否 |
| 归并 | n log n | n log n | n | 是 |
| 堆排 | n log n | n log n | 1 | 否 |
| 计数 | n+k | n+k | k | 是 |

## 核心重点
- 堆 = 完全二叉树 + 堆性质
- 堆排序 O(n log n) 原地但不稳定
- 计数排序适合小值域整数，O(n+k)
- 没有万能排序，按场景选
- 工程中 qsort 是快排+插入混合
