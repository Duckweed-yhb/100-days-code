# Day 40 · 插入排序与希尔

## 学习内容

### 插入排序

像打扑克牌：摸到一张新牌，插入到左手已经排好序的牌堆里。

```c
void insert_sort(int *a, int n) {
    for (int i = 1; i < n; i++) {
        int key = a[i];
        int j = i - 1;
        while (j >= 0 && a[j] > key) {
            a[j+1] = a[j];
            j--;
        }
        a[j+1] = key;
    }
}
```

### 复杂度分析

- 最坏（逆序）：每次都要挪全部，O(n²)
- 最好（已有序）：每次 while 一次不进，O(n)
- 平均：O(n²)

但实践中插入排序对**近乎有序**的数据非常快，比冒泡选择都快。这也是它被广泛作为高级排序小数组回退的原因。

### 插入 vs 冒泡 vs 选择

| 排序 | 最好 | 最坏 | 特点 |
|---|---|---|---|
| 冒泡 | O(n) | O(n²) | 代码最简单 |
| 选择 | O(n²) | O(n²) | 交换次数最少 |
| 插入 | O(n) | O(n²) | 近乎有序时最快 |

### 希尔排序

插入排序的改进：先分组，对每组插入排序，再逐步缩小分组间隔。让数据"宏观上有序"，最后再做一次完整插入排序就很快。

```c
void shell_sort(int *a, int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < n; i++) {
            int key = a[i];
            int j = i;
            while (j >= gap && a[j-gap] > key) {
                a[j] = a[j-gap];
                j -= gap;
            }
            a[j] = key;
        }
    }
}
```

希尔排序是第一批突破 O(n²) 的排序，平均 O(n^1.3) 左右（取决于间隔序列）。

### 实际工程

C 标准库 qsort 内部：大数组用快排，递归到小数组（元素 < 16）切换插入排序。这就是为什么要学"基础"排序。

## 核心重点
- 插入排序：每次把新元素插入已排好序的前缀
- 近乎有序时插入排序 O(n)
- 希尔排序通过分组突破 O(n²)
- 高级排序在小数组时回退到插入排序
- 插入排序稳定、代码简单
