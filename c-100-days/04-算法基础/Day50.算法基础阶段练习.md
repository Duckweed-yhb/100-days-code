## 学习内容

### 知识地图

```
排序
 ├─ O(n²)：冒泡、选择、插入
 ├─ O(n log n)：快排、归并、堆排
 └─ O(n+k)：计数排序
查找
 ├─ 顺序 O(n)
 └─ 二分 O(log n)，前提有序
递归/分治
 ├─ 基线条件 + 递归条件
 └─ 分解 → 解决 → 合并
回溯
 └─ 选择 → 递归 → 撤销，剪枝
```

### 综合练习 1：找缺失数字

数组 0~n 中少了一个数，找出来。思路：求和公式 n(n+1)/2 减去数组实际和，差值就是缺失数。O(n) 时间 O(1) 空间。

### 综合练习 2：合并区间

给定若干区间 [start, end]，合并重叠区间。思路：按 start 排序，遍历合并。O(n log n)。

### 综合练习 3：旋转数组

把数组右移 k 位。技巧：整体反转，前 k 个反转，后 n-k 个反转。三次反转 O(n)。

### 综合练习 4：子集 II（有重复元素）

数组有重复数字，输出所有不重复子集。思路：排序，同一层相同元素只取第一个，其余跳过。

## 核心重点
- 排序找 O(n log n)，查找二分 O(log n)
- 递归是分治和回溯的基础
- 回溯关键是决策树 + 剪枝
- 多刷题才能内化
- 算法没有银弹，靠熟练度
