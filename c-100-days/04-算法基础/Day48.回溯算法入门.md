## 学习内容

### 回溯是什么

回溯像走迷宫：每一步试一个方向，走不通就退回来换方向。本质是**暴力枚举的系统化方法**。

### 回溯模板

```c
void backtrack(路径, 选择列表) {
    if (满足结束条件) {
        记录结果;
        return;
    }
    for (选择 : 选择列表) {
        做选择;
        backtrack(路径, 选择列表);
        撤销选择;      // 回溯
    }
}
```

三要素：路径、选择列表、结束条件。

### 全排列

给定 [1,2,3]，输出所有排列：

```c
int path[10];
int used[10];
int result[6][10];
int result_cnt = 0;

void permute(int *a, int n, int depth) {
    if (depth == n) {
        for (int i = 0; i < n; i++) result[result_cnt][i] = path[i];
        result_cnt++;
        return;
    }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        used[i] = 1;
        path[depth] = a[i];
        permute(a, n, depth + 1);
        used[i] = 0;       // 撤销
    }
}
```

### 回溯 vs 分治

- 分治：子问题独立，合并结果
- 回溯：边走边试，撤销选择，枚举所有解

### 剪枝

如果提前知道某条路不可能有解，直接不往下走，叫剪枝。剪枝能大幅减少搜索量。

## 核心重点
- 回溯 = 试错 + 回退，系统化暴力枚举
- 模板：做选择 → 递归 → 撤销选择
- used 数组记录已选元素
- 剪枝优化搜索
- 全排列、子集、组合都是回溯
