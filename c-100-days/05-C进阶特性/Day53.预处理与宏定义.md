## 学习内容

### 预处理是什么

C 编译前有一个"预处理"步骤：把 # 开头的指令处理掉，文本替换后再编译。

### #define 宏常量

```c
#define PI 3.14159
#define MAX_SIZE 100
```

预处理时所有 `PI` 都被替换成 `3.14159`。注意末尾不要加分号。

### 带参宏

```c
#define SQUARE(x) ((x) * (x))
```

调用 `SQUARE(3+2)` 展开成 `((3+2)*(3+2)) = 25`。

**括号必须加够**：
- `#define SQUARE(x) x*x` 写 `SQUARE(3+2)` 会展开成 `3+2*3+2 = 11`，错！
- 正确做法是每个参数和整体都加括号。

### 宏 vs 函数

| 方面 | 宏 | 函数 |
|---|---|---|
| 处理阶段 | 预处理文本替换 | 编译后调用 |
| 类型检查 | 无 | 有 |
| 调试 | 困难 | 容易 |
| 速度 | 快（无调用开销） | 有调用开销 |

小而频繁的操作用宏（或 inline 函数）。

### #include

```c
#include <stdio.h>   // 标准库，尖括号
#include "myheader.h" // 自己写的头文件，双引号
```

尖括号在系统路径找，双引号先在当前目录找。

### 头文件卫士

防止头文件被重复包含：

```c
#ifndef MYHEADER_H
#define MYHEADER_H

// 头文件内容

#endif
```

或更现代的写法：`#pragma once`（大多数编译器支持）。

### 常见预处理宏

```c
__FILE__    // 当前文件名
__LINE__    // 当前行号
__DATE__    // 编译日期
__TIME__    // 编译时间
```

可以用来打调试日志。

## 核心重点
- #define 是文本替换，不是语句
- 带参宏每个参数和整体都要加括号
- 宏无类型检查，速度快但不安全
- 头文件卫士防止重复包含
- 标准库用 <>，自己写用 ""
