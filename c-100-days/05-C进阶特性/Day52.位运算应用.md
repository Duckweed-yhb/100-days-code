## 学习内容

### 经典技巧：n & (n-1)

`n & (n-1)` 会把 n 最低位的 1 变成 0：

```c
n     = 0b10100
n-1   = 0b10011
n&(n-1)= 0b10000
```

应用：
- 数 n 中有几个 1：不断 `n &= n-1`，数几次变 0
- 判断 n 是否 2 的幂：n > 0 且 `n & (n-1) == 0`

### 不用加减乘除做加法

```c
int add(int a, int b) {
    while (b != 0) {
        int sum = a ^ b;          // 不进位加
        int carry = (a & b) << 1; // 进位
        a = sum;
        b = carry;
    }
    return a;
}
```

异或是不进位加法，与后左移一位是进位。

### 找出现一次的数

数组里所有数都出现两次，只有一个出现一次，找出来：

```c
int single_num = 0;
for (int i = 0; i < n; i++) single_num ^= a[i];
```

因为 `x ^ x = 0`，`x ^ 0 = x`，成对的都抵消了。

### 位域

结构体里可以按位指定成员宽度：

```c
struct Flags {
    unsigned int ready  : 1;
    unsigned int error  : 1;
    unsigned int mode   : 2;
};
```

总共只占 4 位。适合硬件寄存器、紧凑协议。但位域跨平台移植性一般。

### 掩码

```c
#define LOW8(x)  ((x) & 0xFF)
#define HIGH8(x) (((x) >> 8) & 0xFF)
```

从一个 32 位数中取出某几个字节。

## 核心重点
- n & (n-1) 消最低位 1
- 异或抵消成对元素，找单身数
- 位运算加法：异或 + 进位
- 位域节省内存但移植性差
- 掩码用于提取特定位段
