## 学习内容

### 位运算是什么

C 可以直接操作整数的每一个二进制位。这在嵌入式、驱动、性能优化中必不可少。

### 六个位运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `&` | 按位与 | 两位都 1 才 1 |
| `\|` | 按位或 | 有一位 1 就 1 |
| `^` | 按位异或 | 两位不同为 1 |
| `~` | 按位取反 | 0 变 1，1 变 0 |
| `<<` | 左移 | 左移 n 位 = ×2ⁿ |
| `>>` | 右移 | 右移 n 位 = /2ⁿ |

### 例子

```c
unsigned char a = 0b1100;   // 12
unsigned char b = 0b1010;   // 10

a & b;    // 0b1000 = 8
a | b;    // 0b1110 = 14
a ^ b;    // 0b0110 = 6
~a;       // 按位取反
a << 1;   // 0b11000 = 24（×2）
a >> 1;   // 0b0110 = 6（/2）
```

### 常用技巧

**判断奇偶**：`n & 1` 为 1 是奇数，为 0 是偶数。

**乘除 2 的幂**：`n << k` 等于 `n * 2^k`，`n >> k` 等于 `n / 2^k`。比乘除快。

**交换两数不用临时变量**：
```c
a ^= b;
b ^= a;
a ^= b;
```

### 标志位操作

位运算最常见的应用：用一个整数的不同位表示开关。

```c
// 打开第 k 位
flags |= (1 << k);

// 关闭第 k 位
flags &= ~(1 << k);

// 翻转第 k 位
flags ^= (1 << k);

// 检查第 k 位是否为 1
if (flags & (1 << k)) { ... }
```

Linux 系统调用的权限位就是这么存的。

## 核心重点
- 六个位运算符 & | ^ ~ << >>
- 左移 ×2，右移 /2
- `& 1` 判断奇偶
- `|=` 置位、`&=~` 清位、`^=` 翻转
- 标志位是位运算最常见应用
