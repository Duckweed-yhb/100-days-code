## 学习内容

### 文件指针

C 用 `FILE*` 表示打开的文件。FILE 是 stdio.h 定义的结构体，内部缓冲、状态都封装好了。

### 打开文件

```c
#include <stdio.h>

FILE *fp = fopen("test.txt", "r");
if (fp == NULL) {
    perror("打开失败");
    return 1;
}
// 操作文件...
fclose(fp);
```

### 打开模式

| 模式 | 含义 |
|---|---|
| `"r"` | 只读，文件必须存在 |
| `"w"` | 写，文件不存在则创建，存在则清空 |
| `"a"` | 追加，写到末尾 |
| `"r+"` | 读写，文件必须存在 |
| `"w+"` | 读写，清空原内容 |
| `"b"` | 二进制模式，如 `"rb"`、`"wb"` |

### fopen 失败返回 NULL

常见原因：文件不存在（用 "r" 打开不存在文件）、路径错、权限不够。**必须检查返回值**。

### fclose

用完一定要 fclose，否则缓冲里的数据可能没真正写盘。程序退出时系统会自动关，但长运行程序必须手动关。

### perror

`perror("msg")` 会打印 msg 加上系统错误原因，非常有用：

```
打开失败: No such file or directory
```

### 标准流

程序启动时自动打开三个文件：
- `stdin`：标准输入（键盘）
- `stdout`：标准输出（屏幕）
- `stderr`：标准错误（屏幕，不带缓冲）

## 核心重点
- FILE* 表示打开的文件
- fopen 打开，fclose 关闭
- 打开模式 r/w/a/r+/w+，b 表示二进制
- fopen 失败返回 NULL，必须检查
- perror 打印系统错误
