## 学习内容

### 二级指针

指针本身也是变量，也要存在内存里，也有地址。指向指针的指针就是二级指针：

```c
int x = 42;
int *p = &x;       // p 指向 x
int **pp = &p;     // pp 指向 p

printf("%d\n", **pp);   // 42：先 *pp 得到 p，再 *p 得到 x
```

图解：

```
pp → p → x = 42
```

`*pp` 是 p 本身，`**pp` 是 x。

### 什么时候需要二级指针

主要场景：函数里要修改调用者的指针变量本身。比如动态分配内存并通过参数带回：

```c
void alloc_buffer(char **p, int size) {
    *p = malloc(size);   // 修改调用者的指针
}
```

### 指针数组

数组里每个元素都是指针：

```c
const char *names[] = {
    "张三", "李四", "王五", "赵六"
};
int n = 4;
for (int i = 0; i < n; i++) {
    printf("%s\n", names[i]);
}
```

`names[i]` 是一个 `const char *`，指向一个字符串字面值。这是 C 里表示"字符串数组"的标准方式。

### 指针数组 vs 二维字符数组

```c
// 方式一：指针数组（每行长度可变）
const char *a[] = {"Hi", "Hello", "你好"};

// 方式二：二维数组（每行定长）
char b[][20] = {"Hi", "Hello", "你好"};
```

| 方式 | 优点 | 缺点 |
|---|---|---|
| 指针数组 | 每行长度灵活、省空间 | 间接寻址稍慢 |
| 二维数组 | 连续内存、访问快 | 每行都要按最长行分配 |

### 命令行参数 argc/argv

`main` 的完整形式就是用指针数组接收命令行参数：

```c
int main(int argc, char *argv[]) {
    for (int i = 0; i < argc; i++) {
        printf("argv[%d] = %s\n", i, argv[i]);
    }
    return 0;
}
```

运行 `./a.out hello world`：

```
argv[0] = ./a.out
argv[1] = hello
argv[2] = world
```

### 函数指针初印象（预告）

Day55 会深入，今天先知道有 `void (*func)(int)` 这种"指向函数的指针"，和数据指针是两码事。

## 核心重点
- 二级指针 `T **p` 指向一个 `T *` 变量
- 指针数组常用于表示字符串数组
- 指针数组每行长度灵活，二维数组每行定长
- `main(int argc, char *argv[])` 就是指针数组的实际应用
- 二级指针主要用于函数内修改调用者的指针
