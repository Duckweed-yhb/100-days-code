# Day 14 · 指针入门与地址运算

## 今日目标

## 学习内容

### 内存地址概念

内存像一排编号的小格子，每个格子有一个编号（地址）。变量名对应某个格子，通过格子编号就能找到那个变量。指针就是"存放地址的变量"。

### 声明指针

```c
int  x = 42;
int *p = &x;      // p 是一个指针，保存 x 的地址
```

读法：`int *p` 读作"p 是指向 int 的指针"。`*` 在声明时表示"这是指针"。

### 两个核心运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `&` | 取变量的地址 | `&x` 得到 x 的内存地址 |
| `*` | 解引用，访问地址上的值 | `*p` 就是 p 指向的那个变量 |

```c
int x = 42;
int *p = &x;

printf("%p\n", (void*)p);   // 打印 p 里存的地址
printf("%d\n", *p);         // 42，通过指针读 x
*p = 100;                   // 通过指针改 x
printf("%d\n", x);          // 100！x 被间接修改了
```

### 指针类型的意义

`int *p` 和 `double *q` 虽然存的都是地址，但类型不同：
- `*p = 5` 会写 4 字节（int 的大小）
- `*q = 3.14` 会写 8 字节（double 的大小）

类型告诉编译器"通过这个地址读写几个字节、怎么解释"。**不同类型的指针不要乱转**，除非你非常清楚在做什么。

### 指针占多大

指针本身也是变量，也要占内存。在 64 位系统上，任何类型的指针都是 8 字节（因为地址是 64 位）。

```c
printf("%zu\n", sizeof(int*));     // 8
printf("%zu\n", sizeof(double*));  // 8
```

### 空指针

```c
int *p = NULL;    // 不指向任何有效地址
```

`NULL` 是标准宏，值为 0。**绝不能解引用 NULL**：`*p` 会让程序立刻崩溃（段错误）。使用指针前判断一下：

```c
if (p != NULL) {
    *p = 10;
}
```

### 指针的指针（预告）

```c
int x = 42;
int *p = &x;
int **pp = &p;    // pp 指向 p
```

## 核心重点
- 指针就是存放内存地址的变量
- `&` 取地址，`*` 解引用（通过地址访问变量）
- 指针类型决定解引用时读写几个字节
- 64 位系统上指针本身占 8 字节
- `NULL` 是空指针，永远不要解引用它
