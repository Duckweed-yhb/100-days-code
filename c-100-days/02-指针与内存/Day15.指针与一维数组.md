# Day 15 · 指针与一维数组

## 今日目标
- 理解数组名与数组首元素地址的关系
- 掌握指针算术：`p+1`、`p++` 的含义
- 能用指针遍历数组

## 学习内容

### 数组名就是首元素地址

```c
int a[5] = {10, 20, 30, 40, 50};
printf("%p\n", (void*)a);      // a 的值 = &a[0]
printf("%p\n", (void*)&a[0]);  // 一样
```

在大多数表达式中，数组名会"退化"为指向首元素的指针。

### 指针算术

指针加减一个整数，不是加数字，而是**按类型大小步进**：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;       // p 指向 a[0]

p++;              // p 指向 a[1]，地址 +4（int 是4字节）
printf("%d\n", *p);   // 20

p += 2;           // p 指向 a[3]
printf("%d\n", *p);   // 40

p--;              // 回到 a[2]
```

### 下标访问与指针访问等价

```c
a[i] 等价于  *(a + i)
```

也就是说 `a[2]` 和 `*(a+2)` 完全是一回事。甚至可以反过来写 `p[3]`，只要 p 指向数组。

### 用指针遍历数组

```c
int a[5] = {1, 2, 3, 4, 5};
int *p;
for (p = a; p < a + 5; p++) {
    printf("%d ", *p);
}
```

`p` 从 `a`（首地址）开始，每次 `p++` 指向下一个元素，直到 `p == a+5` 停止。

### 两个指针相减

```c
int *p = &a[1];
int *q = &a[4];
printf("%ld\n", q - p);   // 3，中间隔了3个元素
```

两个同类型指针相减，得到的是"之间隔了几个元素"，不是字节数。

### 数组名是常量指针

数组名虽然像指针，但它是**常量**，不能 `a++`、不能 `a = p`。因为数组在内存里的位置是编译时确定的，不能被重新赋值。

### 函数参数中的数组

```c
void func(int a[], int n);
// 等价于
void func(int *a, int n);
```

写 `int a[]` 和写 `int *a` 完全一样，都是指针。这就是为什么函数内 `sizeof(a)` 是 8 字节（指针大小）。

## 核心重点
- 数组名在表达式中退化为首元素地址
- `p+1` 不是地址加 1 字节，而是指向下一个同类型元素
- `a[i]` 等价于 `*(a+i)`
- 数组名是常量，不能自增自减或重新赋值
- 函数参数 `int a[]` 本质就是 `int *a`
