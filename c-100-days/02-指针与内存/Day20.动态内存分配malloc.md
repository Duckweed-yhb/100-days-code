# Day 20 · 动态内存分配malloc

## 今日目标
- 理解栈与堆的区别
- 掌握 `malloc`、`free` 的基本用法
- 能在运行时决定数组大小

## 学习内容

### 为什么需要动态内存

前面用数组时，大小必须在编译时确定（或至少声明时写死）：

```c
int arr[100];    // 固定100个，用不满浪费，用不下溢出
```

但实际场景往往是"运行时才知道要多少"。比如读用户输入 n 个数，n 要等运行时输入。这时就要用堆上动态分配的内存。

### malloc 与 free

```c
#include <stdlib.h>

int *p = malloc(10 * sizeof(int));   // 要 10 个 int 的空间
if (p == NULL) {
    printf("分配失败\n");
    return 1;
}

// 使用 p[0] ~ p[9]
p[0] = 42;

free(p);     // 用完归还！
p = NULL;    // 好习惯：置空，防止野指针
```

- `malloc(字节数)` 在堆上分配内存，返回首地址
- 分配失败返回 `NULL`，必须检查
- `free(p)` 释放这块内存，归还给系统
- `sizeof(int)` 让代码跨平台可移植，不要写死 `4`

### 栈 vs 堆

| 特性 | 栈 | 堆 |
|---|---|---|
| 大小 | 小（通常 1~8MB） | 大（受系统限制） |
| 生命周期 | 函数返回自动释放 | 程序员手动 free |
| 分配速度 | 极快 | 较慢 |
| 碎片 | 无 | 可能产生 |
| 典型用途 | 局部变量 | 动态数组、链表、树 |

### 动态数组

```c
int n;
scanf("%d", &n);
int *arr = malloc(n * sizeof(int));

for (int i = 0; i < n; i++) {
    arr[i] = i * i;
}

for (int i = 0; i < n; i++) {
    printf("%d ", arr[i]);
}

free(arr);
```

这就是 C99 之前"变长数组"的标准做法。（C99 也有 VLA，但不如 malloc 灵活。）

### 必须 free 的原因

程序退出时操作系统会回收所有内存，但作为好习惯：
- 长运行程序（服务器）不 free 会内存泄漏，越吃越多
- 让代码意图清晰

### 配对原则

`malloc` 与 `free` 必须成对：
- 同一块内存只能 free 一次（free 两次是未定义行为）
- 不能 free 不是 malloc 返回的指针
- free 之后不要继续使用这块内存（野指针）

## 核心重点
- 栈上数组大小编译时确定，堆上 malloc 运行时决定
- `malloc(n * sizeof(type))` 分配，返回指针要检查 NULL
- `free(p)` 手动释放，释放后 p 置空
- 栈自动回收，堆手动管理
- malloc/free 必须配对，不能重复 free
