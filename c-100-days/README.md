# C - 100天从新手到大师

> 一套自编原创的 C 语言学习路线，从环境搭建到系统编程与综合项目，共 100 天。建议节奏：工作日每天 1~1.5 小时，先读"学习内容"再动手写代码；周末复盘本周内容并做阶段小项目。

## 为什么学 C

C 语言是操作系统、嵌入式、数据库、编译器等底层领域的事实标准，也是理解计算机如何工作的最佳语言。它不会用魔法帮你隐藏细节——指针、内存、编译链接全部暴露在你面前。学会 C，再学任何语言都降维打击；不学会 C，写任何上层语言都像隔靴搔痒。

本路线只讲 C99/C11 标准与标准库（stdio/stdlib/string/ctype/math/time 等），多线程用 POSIX pthread、网络用 POSIX socket（标注 POSIX/类 Unix 环境，Windows 可用 WSL 实验），不涉及未进标准的编译器扩展。

## 怎么用

1. 每天打开对应 Day 文件，先读"今日目标"明确要学什么。
2. 仔细看"学习内容"，所有示例代码亲手敲一遍，不要复制粘贴。
3. 对照"核心重点"检查是否真的理解。
4. 完成"练习/任务"，至少做前两题。
5. Day25 起，做"今日刷题"里的 LeetCode 题。
6. 做完后在"打卡清单"勾选。
7. 每阶段最后一天是阶段项目/复盘，务必停下来动手做。

## 目录约定

- 根目录下有 8 个阶段文件夹，命名格式为 `NN-主题`，例如 `01-C语言基础`。
- 每个阶段文件夹内是该阶段的 Day 文件，命名格式为 `DayNN.主题.md`，其中 `NN` 是两位数字（01~100），例如 `Day01.认识C语言与环境安装.md`。
- 每个 Day 文件固定包含六小节：`今日目标`、`学习内容`、`核心重点`、`练习/任务`、`今日刷题`（Day25 起）、`打卡清单`。
- 根目录只放本 README.md，不放具体知识点。

## 学习建议

- **动手 > 阅读**：C 是写出来的，不是看出来的。每天代码量不少于 50 行。
- **报错是朋友**：编译器的警告和错误认真读，不要忽略。
- **小步快跑**：不要一天学十天的量，每天坚持比突击重要。
- **回头复习**：周末把本周写的代码重写一遍，不看答案。
- **工具链**：推荐 gcc + VS Code，调试用 gdb 或 VS Code 图形化调试。
