## 学习内容

### 树是什么

树是层次结构，一对一变成一对多。像倒过来的真实树：根在上，叶在下。

### 术语

```
        A          ← 根节点
       / \
      B   C        ← B、C 是 A 的子节点
     / \   \
    D   E   F      ← D、E、F 是叶子（没有子节点）
```

- **根**：最顶端节点（A）
- **叶子**：没有子节点的节点（D、E、F）
- **父节点/子节点**：B 是 D 的父节点，D 是 B 的子节点
- **深度**：从根到某节点经过的边数
- **高度**：从某节点到叶子最长路径的边数
- **子树**：任意节点和它的后代组成的树

### 二叉树

每个节点最多两个孩子（左孩子、右孩子），叫二叉树。

特殊二叉树：
- **满二叉树**：每层都满
- **完全二叉树**：除最后一层外都满，最后一层靠左连续
- **二叉搜索树 BST**：左子树所有值 < 根 < 右子树所有值

### 为什么树重要

- 文件系统就是树（盘符/文件夹/文件）
- 数据库索引用 B+ 树
- 二叉搜索树让查找插入都是 O(log n)
- 堆是完全二叉树
- 机器学习决策树

### 树 vs 线性结构

数组、链表、栈、队列都是线性的，只有前后关系。树是分支的，一个节点可以连多个后代，表达"层次"和"分类"。

## 核心重点
- 树是层次结构，根在上叶在下
- 二叉树每节点最多两个孩子
- 深度从上往下数，高度从下往上数
- 完全二叉树适合数组存储
- BST 是后面算法的核心结构
