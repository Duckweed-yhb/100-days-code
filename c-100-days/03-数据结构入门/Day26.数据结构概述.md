# Day 26 · 数据结构概述

## 今日目标

- 建立"数组 vs 链表"的直觉

## 学习内容

### 什么是数据结构

数据结构是**数据的组织方式**。同样一组数字，存在数组里、链表上、二叉树中，操作效率天差地别。选对数据结构，问题解决一半。

### 逻辑结构

描述数据之间的逻辑关系：

| 结构 | 例子 |
|---|---|
| 集合 | 无序、无关系 |
| 线性结构 | 数组、链表、栈、队列（一对一） |
| 树形结构 | 二叉树（一对多） |
| 图结构 | 地图（多对多） |

### 物理结构

描述数据在内存里怎么存：

- **顺序存储**：数组，连续内存，随机访问 O(1)
- **链式存储**：链表，散布内存，靠指针串联，插入删除 O(1)

### 数组 vs 链表

| 操作 | 数组 | 链表 |
|---|---|---|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 中间插入 | O(n) | O(1)（已知位置） |
| 内存 | 连续、缓存友好 | 散落、有指针开销 |

没有"最好"的结构，只有"最适合当前操作"的结构。

### 抽象数据类型（ADT）

ADT 只定义"能做什么"，不关心"怎么做"。比如栈定义为"后进先出"，至于底层用数组还是链表实现，使用者不管。

后面我们学的栈、队列、树、图，都是 ADT，各有至少两种实现方式。

### 算法与数据结构的关系

算法 + 数据结构 = 程序（Wirth 名言）。数据结构是静态的骨架，算法是动态的操作。学完数据结构，明天开始逐个实现。

## 核心重点
- 数据结构 = 数据的组织方式
- 逻辑结构：线性、树、图；物理结构：顺序、链式
- 数组随机访问快，链表插入删除快
- ADT 分离"做什么"和"怎么做"
- 选数据结构要匹配主要操作
