## 学习内容

### 知识地图回顾

```
线性结构
 ├─ 数组：连续内存，随机访问 O(1)
 ├─ 链表：动态节点，插入删除 O(1)
 ├─ 栈：LIFO，括号匹配、DFS
 └─ 队列：FIFO，BFS
层次结构
 └─ 树：二叉树、BST，递归遍历
图结构
 ├─ 邻接矩阵/邻接表
 ├─ DFS / BFS
哈希
 └─ 哈希表 O(1) 查找
```

### 综合题 1：用栈判断出栈序列

入栈顺序 1,2,3,4,5，问某个出栈序列是否合法（经典题）。思路：用一个辅助栈模拟，按入栈顺序压栈，栈顶等于期望出栈就弹。

### 综合题 2：二叉树层序打印每层

用队列层序遍历，但每层单独打印一行。技巧：每轮记录当前队列大小，那个大小就是当前层的节点数。

### 综合题 3：LRU 缓存（思路）

LRU = 最近最少使用淘汰。需要：
- 哈希表 O(1) 找节点
- 双向链表 O(1) 移动/删除节点
两者结合就是 Day28 说的"双向链表 + 哈希表"。今天只理解思路，不要求写完整代码。

### 综合题 4：图的 BFS 最短路

无权图从 start 到 end 的最短边数，BFS 第一次到达 end 时的距离就是答案。

### 选数据结构的思考框架

拿到问题先问：
1. 主要操作是查、插、删还是遍历？
2. 数据量多大？
3. 需要保序吗？
4. key 是整数还是字符串？

| 操作特征 | 选什么 |
|---|---|
| 按下标随机访问 | 数组 |
| 频繁中间插入删除 | 链表 |
| LIFO | 栈 |
| FIFO | 队列 |
| 按 key 快速查 | 哈希表 |
| 有序遍历 | BST |
| 层次/网络关系 | 图 |

## 核心重点
- 数据结构没有银弹，匹配操作才是王道
- 栈 DFS、队列 BFS 是通用范式
- 哈希表 + 双向链表 = LRU
- 多结构组合解决复杂问题
- 先想清楚操作特征再选结构
