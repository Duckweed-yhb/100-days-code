# Day 34 · 图的基本概念

## 今日目标

- 掌握有向图/无向图、权值、度等概念
- 学会邻接矩阵与邻接表两种存储

## 学习内容

### 图是什么

图 G = (V, E)，V 是顶点集合，E 是边集合。图比树更一般：任意两个顶点之间都可能有边。

### 基本术语

- **无向图**：边没有方向（A-B 等价于 B-A）
- **有向图**：边有方向（A→B 不等价于 B→A）
- **权值**：边上可以带数字，表示距离、费用等
- **度**：无向图中顶点连了几条边；有向图分入度和出度
- **路径**：从一个顶点沿着边走到另一个顶点
- **连通图**：任意两点之间都有路径

### 现实中的图

- 地图：顶点是城市，边是公路
- 社交网络：顶点是人，边是好友关系
- 网页链接：顶点是网页，边是超链接

### 存储方式 1：邻接矩阵

用 `adj[i][j] = 1` 表示 i 和 j 之间有边：

```c
#define N 100
int adj[N][N];

// 添加边
void add_edge(int u, int v) {
    adj[u][v] = 1;
    adj[v][u] = 1;   // 无向图对称
}
```

优点：判断两顶点是否相邻 O(1)。缺点：顶点多但边少时（稀疏图）浪费内存，空间 O(V²)。

### 存储方式 2：邻接表

每个顶点维护一个链表，存它的所有邻居：

```c
typedef struct Edge {
    int to;
    int weight;
    struct Edge *next;
} Edge;

Edge *graph[N];   // graph[i] 是 i 的邻居链表头

void add_edge(int u, int v, int w) {
    Edge *e = malloc(sizeof(Edge));
    e->to = v; e->weight = w;
    e->next = graph[u];
    graph[u] = e;
}
```

优点：稀疏图省空间，遍历邻居快。缺点：判断 i、j 是否相邻要遍历 i 的链表。

### 怎么选

- 稠密图（边多）：邻接矩阵
- 稀疏图（边少）：邻接表
- 实际工程中邻接表更常用

## 核心重点
- 图 = 顶点 + 边，比树更一般
- 有向/无向、度、路径、连通是基本术语
- 邻接矩阵空间 O(V²)，适合稠密图
- 邻接表空间 O(V+E)，适合稀疏图
- 地图、社交网络、网页都是图
