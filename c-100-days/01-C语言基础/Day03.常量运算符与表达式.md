# Day 03 · 常量运算符与表达式

## 今日目标
- 掌握字面常量、`#define` 宏常量与 `const` 常量的区别
- 熟练使用算术、赋值、关系、逻辑运算符
- 理解运算符优先级与结合性对表达式的影响

## 学习内容

### 常量的三种写法

```c
#define PI 3.14159          // 宏常量：预处理时直接文本替换
const double g = 9.8;       // const 常量：类型安全，不可修改
```

| 方式 | 特点 |
|---|---|
| 字面量 `3.14` | 直接写在代码里，无名字 |
| `#define PI 3.14` | 预处理替换，不做类型检查，无作用域限制 |
| `const double g = 9.8` | 有类型、有作用域、占内存，推荐用于有类型要求的常量 |

### 算术运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `+` `-` `*` `/` | 加减乘除 | `7 / 2` 结果是 `3`（整数除法截断） |
| `%` | 取余（取模） | `7 % 2` 结果是 `1` |
| `++` `--` | 自增自减 | `i++` 先用再加，`++i` 先加再用 |

整数除法是初学者最常踩的坑：`5 / 2` 得 `2` 而不是 `2.5`。要得到小数，至少有一个操作数是浮点型：`5.0 / 2` 得 `2.5`。

### 赋值与复合赋值

```c
int x = 10;
x += 5;    // 等价 x = x + 5;
x -= 3;    // x = x - 3;
x *= 2;    // x = x * 2;
x /= 4;
x %= 3;
```

### 关系与逻辑运算符

关系运算结果是"真"（值为 1）或"假"（值为 0）：

| 运算符 | 含义 |
|---|---|
| `==` | 等于（注意不是一个等号） |
| `!=` | 不等于 |
| `>` `<` `>=` `<=` | 大小比较 |
| `&&` | 逻辑与（两边都真才真） |
| `\|\|` | 逻辑或（一边真就真） |
| `!` | 逻辑非 |

C 语言中"非零即真"：`if (5)` 条件成立，因为 5 不是 0。

### 运算符优先级（常用）

优先级从高到低（只列最常用的）：

1. 括号 `()`
2. 单目 `!` `-` `++` `--`
3. 乘除取余 `*` `/` `%`
4. 加减 `+` `-`
5. 关系 `>` `<` `>=` `<=`
6. 相等 `==` `!=`
7. 逻辑与 `&&`
8. 逻辑或 `||`
9. 赋值 `= += -=`

拿不准优先级时，**加括号**永远是最安全的做法。

### 逗号运算符与表达式语句

逗号 `,` 可以把多个表达式串起来，整个逗号表达式的值是最右边那个。实际开发中逗号多用于 `for` 循环内，不建议滥用。

## 核心重点
- 常量推荐用 `const`，`#define` 用于无类型的文本替换
- 整数除法截断：`7 / 2 == 3`，想得到小数要用浮点
- `==` 是比较，`=` 是赋值，新手极易混淆
- 逻辑运算 `&&` `||` 具有短路求值特性
- 优先级不确定就加括号，不要背表
