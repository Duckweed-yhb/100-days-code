# Day 06 · 循环结构for与while

## 今日目标
- 掌握 `while`、`do-while`、`for` 三种循环
- 理解循环三要素：初始化、条件判断、更新
- 能编写累加、计数、找规律等常见循环程序

## 学习内容

### while 循环

```c
int i = 1;
int sum = 0;
while (i <= 100) {
    sum += i;
    i++;
}
// sum = 5050
```

`while` 先判断条件，条件为真才执行循环体。如果一开始条件就为假，循环体一次都不执行。

### do-while 循环

```c
int n;
do {
    printf("请输入一个正数: ");
    scanf("%d", &n);
} while (n <= 0);
```

`do-while` 先执行一次循环体再判断条件，所以至少执行一次。适合"先做再判断"的场景，比如要求用户输入合法值。

### for 循环

```c
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
```

`for` 把三要素写在一行：`for (初始化; 条件; 更新)`。最适合已知循环次数的场景。

C99 允许在 `for` 括号内定义变量 `int i`，该变量只在循环内有效。

### 三种循环怎么选

| 场景 | 推荐 |
|---|---|
| 已知循环次数 | `for` |
| 未知次数，靠条件退出 | `while` |
| 至少执行一次 | `do-while` |

### 累加与累乘模板

```c
// 求 1+2+...+n
int n, sum = 0;
scanf("%d", &n);
for (int i = 1; i <= n; i++) {
    sum += i;
}

// 求 n!
int n; long long fact = 1;
scanf("%d", &n);
for (int i = 1; i <= n; i++) {
    fact *= i;
}
```

### 死循环

```c
while (1) { ... }
for (;;) { ... }
```

死循环不是错误，事件服务器、游戏主循环都靠它。但要确保循环体内有退出手段（`break` 或 `return`），否则程序永远不会停。

### 常见错误

- 循环条件写成 `i = 100`（赋值）而非 `i == 100`（比较），导致死循环
- 循环体内忘记 `i++`，同样死循环
- 累加变量忘记初始化为 0，累乘忘记初始化为 1
- 边界写错：`i <= n` 写成 `i < n`，少算一次

## 核心重点
- while 先判断后执行，do-while 先执行后判断，for 适合已知次数
- 累加器初值为 0，累乘器初值为 1
- for 三要素：初始化、条件、更新，缺一不可
- 注意边界条件 `<` 与 `<=` 的区别
- 死循环要有退出机制
