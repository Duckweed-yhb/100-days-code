# Day 10 · 作用域与存储类型

## 今日目标
- 区分局部变量与全局变量
- 理解 `auto`、`static`、`extern` 的含义
- 知道变量的生命周期与可见性

## 学习内容

### 局部变量

在函数内部声明的变量叫局部变量：

```c
void func(void) {
    int x = 10;       // 局部变量，只在 func 内有效
    printf("%d\n", x);
}

int main(void) {
    func();
    // printf("%d\n", x);   // 错误！main 看不到 func 里的 x
    return 0;
}
```

局部变量在函数调用时创建，函数返回时销毁。不同函数可以使用同名变量，互不干扰。

### 全局变量

在所有函数外部声明的变量叫全局变量：

```c
int g_count = 0;       // 全局变量

void func(void) {
    g_count++;
}

int main(void) {
    func();
    printf("%d\n", g_count);   // 1
    return 0;
}
```

全局变量在程序整个运行期间都存在，所有函数都能访问。**但全局变量能少用就少用**：它让函数之间产生隐式耦合，谁都能改，出了 bug 很难查。

### 块级作用域

C99 允许在任何 `{}` 块内声明变量：

```c
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        // i 和 j 都只在各自循环内有效
    }
}
```

在 `if`、`while`、任意大括号块里声明的变量，出了大括号就消失。

### 存储类型关键字

| 关键字 | 作用 |
|---|---|
| `auto` | 局部变量默认就是 auto，自动分配自动回收，几乎不写 |
| `static` 局部 | 函数内 static 变量只初始化一次，函数返回后值保留 |
| `static` 全局 | 限定该全局变量只能在本文件内访问（内部链接） |
| `extern` | 声明"这个变量定义在别的文件里" |

### static 局部变量

```c
void counter(void) {
    static int n = 0;    // 只在第一次调用时初始化
    n++;
    printf("第 %d 次调用\n", n);
}

int main(void) {
    counter();   // 第 1 次
    counter();   // 第 2 次
    counter();   // 第 3 次
    return 0;
}
```

普通局部变量每次调用都重新创建，`static` 局部变量则"永生"——它住在静态存储区，不随函数返回销毁。

### 生命周期 vs 可见性

- **生命周期**：变量什么时候存在、什么时候销毁
- **可见性**：在哪些代码位置能访问它

局部自动变量：生命周期 = 函数调用期间，可见性 = 函数内部
全局变量：生命周期 = 整个程序，可见性 = 所有函数
static 局部：生命周期 = 整个程序，可见性 = 函数内部

## 核心重点
- 局部变量在函数内，函数结束就销毁；全局变量全程存在
- 全局变量少用，避免隐式耦合
- `static` 局部变量只初始化一次，值跨调用保留
- `extern` 用于跨文件引用全局变量
- 区分"生命周期"和"可见性"两个概念
