## 学习内容

### 值传递：C 语言唯一的参数传递方式

C 语言中，函数参数永远是**值传递**——把实参的值拷贝一份给形参。函数内部对形参的修改，不会影响外面的实参：

```c
void swap(int a, int b) {
    int t = a; a = b; b = t;
}

int main(void) {
    int x = 1, y = 2;
    swap(x, y);
    printf("%d %d\n", x, y);   // 仍然是 1 2，没有交换！
    return 0;
}
```

上面的 `swap` 交换的是两个副本，`main` 里的 `x` 和 `y` 根本没动。要真正交换，必须传地址（Day14 指针章节解决）。

### 多参数函数

```c
int max3(int a, int b, int c) {
    int m = a;
    if (b > m) m = b;
    if (c > m) m = c;
    return m;
}
```

参数可以有多个，用逗号分隔。参数之间类型可以不同：

```c
void show(const char *name, int age, double score);
```

### 返回值的使用

`return` 带回的是一个值，可以直接参与表达式：

```c
int s = add(3, 5) * 2;       // 16
printf("%d\n", add(1,2));    // 3
```

返回值类型必须与函数声明一致。如果函数声明为 `int` 却 `return;` 不带值，编译器会警告。

### 函数不能返回多个值

C 语言 `return` 只能带回一个值。如果确实需要返回多个结果，有两种办法：

1. **用指针参数带回**（明天学指针后详解）：
```c
void divide(int a, int b, int *quot, int *rem) {
    *quot = a / b;
    *rem  = a % b;
}
```

2. **用结构体打包**（Day13 学）：把多个值包进一个结构体，整体返回。

### 参数设计建议

- 参数不要太多（超过 4~5 个考虑用结构体打包）
- 参数名要见名知意，不要图省事写 `a, b, c`
- 不需要修改的参数，尽量加 `const` 保护（预告：指针场景常用）

### 函数调用是栈上的活动

每次调用函数，系统会在栈上为这次调用创建一个"栈帧"，里面存放形参、局部变量、返回地址。函数返回后栈帧销毁。这就是为什么函数内部的局部变量在函数结束后就不存在了。

## 核心重点
- C 语言参数永远是值传递，形参是实参的副本
- 函数内部改形参不影响外部，想改外部变量必须传指针
- return 只能返回一个值，多返回值靠指针参数或结构体
- 函数调用会创建栈帧，返回后栈帧销毁
- 参数设计要精简、命名要清晰
