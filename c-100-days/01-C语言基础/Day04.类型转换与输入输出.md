## 学习内容

### 自动类型转换

当不同类型的值混合运算时，编译器会自动把"小类型"提升为"大类型"，规则如下（从低到高）：

```
char -> short -> int -> unsigned int -> long -> float -> double
```

```c
int a = 5;
double b = 2.0;
double c = a / b;    // a 先被提升为 double，结果 2.5
```

注意：`5 / 2` 两个都是 int，结果仍是 int（等于 2），即使赋值给 double 也来不及了。

### 强制类型转换

用 `(类型)` 显式转换：

```c
int x = 7, y = 2;
double r = (double)x / y;   // 把 x 转成 double 再除，得 3.5
```

### 用 scanf 读取输入

```c
#include <stdio.h>

int main(void) {
    int age;
    double height;
    char name[20];

    printf("请输入年龄 身高 姓名: ");
    scanf("%d %lf %s", &age, &height, name);
    printf("你好 %s, 今年 %d 岁, 身高 %.1f\n", name, age, height);
    return 0;
}
```

关键注意点：
- 变量前要加 `&`（取地址符，字符串数组名除外，因为数组名本身就是地址）
- `double` 用 `%lf`，`float` 用 `%f`
- `%s` 读到空白符为止，不要带空格
- `scanf` 返回成功读取的变量个数，可用于检查输入合法性

### printf 格式控制进阶

```c
printf("%5d\n",   42);      // 右对齐，宽度5: "   42"
printf("%-5d|\n", 42);      // 左对齐: "42   |"
printf("%.2f\n",  3.14159); // 保留两位小数: "3.14"
printf("%05d\n",  42);      // 补零: "00042"
printf("%x %X\n", 255, 255);// 十六进制: ff FF
```

### 常见输入问题

- **输入缓冲区残留**：`scanf("%d", &n)` 后换行符还留在缓冲区，紧接着 `scanf("%c", &c)` 会读到换行符。解决：在格式串里加空格 `" %c"`。
- **缓冲区溢出**：`%s` 不限制长度，输入过长会踩内存。安全做法用 `%19s` 限制最多读 19 个字符。

```c
char name[20];
scanf("%19s", name);   // 最多读19个字符，留一个位置给 '\0'
```

## 核心重点
- 混合运算时小类型自动提升为大类型，但两个 int 相除结果仍是 int
- `(类型)值` 是强制转换，常用于避免整数除法
- `scanf` 变量前要加 `&`，字符串数组名不用
- `printf` 可用 `%5d`、`%.2f`、`%-5d` 控制宽度精度对齐
- 用 `%19s` 防止字符串输入溢出
