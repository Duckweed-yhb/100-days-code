## 学习内容

### 为什么需要函数

函数是一段起名字的、可重复使用的代码块。它有三个好处：
1. **复用**：写一次，到处调用
2. **分治**：把大问题拆成小函数，主函数读起来像目录
3. **隔离**：函数内部变量不影响外部，减少相互干扰

### 函数的结构

```c
返回值类型  函数名(参数列表) {
    函数体;
    return 返回值;
}
```

例子：

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    int s = add(3, 5);
    printf("%d\n", s);   // 8
    return 0;
}
```

### 函数声明（原型）

C 语言要求"先声明后使用"。如果 `add` 定义在 `main` 后面，编译器在 `main` 里第一次遇到 `add(3,5)` 时还不认识它，会报错或给出警告。解决办法是在文件顶部写**函数原型**：

```c
#include <stdio.h>

int add(int a, int b);    // 声明：告诉编译器函数长什么样

int main(void) {
    printf("%d\n", add(3, 5));
    return 0;
}

int add(int a, int b) {   // 定义：真正实现
    return a + b;
}
```

函数声明里参数名可以省略，只写类型：`int add(int, int);` 也可以。

### 无参函数与无返回值函数

```c
void greet(void) {          // void 表示没有返回值
    printf("你好\n");
}

int main(void) {
    greet();                // 调用无参函数
    return 0;
}
```

`void` 在参数列表里表示"不接收任何参数"。

### return 的作用

- `return 值;` 立即结束函数并把值返回给调用者
- `void` 函数里可以写 `return;`（不带值）提前结束
- `return` 后面的语句永远不会执行

### 函数调用的执行过程

1. 程序走到 `add(3, 5)` 时，把 3 和 5 拷贝给 `a` 和 `b`
2. 跳转到 `add` 函数体执行
3. `return a + b` 把结果交回调用处
4. 从 `main` 原来暂停的地方继续往下走

这个"拷贝参数、跳转执行、带回结果"的过程，是理解后面"值传递"的基础。

### 避免重复代码

不要在 `main` 里塞满逻辑。把"判断素数"、"求最大值"这类独立功能抽成函数，`main` 只做流程编排。

## 核心重点
- 函数 = 返回类型 + 函数名 + 参数列表 + 函数体
- 先声明后使用：函数定义在 main 后面时，要在顶部写原型
- `void` 表示无返回值或无参数
- `return` 立即结束函数并返回值
- 函数让代码可复用、可分治、可隔离
