# Day 07 · 循环控制与嵌套循环

## 今日目标
- 掌握 `break`、`continue`、`goto` 的用法与区别
- 学会嵌套循环的执行流程
- 能用嵌套循环解决打印图形、枚举搜索等问题

## 学习内容

### break：立即跳出整个循环

```c
for (int i = 1; i <= 100; i++) {
    if (i == 10) break;      // 一旦 i 等于 10，立刻结束循环
    printf("%d ", i);
}
// 输出 1 2 3 4 5 6 7 8 9
```

`break` 只能跳出**它所在的那一层**循环。

### continue：跳过本次，进入下一次

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue; // 偶数跳过
    printf("%d ", i);
}
// 输出 1 3 5 7 9
```

`continue` 不结束循环，只是跳过本次循环体剩下的语句，直接进入下一次条件判断。

### goto：直接跳转

```c
for (int i = 0; i < 10; i++) {
    for (int j = 0; j < 10; j++) {
        if (i * j > 50) goto end;  // 直接跳出两层
    }
}
end:
printf("结束\n");
```

`goto` 可以一次跳出多层循环，这是它唯一的合理用途。除此之外应尽量避免，因为滥用会让流程混乱。

### 嵌套循环

循环里面再套循环，外层每走一步，内层要完整走一圈：

```c
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        printf("i=%d j=%d\n", i, j);
    }
}
```

执行顺序：i=1 时 j 从 1 到 3，然后 i=2 时 j 再从 1 到 3，以此类推。

### 打印图形

```c
// 打印 5 行直角三角形
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        printf("*");
    }
    printf("\n");
}
```

```
*
**
***
****
*****
```

外层控制行数，内层控制每行打印几个星号。

### 枚举思想

双重循环可以做简单的枚举搜索：

```c
// 百钱百鸡：公鸡5元一只，母鸡3元一只，小鸡三只1元，100元买100只
for (int x = 0; x <= 20; x++) {
    for (int y = 0; y <= 33; y++) {
        int z = 100 - x - y;
        if (5*x + 3*y + z/3.0 == 100 && z % 3 == 0) {
            printf("公鸡%d 母鸡%d 小鸡%d\n", x, y, z);
        }
    }
}
```

### 常见错误

- `break` 和 `continue` 用混：break 是退出整个循环，continue 是跳过本次
- 嵌套循环时误以为 break 能跳出多层
- 内层循环变量和外层重名，导致逻辑混乱

## 核心重点
- break 跳出当前层循环，continue 跳过本次
- goto 仅用于跳出多层嵌套，平时不用
- 嵌套循环外层走一步，内层走一圈
- 打印图形：外层管行，内层管列
- 枚举问题用多重循环暴力搜索即可
