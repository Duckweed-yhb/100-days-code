## 学习内容

### 什么是变量

变量本质是一块有名字的内存空间，用来存放程序运行期间可以变化的数据。声明变量时，编译器会根据数据类型分配相应大小的内存。

```c
int age;           // 声明一个整型变量
age = 18;          // 赋值
int score = 95;    // 声明同时初始化
```

### 基本数据类型

C 语言的基本类型分为四类：字符型、整型、浮点型、空类型。

| 类型 | 关键字 | 典型大小 | 说明 |
|---|---|---|---|
| 字符型 | `char` | 1 字节 | 本质是小整数，存放 ASCII 码 |
| 短整型 | `short` | 2 字节 | 范围约 -32768~32767 |
| 整型 | `int` | 4 字节 | 范围约 -21 亿~21 亿 |
| 长整型 | `long` | 4 或 8 字节 | 取决于平台 |
| 单精度浮点 | `float` | 4 字节 | 约 6~7 位有效数字 |
| 双精度浮点 | `double` | 8 字节 | 约 15~16 位有效数字 |
| 空类型 | `void` | 无 | 表示"无类型"，用于函数无返回值等 |

> 类型大小并非 C 标准写死，标准只规定 `sizeof(short) <= sizeof(int) <= sizeof(long)`。用 `sizeof(类型)` 可在本机查看实际字节数。

###  signed 与 unsigned

整型默认是 `signed`（有符号），可正可负；加 `unsigned` 后只能表示非负数，但正数范围翻倍。

```c
char a = -1;           // 有符号，合法
unsigned char b = 255; // 无符号，0~255
```

### 标识符命名规则

- 只能由字母、数字、下划线组成
- 不能以数字开头
- 区分大小写（`Age` 和 `age` 是两个变量）
- 不能是关键字（如 `int`、`if`、`for`）
- 见名知意，推荐小写加下划线风格（`student_name`）

### 用 printf 打印不同类型

```c
#include <stdio.h>

int main(void) {
    int    i = 42;
    float  f = 3.14f;
    double d = 2.71828;
    char   c = 'A';

    printf("整数: %d\n", i);
    printf("单精度: %.2f\n", f);
    printf("双精度: %lf\n", d);
    printf("字符: %c\n", c);
    printf("字符的ASCII码: %d\n", c);
    return 0;
}
```

格式占位符速查：`%d` 整型、`%f` 浮点、`%lf` 双精度、`%c` 字符、`%s` 字符串、`%x` 十六进制、`%%` 打印百分号本身。

## 核心重点
- 变量是有名字的内存空间，使用前必须先声明类型
- 常用类型：`char`、`int`、`float`、`double`，大小用 `sizeof` 查看
- `unsigned` 扩大正数范围，失去负数表示能力
- 标识符不能以数字开头、不能用关键字、区分大小写
- `printf` 用 `%d %f %c %s` 等占位符输出对应类型
