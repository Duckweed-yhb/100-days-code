## 学习内容

### 编译带调试信息

```bash
gcc -g -O0 test.c -o test
gdb ./test
```

### 常用 gdb 命令

| 命令 | 作用 |
|---|---|
| `b 行号` | 断点 |
| `b 函数名` | 在函数入口断点 |
| `run` | 启动 |
| `n` | 单步（不进函数） |
| `s` | 单步（进函数） |
| `finish` | 跑完当前函数 |
| `p 变量` | 打印 |
| `bt` | 调用栈 |
| `c` | 继续 |
| `quit` | 退出 |

### 查段错误

程序崩溃后：

```bash
gdb ./test
(gdb) run
# 崩溃后
(gdb) bt     # 看崩在哪一行
(gdb) p var  # 看变量
```

### 观察变量变化

```bash
watch i == 100   # i 变成 100 时停
```

### VS Code 调试

装 C/C++ 扩展，按 F5，选 GDB。图形化点断点、看变量。比命令行直观。

### 调试思维

1. 复现问题
2. 二分缩小范围：在怀疑的位置加 printf
3. 看变量值对不对
4. 想为什么错，而不是瞎改

## 核心重点
- gcc -g 加调试信息
- gdb：b/n/s/p/bt/c
- bt 看崩溃位置
- watch 观察变量
- 调试是工程师核心能力
