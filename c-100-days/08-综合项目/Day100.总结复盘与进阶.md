### 你现在应该会的

- 熟练写 C 程序：变量、函数、指针、结构体
- 用 malloc 管理动态内存
- 实现链表、栈、队列、树
- 写排序、二分、递归、回溯、DP
- 文件 I/O、多线程、socket 基础
- 用 gdb 调试、Makefile 构建
- 模块化多文件项目

### 还不够的地方

- 工程化：版本控制 git、CI/CD
- 更深入的系统：Linux 内核、网络协议
- 性能优化：cache、并行、SIMD
- 现代 C：C11 原子、线程局部存储

### 下一步建议

1. **继续刷题**：LeetCode 热题 100，保持手感
2. **读开源代码**：从小项目开始，比如 redis 数据结构部分
3. **学 C++**：C 的超集，工程界主流
4. **做一个大项目**：自己写个编辑器、数据库、解释器
5. **深入系统**：读《UNIX 环境高级编程》

### 推荐资源

- 书：《C Primer Plus》《C 和指针》《UNIX 环境高级编程》
- 网站：LeetCode、VisuAlgo、CppReference
- 源码：Redis、Nginx、Linux 内核

C 语言是一门需要动手的语言。100 天只是入门，真正掌握靠项目和刷题。继续写代码，保持好奇。
