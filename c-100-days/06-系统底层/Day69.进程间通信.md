## 学习内容

### 为什么要 IPC

进程内存隔离，父子进程之间变量各自副本，改了不影响对方。要交换数据就得用操作系统提供的 IPC 机制。

### 常见 IPC 方式

| 方式 | 特点 |
|---|---|
| 管道 pipe | 半双工，有血缘关系进程 |
| 命名管道 FIFO | 无血缘也能用 |
| 消息队列 | 内核维护消息链表 |
| 共享内存 | 最快，需同步 |
| 信号量 | 用于同步，不传数据 |
| socket | 可跨机器 |

### 管道 pipe（POSIX/类 Unix 环境 Linux/macOS；Windows 可用 WSL）

```c
int fd[2];
pipe(fd);      // fd[0] 读端，fd[1] 写端

pid_t pid = fork();
if (pid == 0) {
    close(fd[0]);           // 子进程关闭读端
    write(fd[1], "hello", 5);
    close(fd[1]);
} else {
    close(fd[1]);           // 父进程关闭写端
    char buf[10] = {0};
    read(fd[0], buf, 5);
    printf("收到: %s\n", buf);
    close(fd[0]);
}
```

管道像一根水管，一端写一端读，数据按字节流走。

### 共享内存

多个进程映射同一块物理内存，直接读写，最快。但要配合信号量同步，防止同时写。

### 选哪种 IPC

- 简单父子通信：管道
- 大量数据高速：共享内存
- 跨网络：socket
- 通知事件：信号

## 核心重点
- 进程内存隔离，要 IPC 才能通信
- 管道半双工，有血缘
- 共享内存最快但需同步
- socket 可跨机器
- IPC 选择看场景
