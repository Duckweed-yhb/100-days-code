# Day 64 · C程序编译过程

## 今日目标
- 理解从 .c 到可执行文件的四个阶段
- 认识预处理器、编译器、汇编器、链接器
- 会用 gcc 分步编译

## 学习内容

### 四个阶段

```
hello.c
  │  1. 预处理 (cpp)
  ▼
hello.i   （展开宏、头文件）
  │  2. 编译 (cc1)
  ▼
hello.s   （汇编代码）
  │  3. 汇编 (as)
  ▼
hello.o   （机器码目标文件）
  │  4. 链接 (ld)
  ▼
hello.exe
```

### 1. 预处理

展开 #include、#define，处理条件编译：

```powershell
gcc -E hello.c -o hello.i
```

### 2. 编译

把 C 代码翻译成汇编：

```powershell
gcc -S hello.i -o hello.s
```

### 3. 汇编

把汇编翻译成机器码（目标文件 .o）：

```powershell
gcc -c hello.s -o hello.o
```

### 4. 链接

把多个 .o 和库合并成可执行文件：

```powershell
gcc hello.o -o hello.exe
```

### 目标文件里有什么

- 机器指令（代码段）
- 数据（已初始化全局变量）
- 符号表（函数名、变量名）
- 重定位信息（哪里要填地址）

### 为什么要懂这些

- 编译错误分阶段：语法错在编译期，链接错在链接期
- 库的概念在链接阶段
- 优化在编译阶段
- 看 .i 文件能理解宏展开到底做了什么

## 核心重点
- 四阶段：预处理 → 编译 → 汇编 → 链接
- gcc -E / -S / -c 分步执行
- 目标文件 .o 是机器码但未链接
- 链接把多个 .o 和库拼成可执行文件
- 编译错误 vs 链接错误要分清
