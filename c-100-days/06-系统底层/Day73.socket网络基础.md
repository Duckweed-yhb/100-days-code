## 学习内容

### 网络通信模型

```
客户端  ──── 网络 ────  服务器
发请求                   监听端口
收响应                   处理请求
```

### socket 是什么

socket 是操作系统提供的网络通信端点。可以把它想象成"网络文件描述符"，通过 read/write 收发数据。

### TCP vs UDP

| 方面 | TCP | UDP |
|---|---|---|
| 连接 | 面向连接（三次握手） | 无连接 |
| 可靠 | 保证送达、有序 | 不保证 |
| 速度 | 较慢 | 快 |
| 场景 | 网页、文件 | 视频、游戏 |

### 网络字节序

多字节整数在网络上传输用大端序。主机可能是小端，要转换：

```c
htons()   // 主机转网络（短）
htonl()   // 主机转网络（长）
ntohs()   // 网络转主机（短）
```

### 服务器端大致流程

1. `socket()` 创建套接字
2. `bind()` 绑定地址和端口
3. `listen()` 开始监听
4. `accept()` 接受连接
5. `read/write` 通信
6. `close()`

### 客户端大致流程

1. `socket()` 创建
2. `connect()` 连接服务器
3. `read/write` 通信
4. `close()`

POSIX/类 Unix 环境（Linux/macOS；Windows 可用 WSL）。Windows 上用 Winsock2，函数名略有不同，但概念一致。

## 核心重点
- socket 是网络通信端点
- TCP 可靠面向连接，UDP 快不保证
- 服务器：socket-bind-listen-accept
- 客户端：socket-connect
- 网络字节序大端
