# Day95 面试基础

> 目标：把计算机四大基础（数据结构与算法、计网、操作系统、数据库）按 Rust 岗位的高频考点快速复盘一遍，给自己列一份自检清单。

## 为什么 Rust 岗也要考计算机基础

Rust 工程师面后端/系统岗，公司不只考 Rust 语法，照样考 CS 基础。今天不展开细节，只给你**复习要点 + 自检问题**，每项花一两个晚上过一遍。

## 一、数据结构与算法

**复习要点：**

- 数组、链表、栈、队列、哈希表、树（二叉树/二叉搜索树）、图
- 排序：快排、归并、堆排的复杂度与稳定性
- 二分查找、DFS/BFS、动态规划入门
- 复杂度分析：时间/空间大 O

**自检问题：**

- 哈希表怎么解决冲突？负载因子是什么？
- 快排最坏复杂度多少？怎么避免？
- DFS 和 BFS 分别用什么数据结构实现？
- 动态规划的「重叠子问题」「最优子结构」指什么？

> 你之前刷 NOIP（Day14、Day96 提到的回文质数那些）已经在练这块，保持手感即可。

## 二、计算机网络

**复习要点：**

- TCP 三次握手、四次挥手；TCP 可靠传输（超时重传、滑动窗口）
- UDP vs TCP 区别与场景
- HTTP/1.1 vs HTTP/2 vs HTTP/3；常见状态码（200/301/304/400/401/403/404/500）
- HTTPS：TLS 握手大概流程、对称加密 vs 非对称加密

**自检问题：**

- 为什么三次握手不能两次？四次挥手为什么多？
- HTTP 长连接是什么？
- 从输入 URL 到页面显示，发生了什么？
- Cookie / Session / Token 区别？

## 三、操作系统

**复习要点：**

- 进程 vs 线程；协程是什么（Rust async 就是用户态协程）
- 进程间通信（管道、共享内存、消息队列）
- 内存管理：虚拟内存、分页、页表、swap
- 调度：时间片、上下文切换开销
- 锁：互斥锁、读写锁、死锁四个必要条件

**自检问题：**

- 进程和线程区别？线程切换为什么比进程轻？
- 用户态线程和内核态线程差别？Rust 的 async 属于哪种？
- 死锁怎么产生？怎么避免？
- 虚拟内存解决了什么问题？

## 四、数据库

**复习要点：**

- 索引：B+ 树为什么适合做索引；聚簇索引 vs 非聚簇索引
- 事务 ACID：原子性、一致性、隔离性、持久性
- 隔离级别：读未提交 / 读已提交 / 可重复读 / 串行化
- 范式与常见 SQL 优化

**自检问题：**

- 为什么索引用 B+ 树而不是 B 树或哈希？
- 什么是幻读？哪个隔离级别解决它？
- 事务隔离级别各级别分别解决什么问题？
- 慢查询怎么排查？

## 复习节奏建议

- 别死磕大部头，按上面清单查漏补缺
- 每个自检问题答不上来，就针对性搜一篇博客
- 算法保持每周刷 2~3 道，别手生

## 今日小结

- Rust 岗照样考 CS 四大基础
- 数据结构与算法：复杂度、树/图/DP、排序
- 计网：TCP 握手挥手、HTTP 版本、HTTPS
- OS：进程线程协程、虚拟内存、锁与死锁
- 数据库：B+ 树索引、事务 ACID、隔离级别
