# Day100 总结与后续

> 目标：复盘这 100 天走过的知识图谱，选定一个进阶方向，列出书单和后续学习节奏——毕业不是终点。

## 恭喜你走到这里

100 天，从 `fn main` 都不会，到能写 Web 服务、碰过操作系统、知道 Rust 各大生态方向。这不是结束，而是「入门完成」的起点。今天做三件事：复盘、定向、排节奏。

## 后续方向（选一个深挖）

别贪多。挑一个你最有感觉的方向继续：

- **后端/云原生**：深入异步、tonic/gRPC、给真项目贡献 PR
- **系统/操作系统**：继续 rCore 后续实验，读 Linux 内核或写一个小 OS
- **嵌入式**：买块开发板，把 Embassy 玩熟
- **数据库**：读一个用 Rust 写的数据库源码（如 redb）
- **WASM/前端**：用 Leptos 写一个完整 Web 应用

## 进阶书单

这三本是公认的「入门之后」必读：

| 书 | 适合谁 | 讲什么 |
|---|---|---|
| 《Programming Rust》（O'Reilly） | 想系统吃透 | 比官方书更深，覆盖高级主题 |
| 《Rust for Rustaceans》 | 已会写、想写好 | 讲「 idiomatic Rust」怎么写地道 |
| 《Rust Atomics and Locks》 | 并发/系统方向 | 深入原子操作与锁，免费在线 |

## 持续学习节奏建议

- **别断手**：每周至少写一点 Rust，哪怕是小工具
- **读源码**：挑一个你常用的 crate，读它的 README 和几个核心文件
- **参与开源**：从 Day91 的 good first issue 开始，提一两个 PR
- **写博客/笔记**：把你踩过的坑记下来，教是最好的学

## 三句话收尾

1. Rust 难的不是语法，是换一种「用类型思考」的方式——你已经入门了
2. 编译器不是敌人，是陪你成长的导师，报错越熟说明你越强
3. 100 天只是开始，保持每周动手，一年后你会感谢今天的自己
