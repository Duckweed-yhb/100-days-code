# Day17 枚举 enum

> 目标：学会用 `enum` 定义「一个值只能是几种固定情况之一」的类型，并让每种情况都能携带自己的数据。

## 为什么需要枚举

结构体描述的是「一个东西同时拥有哪些字段」。但有些场景是「一个东西只能是几种互斥情况之一」。比如一张消息：它要么是「退出」信号，要么是「移动到坐标」，要么是「发送一段文本」，要么是「改颜色」。这四件事不可能同时发生，但都属于「消息」这一类。

**枚举（enumeration，enum）**就是干这个的：你先列出所有可能的情况（叫**变体 variant**），一个值在任一时刻只能是其中之一。

生活里的例子：扑克牌的花色只能是 黑桃 / 红桃 / 梅花 / 方块 四种之一；一周的星期只能是 周一到周日 之一。

## 定义枚举

```rust
enum Message {
    Quit,                        // 变体1：不带任何数据
    Move { x: i32, y: i32 },     // 变体2：带一个匿名结构体数据
    Write(String),               // 变体3：带一个 String
    ChangeColor(i32, i32, i32),  // 变体4：带三个 i32
}

fn main() {
    // 用 :: 从枚举命名空间里取出变体
    let m1 = Message::Quit;
    let m2 = Message::Write(String::from("hello"));
    let m3 = Message::ChangeColor(255, 0, 0);
}
```

看出来了吗？**枚举的每个变体都能带不同类型、不同数量的数据**：

- `Quit` 什么都不带；
- `Move` 带两个命名字段；
- `Write` 带一个 `String`；
- `ChangeColor` 带三个 `i32`。

这些写法你其实都见过——它们分别对应 Day16 学过的类单元结构体、命名字段结构体、元组结构体。**枚举就是把这几种「长得不一样的结构体」打包成同一个类型。**

## 为什么这比多个结构体强

你可能会想：那我分别定义 `Quit`、`Move`、`WriteMsg`、`ChangeColor` 四个结构体不就行了？问题在于：如果它们是四个不同类型，你就没法把它们放进同一个数组、传给同一个函数参数。

```rust
// 四个变体同属 Message 类型，可以放进同一个数组
let messages: Vec<Message> = vec![
    Message::Quit,
    Message::Write(String::from("hello")),
    Message::ChangeColor(0, 255, 0),
];

// 函数只需要接收一个 Message，不用关心具体是哪种
fn process(msg: Message) {
    // 今天先空着，明天学 match 后再来处理它
}
```

这正是枚举的杀手锏：**把「同属一类但形态不同」的数据统一成一种类型**。

## 枚举也能挂方法

和结构体一样，枚举也能用 `impl` 块定义方法：

```rust
impl Message {
    fn call(&self) {
        // 对消息做些处理
        println!("有人发了一条消息");
    }
}

fn main() {
    let m = Message::Write(String::from("hello"));
    m.call();
}
```

## 一个直观对比：结构体 vs 枚举

| | 结构体 struct | 枚举 enum |
|---|---|---|
| 描述 | 一个东西**同时有**哪些字段 | 一个东西**只能是**哪几种情况之一 |
| 变体关系 | 全部字段同时存在 | 任一时刻只有一个变体生效 |
| 典型例子 | 一个用户有用户名+邮箱+年龄 | 一笔资金流向：转账/退款/冻结 |
| 能否放同一容器 | 同类型结构体可以 | 不同变体天然同属一个枚举类型 |

## 枚举的底层：整数标签

你可能会好奇，枚举值在内存里长什么样。Rust 会给每个变体分配一个整数 discriminant（判别值），再加上它携带的数据。所以枚举通常很省内存——这也是后面操作系统训练营里你会大量用到它的原因之一（比如用枚举表示「任务状态：就绪/运行/阻塞」）。

默认的判别值从 0 开始，你也可以手动指定：

```rust
enum Color {
    Red = 0xff0000,
    Green = 0x00ff00,
    Blue = 0x0000ff,
}
```

## 先混个脸熟：`Option<T>`

标准库里最常用的枚举就是 `Option<T>`，它用来表示「一个值可能存在、也可能不存在」：

```rust
enum Option<T> {
    Some(T), // 有值，里面包着一个 T
    None,    // 没有值
}
```

```rust
let some_num = Some(5);          // 有值
let absent: Option<i32> = None;  // 没值，必须标注类型
```

这东西为什么重要、为什么 Rust 要用它取代其他语言里的 `null`，我们**明天 Day18 专门讲**。今天你只要知道：枚举变体可以携带数据，而 `Option` 就是这么一个枚举。至于怎么把一个 `Message` 或 `Option` 拆开、根据不同情况做不同事，那是 Day19 `match` 的活儿。

## 今日小结

- 枚举 `enum` 描述「一个值只能是几种固定情况之一」，变体用 `枚举名::变体名` 访问
- 每个变体可以携带不同类型、不同数量的数据（无数据 / 命名字段 / 元组 / 单个值）
- 不同变体同属一个枚举类型，能放进同一容器、传给同一函数——这是多个结构体做不到的
- 枚举也能在 `impl` 块里挂方法
- `Option<T>`（`Some(T)` / `None`）是标准库最重要的枚举之一，明天细讲
