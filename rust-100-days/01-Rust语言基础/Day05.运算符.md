# Day05 运算符

> 目标：掌握 Rust 的算术、赋值、比较、逻辑运算符，学会不同数字类型之间用 `as` 转换，并动手做一个温度换算小程序。

## 运算符是"做事情的符号"

运算符把值连起来做计算。Rust 的运算符和 C / Java 大同小异，今天快速过一遍常用的，重点记几个和别的语言不一样的地方。

## 算术运算符

| 运算符 | 作用 | 例子 |
|---|---|---|
| `+` | 加 | `1 + 2` → `3` |
| `-` | 减 | `5 - 2` → `3` |
| `*` | 乘 | `3 * 4` → `12` |
| `/` | 除 | `10 / 3` → `3`（**整数除法**） |
| `%` | 取余（求模） | `10 % 3` → `1` |

```rust
fn main() {
    let a = 10;
    let b = 3;
    println!("{}", a + b);   // 13
    println!("{}", a - b);   // 7
    println!("{}", a * b);   // 30
    println!("{}", a / b);   // 3   ← 注意：两个整数相除，小数部分被丢掉
    println!("{}", a % b);   // 1   ← 10 除以 3 余 1
}
```

> **整数除法坑**：`10 / 3` 在 Rust 里结果是 `3`，不是 `3.333`，因为两边都是整数。想要小数结果，得让至少一边是浮点数，或者用 `as` 转换（后面讲）。

### Rust 没有幂运算符

别的语言里 `2 ** 3` 可能表示 2 的 3 次方，但 Rust 里**没有** `**` 这个运算符。求幂要用方法：

```rust
fn main() {
    let x = 2_i32.pow(3);        // 整数的幂 → 8
    let y = 2.0_f64.sqrt();      // 开平方
    println!("{} {}", x, y);
}
```

## 赋值与复合赋值

普通赋值就是 `=`。把运算和赋值合起来，有一套"复合赋值"运算符：

| 运算符 | 等价于 |
|---|---|
| `+=` | `x = x + 值` |
| `-=` | `x = x - 值` |
| `*=` | `x = x * 值` |
| `/=` | `x = x / 值` |
| `%=` | `x = x % 值` |

注意：左边的变量必须是**可变的**（`mut`），否则编译报错。

```rust
fn main() {
    let mut x = 10;
    x += 5;     // x = 15
    x *= 2;     // x = 30
    println!("{}", x);
}
```

> Rust **没有** `x++`、`x--` 这种自增自减运算符，要用 `x += 1`。初学别从别的语言带习惯过来。

## 比较运算符

比较两个值，结果一定是 `bool`（`true` 或 `false`）：

| 运算符 | 含义 |
|---|---|
| `==` | 等于（**注意是两个等号**） |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

```rust
fn main() {
    let a = 5;
    let b = 10;
    println!("{}", a == b);   // false
    println!("{}", a < b);    // true
}
```

> 新手最常见错误：判断相等写成一个 `=`（那是赋值）。Rust 里判断相等必须 `==`。

## 逻辑运算符

用来组合多个条件：

| 运算符 | 含义 | 说明 |
|---|---|---|
| `&&` | 逻辑与（并且） | 两边都为 `true` 才为 `true` |
| `\|\|` | 逻辑或（或者） | 任意一边为 `true` 就为 `true` |
| `!` | 逻辑非（取反） | `true` 变 `false`，反之亦然 |

它们都是**短路求值**：`&&` 左边已经是 `false` 就不算右边；`||` 左边已经是 `true` 就不算右边。

```rust
fn main() {
    let age = 25;
    let has_ticket = true;
    // 必须成年 并且 有票，才能进
    if age >= 18 && has_ticket {
        println!("请进");
    }
    if !(age < 18) {
        println!("不是未成年人");
    }
}
```

## 类型转换：`as`

Rust **不会偷偷帮你转换数字类型**。整数和浮点数混在一起运算会直接报错，必须手动用 `as` 转换：

```rust
fn main() {
    let x = 10;          // i32
    let y = 3.0;         // f64
    // let z = x / y;    // ❌ 报错：i32 和 f64 不能直接除
    let z = x as f64 / y; // ✅ 把 x 先转成 f64
    println!("{}", z);    // 3.333...
}
```

常见转换写法：

```rust
let a = 65_i32;
let b = a as f64;        // i32 → f64：65.0
let c = 3.99_f64;
let d = c as i32;        // f64 → i32：直接截断小数部分，d = 3（不是四舍五入）
let e = a as u8;         // 65 转成 u8
```

> `as` 转换浮点数是**直接砍掉小数**（向零取整），不是四舍五入。需要四舍五入要用方法 `.round()`。

## 小练习：摄氏度转华氏度

公式：`华氏度 = 摄氏度 × 9 / 5 + 32`。动手写一个：

```rust
fn main() {
    let celsius: f64 = 26.0;                       // 今天气温，单位摄氏度
    let fahrenheit = celsius * 9.0 / 5.0 + 32.0;  // 套公式
    println!("{}℃ = {}℉", celsius, fahrenheit);     // 26℃ = 78.8℉
}
```

运行下面命令看看输出：

```powershell
cargo run
```

> 注意这里所有数字都写了 `.0` 或标注 `f64`，就是为了避免整数除法把小数吃掉。你可以把 `9.0 / 5.0` 改成 `9 / 5` 试试——结果会变成 `26 * 1 + 32 = 58`，体会一下整数除法的坑。

## 运算符优先级速记

和数学里差不多：先乘除后加减，比较比加减低，逻辑与比逻辑或高。拿不准就**加括号**，永远不会错：

```rust
let x = (2 + 3) * 4;     // 20，而不是 14
```

## 今日小结

- 算术：`+ - * / %`；整数除法会丢小数；Rust **没有** `**` 幂运算，用 `.pow()`。
- 复合赋值 `+= -= *= /= %=` 要求变量是 `mut`；没有 `++` / `--`。
- 比较 `== != < > <= >=` 结果是 `bool`；判断相等是两个等号。
- 逻辑 `&& || !` 短路求值；数字类型混用必须用 `as` 显式转换。
