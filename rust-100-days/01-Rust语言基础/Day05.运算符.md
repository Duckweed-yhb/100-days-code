## 运算符是「做事情的符号」

运算符把值连起来做计算。Rust 的运算符和 C / Java 大体一样，今天快速过一遍常用的，重点记几个跟别的语言不一样的地方。

## 算术运算符

| 运算符 | 作用 | 例子 |
|---|---|---|
| `+` | 加 | `1 + 2` → `3` |
| `-` | 减 | `5 - 2` → `3` |
| `*` | 乘 | `3 * 4` → `12` |
| `/` | 除 | `10 / 3` → `3`（**整数除法**） |
| `%` | 取余（求模） | `10 % 3` → `1` |

`%` 读作「模」，算的是除完之后剩下的零头：10 除以 3 得 3，余 1。

📦 本块能单独跑：

```rust
fn main() {
    let a = 10;
    let b = 3;
    println!("{}", a + b);   // 13
    println!("{}", a - b);   // 7
    println!("{}", a * b);   // 30
    println!("{}", a / b);   // 3   ← 两个整数相除，小数部分被丢掉
    println!("{}", a % b);   // 1   ← 10 除以 3 余 1
}
```

> **整数除法坑**：`10 / 3` 在 Rust 里结果是 `3`，不是 `3.333`，因为两边都是整数。想要小数结果，得让至少一边是浮点数，或者用 `as` 转换（后面讲）。

### Rust 没有幂运算符

别的语言里 `2 ** 3` 可能表示 2 的 3 次方，但 Rust 里**没有** `**` 这个运算符。求幂要调方法，也就是用 `.pow(...)` 这种写法：

📦 本块能单独跑：

```rust
fn main() {
    let x = 2_i32.pow(3);        // 整数的 3 次方 → 8
    let y = 2.0_f64.sqrt();      // 开平方 → 1.4142135623730951
    println!("{} {}", x, y);
}
```

`2_i32` 和 `2.0_f64` 这种写法你可能第一次见：数字后面直接跟类型名，等于当场把这个字面量的类型定死，叫**字面量后缀**。不写后缀行不行？对普通变量赋值没问题（编译器按默认值猜），但**在这里不行**：

```
error[E0689]: can't call method `pow` on ambiguous numeric type `{integer}`
  |
2 |     let x = 2.pow(3);
  |               ^^^
  |
help: you must specify a concrete type for this numeric value, like `i32`
```

调 `.pow()` 时编译器得先知道这是哪种整数才能找到对应的方法，而 `2` 的类型还没定，它就报「类型不明」。编译器连改法都告诉你：写成 `2_i32`。所以这类方法调用前面，后缀基本是必需的。

## 赋值与复合赋值

普通赋值就是 `=`。把运算和赋值合在一起写，有一套**复合赋值**运算符：

| 运算符 | 等价于 |
|---|---|
| `+=` | `x = x + 值` |
| `-=` | `x = x - 值` |
| `*=` | `x = x * 值` |
| `/=` | `x = x / 值` |
| `%=` | `x = x % 值` |

左边的变量必须是**可变的**（加过 `mut`），否则编译报错。

📦 本块能单独跑：

```rust
fn main() {
    let mut x = 10;
    x += 5;     // x = 15
    x *= 2;     // x = 30
    println!("{}", x);
}
```

> Rust **没有** `x++`、`x--` 这种自增自减运算符，要用 `x += 1`。别把别的语言的习惯带过来。

## 比较运算符

比较两个值，结果一定是 `bool`（`true` 或 `false`）：

| 运算符 | 含义 |
|---|---|
| `==` | 等于（**注意是两个等号**） |
| `!=` | 不等于 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

📦 本块能单独跑：

```rust
fn main() {
    let a = 5;
    let b = 10;
    println!("{}", a == b);   // false
    println!("{}", a < b);    // true
}
```

> 新手最常见错误：判断相等写成一个 `=`，那是赋值。Rust 里判断相等必须写 `==`。

## 逻辑运算符

用来组合多个条件：

| 运算符 | 含义 | 说明 |
|---|---|---|
| `&&` | 逻辑与（并且） | 两边都为 `true` 才为 `true` |
| `\|\|` | 逻辑或（或者） | 任意一边为 `true` 就为 `true` |
| `!` | 逻辑非（取反） | `true` 变 `false`，反之亦然 |

它们都是**短路求值**：`&&` 左边已经是 `false`，右边就不算了；`||` 左边已经是 `true`，右边也不算了。

📦 本块能单独跑：

```rust
fn main() {
    let age = 25;
    let has_ticket = true;
    // 必须成年 并且 有票，才能进
    if age >= 18 && has_ticket {
        println!("请进");
    }
    if !(age < 18) {
        println!("不是未成年人");
    }
}
```

这里的 `!` 是取反运算符，放在表达式前面用。它跟 Day02 里 `println!` 末尾那个 `!` 不是一回事：那个是宏的标记，这个是运算符。看位置就能分清，运算符用在值前面，宏标记紧跟在名字后面。

## 类型转换：`as`

Rust **不会偷偷帮你转换数字类型**。整数和浮点数混在一起运算会直接报错，必须手动用 `as` 转换。`as` 夹在值后面和类型前面，意思是「把这个值转成这个类型」：

📦 本块能单独跑：

```rust
fn main() {
    let x = 10;          // i32
    let y = 3.0;         // f64
    // let z = x / y;    // ❌ 报错：i32 和 f64 不能直接除
    let z = x as f64 / y; // ✅ 把 x 先转成 f64 再除
    println!("{}", z);    // 3.3333333333333335
}
```

常见转换写法：

📦 本块能单独跑：

```rust
fn main() {
    let a = 65_i32;
    let b = a as f64;        // i32 → f64：值是 65.0
    let c = 3.99_f64;
    let d = c as i32;        // f64 → i32：直接截断小数部分，得 3
    let e = a as u8;         // 65 转成 u8
    println!("{} {} {}", b, d, e);   // 65 3 65
}
```

第一行 `65` 后面为什么打印成 `65` 而不是 `65.0`？因为 `{}` 只打印值本身，浮点数末尾的 `.0` 会被省略掉。值仍然是 `f64` 的 `65.0`，Day04 里 `let x = 2.0;` 打印出 `2` 也是一回事。

> `as` 转浮点数会**直接砍掉小数**（向零取整），不是四舍五入，所以 `3.99` 变 `3`。要四舍五入用方法 `.round()`。

## 小练习：摄氏度转华氏度

公式：`华氏度 = 摄氏度 × 9 / 5 + 32`。动手写一个：

📦 本块能单独跑：

```rust
fn main() {
    let celsius: f64 = 26.0;                       // 今天气温，单位摄氏度
    let fahrenheit = celsius * 9.0 / 5.0 + 32.0;  // 套公式
    println!("{}℃ = {}℉", celsius, fahrenheit);     // 26℃ = 78.8℉
}
```

> 这里的数字全写 `.0`，是因为 `celsius` 已经是 `f64` 了，右边的 `9`、`5` 也得是浮点数，写成 `celsius * 9 / 5` 会直接编不过，报 `cannot multiply f64 by {integer}`。真正容易掉进整数除法坑的是温度本身为整数的时候：`let celsius: i32 = 26;` 再套 `celsius * 9 / 5 + 32`，结果是 78 而不是 78.8，因为 `26 * 9` 得 234，`234 / 5` 被截成了 46。

## 运算符优先级速记

和数学里差不多：先乘除后加减，比较比加减低，逻辑与比逻辑或高。拿不准就**加括号**，加了括号永远不会错：

📦 本块能单独跑：

```rust
fn main() {
    let x = (2 + 3) * 4;     // 20，不加括号才是 14
    println!("{}", x);
}
```

## 今日小结

- 算术：`+ - * / %`；整数除法会丢小数；Rust **没有** `**` 幂运算，用 `.pow()`。
- 调 `.pow()` 这类方法时要先定类型，字面量写后缀最省事：`2_i32.pow(3)`。
- 复合赋值 `+= -= *= /= %=` 要求变量是 `mut`；没有 `++` / `--`。
- 比较 `== != < > <= >=` 结果是 `bool`；判断相等是两个等号。
- 逻辑 `&& || !` 短路求值；数字类型混用必须用 `as` 显式转换。
