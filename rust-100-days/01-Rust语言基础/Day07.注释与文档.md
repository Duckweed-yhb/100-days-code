## 注释是写给谁看的

代码给机器执行，也给人读，三个月后的你自己也是读者。注释负责回答的是“这段代码为什么这么写”。

Rust 的注释分两类：**普通注释**（只给人看）和**文档注释**（会被 `cargo doc` 收集成网页）。

## 普通注释

### 行注释 `//`

行注释用得最多，`//` 之后到行尾全是注释：

📦 本块能单独跑：

```rust
fn main() {
    // 这是一个行注释，单独占一行
    let lucky = 7;      // 也可以跟在代码后面，说明这行在干嘛

    // 下面两行暂时不要执行，先注释掉调试
    // println!("不会被打印");
    // println!("也不会");
    println!("{}", lucky);
}
```

> 小技巧：VS Code 里选中一段代码按 `Ctrl + /`，可以批量加上或取消 `//`。

### 块注释 `/* ... */`

用 `/*` 开头、`*/` 结尾，能跨多行：

📦 本块能单独跑：

```rust
fn main() {
    /*
       这是一块多行注释。
       适合临时把一大段代码注释掉，
       或者写一段较长的说明。
    */
    let x = 1;
    println!("{}", x);
}
```

Rust 的块注释可以嵌套，`/* 外层 /* 内层 */ 还在外层里 */` 是合法的，有些语言不支持这么写。日常还是用 `//` 更省事，块注释留给临时屏蔽大段代码。

## 注释写什么

好的注释解释**为什么**，别当代码的复读机。

📦 本块能单独跑：

```rust
fn main() {
    let mut x = 1;
    x = x + 1;      // 反例：这句注释只是把代码又念了一遍

    let index = 4;
    // 正例：+1 是因为接口从 1 开始计数，而数组下标从 0 开始
    let page = index + 1;

    println!("x = {}, page = {}", x, page);
}
```

> 原则：当你看一眼代码觉得“这里有点怪”，那就是最该写注释的地方。

## 文档注释 `///`

`///` 是**文档注释**。它写在函数、结构体这些定义的正上方，`cargo doc` 会把它们收集起来生成 HTML 文档。

📦 本块能单独跑：

```rust
fn main() {
    println!("平均值 = {}", average(3, 5));
}

/// 计算两个整数的平均值。
///
/// 结果是整数除法，小数部分被丢掉，所以 `average(3, 5)` 得 4。
///
/// # 参数
///
/// - `a`：第一个整数
/// - `b`：第二个整数
fn average(a: i32, b: i32) -> i32 {
    (a + b) / 2
}
```

`///` 里面可以写 Markdown，标题、列表、代码块全认。上面那个 `# 参数` 到网页上就是一个二级标题。

下面这段是**注释内容长什么样**，不是能运行的 Rust 代码，你照它写进 `///` 里：

````text
/// 计算两个整数的平均值。
///
/// # 例子
///
/// ```
/// use my_crate::average;      // my_crate 换成你自己的库名
/// assert_eq!(average(3, 5), 4);
/// ```
fn average(a: i32, b: i32) -> i32 {
    (a + b) / 2
}
````

注释里那三个反引号围起来的部分叫**文档测试（doctest）**。`cargo test` 会把它抽出来真的编译、执行一遍，所以文档里的例子不容易过时。文档测试是单独编译成一个小程序的，例子里的函数要带上库名前缀才找得到。

> 注意一个容易踩空的地方：doctest 只对**库（lib）**目标生效。我们现在的项目是 `main.rs` 二进制，运行 `cargo test` 只会跑 `#[test]` 单元测试，不会跑 doctest。所以今天你先把 `///` 写好、用 `cargo doc` 看排版效果；等以后把代码拆成库，`cargo test` 才会真正去跑这些例子。

### 模块文档注释 `//!`

`//!` 用在文件或模块的**开头**，描述“这个文件、这个模块是干什么的”。它不挂在某个具体的东西上，是给整块做说明：

📦 本块能单独跑：

```rust
//! 这个模块提供了一些数学小工具。
//!
//! 目前包含平方函数。

fn main() {
    println!("{}", square(6));
}

/// 计算平方
fn square(n: i32) -> i32 {
    n * n
}
```

> 区分：`///` 贴着它下面那个东西；`//!` 说的是它所在这一整块，一般只出现在开头。

## 用 `cargo doc` 生成网页文档

在项目根目录（有 `Cargo.toml` 的那一层）运行：

```powershell
cargo doc --open
```

它会做两件事：把你写的 `///`、`//!` 编译成 HTML 网页，然后用默认浏览器打开。生成的东西和 Rust 标准库文档（doc.rust-lang.org）是同一套排版。

网页文件落在 `target/doc/` 目录下，可以直接进去翻。把这些文档发到 crate 仓库之后，docs.rs 还会自动托管一份。

## 今日小结

- 普通注释：`//` 行注释（最常用）、`/* ... */` 块注释（可嵌套）；VS Code 里 `Ctrl + /` 批量加注释。
- 注释要解释“为什么”，别复述“是什么”。
- 文档注释 `///` 写在函数、结构体上方，里面的内容支持 Markdown。
- `///` 里的代码块叫 doctest，库项目里 `cargo test` 会真的跑一遍。
- 模块文档 `//!` 写在文件开头，说明整个模块的用途。
- `cargo doc --open` 一键生成并打开网页文档。
