# Day07 注释与文档

> 目标：学会写普通注释和文档注释，用 `cargo doc` 把你写的注释自动生成成一个漂亮的网页文档。

## 为什么要写注释

代码是写给机器执行的，但更是写给**人**（包括三个月后的你）读的。注释就是你写给读代码的人的悄悄话——解释"这段代码为什么这么写"。

Rust 的注释分两大类：**普通注释**（不参与生成文档）和**文档注释**（会被 `cargo doc` 收集成网页）。

## 普通注释

### 行注释 `//`

最常用，从 `//` 开始到行尾都是注释：

```rust
fn main() {
    // 这是一个行注释，单独占一行
    let lucky = 7;      // 也可以跟在代码后面，说明这行在干嘛

    // 下面两行暂时不要执行，先注释掉调试
    // println!("不会被打印");
    // println!("也不会");
    println!("{}", lucky);
}
```

> 小技巧：在 VS Code 里选中一段代码按 `Ctrl + /`，可以批量注释 / 取消注释，调试时特别好用。

### 块注释 `/* ... */`

用 `/*` 开头、`*/` 结尾，可以跨多行：

```rust
fn main() {
    /*
       这是一块多行注释。
       适合临时把一大段代码注释掉，
       或者写一段较长的说明。
    */
    let x = 1;
    println!("{}", x);
}
```

块注释在 Rust 里是可以**嵌套**的（别的一些语言不行），但日常开发还是推荐用 `//` 行注释，块注释偶尔用于临时屏蔽大段代码。

## 注释写什么好

好的注释解释**为什么这么做**，而不是复述代码本身：

```rust
// 反例：废话，谁都看得懂
let x = x + 1;   // 把 x 加 1

// 正例：解释背后的原因
// 必须 +1，因为接口是从 1 开始计数的
let page = index + 1;
```

> 原则：当你自己都觉得"这代码怪怪的"，那就是最该写注释的地方。

## 文档注释 `///`

`///` 是**文档注释**，它会被 `cargo doc` 收集，生成成漂亮的 HTML 文档。通常写在**函数、结构体等定义的正上方**，说明这个东西是干嘛的、怎么用：

```rust
/// 计算两个整数的平均值。
///
/// 注意：结果是整数除法，小数部分会被丢弃。
///
/// # 例子
///
/// ```
/// let avg = my_crate::average(3, 5);
/// assert_eq!(avg, 4);
/// ```
fn average(a: i32, b: i32) -> i32 {
    (a + b) / 2
}
```

几点说明：

- `///` 下面可以写 **Markdown** 格式，标题、列表、代码块都行。
- 里面写的 ` ``` ` 代码块，Rust 会在 `cargo test` 时**自动当真代码运行一遍**（文档测试）——这样文档里的示例永远不会过时。这是 Rust 的一大特色。
- 文档注释主要写给**别人怎么用你的库**看的，所以要讲清楚功能、参数、返回值、边界情况。

### 模块文档注释 `//!`

`//!` 用在文件或模块的**开头**，描述"这个模块/整个文件是干什么的"。它没有放在某个具体项上面，而是给整体做说明：

```rust
//! 这个模块提供了一些数学小工具。
//!
//! 目前包含平均值、平方等函数。

/// 计算平方
fn square(n: i32) -> i32 {
    n * n
}
```

> 区分：`///` 紧贴它下面那个东西；`//!` 是它所在这一块（文件/模块）的总体说明，一般只出现在开头。

## 用 `cargo doc` 生成网页文档

写了文档注释，怎么看效果？在项目根目录（有 `Cargo.toml` 的那一层）运行：

```powershell
cargo doc --open
```

它会：

1. 把你写的 `///` 注释编译成 HTML 网页；
2. 自动用默认浏览器打开，效果和 Rust 标准库文档（doc.rust-lang.org）一模一样。

运行下面命令试试：

```powershell
cargo doc --open
```

> 你也可以打开 `target/doc/` 目录找到生成的网页文件。等以后发布自己的 crate 时，这份文档会自动托管到 docs.rs 上。

## 今日小结

- 普通注释：`//` 行注释（最常用）、`/* ... */` 块注释；VS Code 里 `Ctrl + /` 批量注释。
- 注释要解释"为什么"，别复述"是什么"。
- 文档注释 `///` 写在函数/结构体上方，支持 Markdown，里面的代码块还会被自动当测试跑。
- 模块文档 `//!` 写在文件开头，说明整个模块的用途。
- `cargo doc --open` 一键生成并打开网页文档。
