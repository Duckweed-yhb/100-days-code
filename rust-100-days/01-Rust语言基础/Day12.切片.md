## 什么是切片

**切片（slice）**是一种引用：它不拥有数据，只借用某个集合（字符串、数组）里**一段连续的元素**。

Day11 学过引用不转移所有权，切片就是"借一绺数据"的引用。

它的好处有两个。第一，不用把整个字符串或数组传进去，就能只操作其中一段。第二，只要这个切片还在用，编译器就不允许原数据被改动，这一绺数据始终有效。

两个词先交代：

- **元素**：集合里单独的一项。`[1, 2, 3]` 的三个元素分别是 `1`、`2`、`3`。
- **左闭右开**：写 `0..5`，表示从下标 0 开始、到下标 5 之前为止，也就是 0、1、2、3、4。右边的 5 不算在内。

## 字符串切片 `&str`

写法是 `&字符串[起始..结束]`，意思是从起始位借到结束位的前一位。

📦 本块能单独跑：

```rust
fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];    // 下标 0 到 4 → "hello"
    let world = &s[6..11];   // 下标 6 到 10 → "world"

    println!("{} | {}", hello, world);
}
```

三点说明：

- `0..5` 里的 `..` 是**区间语法**，`a..b` 表示从 a 到 b 之前。
- 下标算的是**字节**，不是字符。这段全是英文字母，一个字母一字节，数字刚好对得上。中文一个字占好几个字节，Day23 会专门讲这个坑。
- 切出来的是引用，`s` 本身没被动过。

区间语法还有几种简写：

📦 本块能单独跑：

```rust
fn main() {
    let s = String::from("hello");

    let a = &s[0..5];    // 完整写法 → "hello"
    let b = &s[..5];     // 起始是 0，可以省略
    let c = &s[0..];     // 一直到末尾，可以省略结束
    let d = &s[..];      // 两头都省 → 整个字符串

    println!("{} {} {} {}", a, b, c, d);
}
```

> 切片的类型是 `&str`（读作"字符串切片"），不是 `&String`。`&str` 借用一段已有的 UTF-8 文本，`String` 自己拥有堆上的字符串数据。这两者的关系 Day13 细讲。

## 一个经典例子：找第一个单词

给定 `"hello world"`，取出第一个单词，也就是空格之前的那一段：

📦 本块能单独跑：

```rust
fn first_word(s: &String) -> &str {
    let bytes = s.as_bytes();              // 把字符串当成字节数组来逐个找
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {                  // 找到空格的位置
            return &s[0..i];               // 返回从开头到空格的切片
        }
    }
    &s[..]                                 // 没空格，整个字符串就是一个单词
}

fn main() {
    let s = String::from("hello world");
    let word = first_word(&s);
    println!("第一个单词是：{}", word);     // hello
}
```

这行 `for (i, &item) in bytes.iter().enumerate()` 信息量有点大，拆开看：

- `s.as_bytes()` 把 `String` 看成一段 `u8` 字节，返回 `&[u8]`。
- `.iter()` 返回一个**迭代器**，可以理解成"能一个个往外取元素的东西"，取完就不再有了。
- `.enumerate()` 在取值的同时附带下标，所以每轮拿到的是 `(下标, 元素)` 这种元组（Day04 讲过元组）。
- `for (i, &item) in ...` 是**解构**（Day04 也讲过）：一次接住下标和元素两个值，分别绑到 `i` 和 `item`。
- 迭代器给的元素是 `&u8`（引用），所以模式里写 `&item`，把里面的字节取出来。取出来才能直接和 `b' '` 比。
- `b' '` 是**字节字面量**，表示"空格那个字节"（值是 32）。普通字符字面量用单引号写 `' '`，前面加个 `b` 就变成字节。

函数返回 `&str`。它不拥有字符串，只借用了其中一段。

### 切片让编译器帮你防 bug

不用切片的话，另一种写法是返回"结尾的下标数字"。原字符串一旦被改掉或清空，这个数字就指向错误的位置了，程序还照跑不误。

换成切片，只要它还在用，Rust 就不允许你改动原字符串。这不是运行时检查，是编译期直接拦下来。

## 数组切片

切片不只能切字符串，也能切数组：

📦 本块能单独跑：

```rust
fn main() {
    let numbers = [1, 2, 3, 4, 5];

    let middle = &numbers[1..4];   // 下标 1、2、3 → [2, 3, 4]
    println!("{:?}", middle);      // {:?} 是 Day04 见过的调试格式

    // 数组切片的类型是 &[i32]
    print_slice(middle);
}

fn print_slice(slice: &[i32]) {   // &[i32]：i32 数组的切片
    for n in slice {
        println!("{}", n);
    }
}
```

| 类型 | 含义 |
|---|---|
| `&str` | 字符串切片（借用一段字符串） |
| `&[T]` | 元素类型为 T 的数组切片，比如 `&[i32]` |

表里那个 `T` 是**类型占位符**，代表"任意一种类型"，不是真的有个类型叫 T。写 `&[i32]` 就是"i32 的一绺"，写 `&[u8]` 就是"u8 的一绺"。

可以把 `&[T]` 理解成"某种数组的一绺"。它不知道背后的数组有多长，只知道自己这一段从哪到哪。

## 字符串字面量就是切片

写在代码里的 `"hello"`，类型其实就是 `&str`：

📦 本块能单独跑：

```rust
fn main() {
    let s: &str = "hello";   // 冒号后面是类型标注，Day04 见过
    println!("{}", s);
}
```

字面量的内容直接存在编译出来的二进制里，程序运行期间一直在那儿，所以能安全地借出来，不需要 `String` 这样的堆内存。

这也是函数参数用 `&str` 时兼容性好的原因：`String` 的引用和字符串字面量都能传进去。

## 今日小结

- 切片是借用集合中一段连续数据的引用，不拥有数据。
- 字符串切片：`&s[起始..结束]`，左闭右开；`..` 两端可省略；类型是 `&str`。
- 数组切片：`&数组[..]`，类型是 `&[T]`（`T` 是元素类型）。
- 用切片代替传索引，能让借用检查器在编译期发现"数据改了、索引却过期"的问题。
- 字符串字面量 `"..."` 的类型就是 `&str`。
