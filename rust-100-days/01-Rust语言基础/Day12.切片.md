# Day12 切片 Slice

> 目标：学会用切片（slice）引用一个集合中的"一段连续数据"，重点掌握字符串切片 `&str`。

## 什么是切片

切片是一种**引用**——它不拥有数据，只是借用某个集合（数组、字符串）里**一段连续的元素**。还记得昨天学的引用不转移所有权吗？切片就是"引用一绺数据"的引用。

它的好处：你不用把整个字符串/数组传进去，就能只操作其中的一部分，而且编译器会帮你保证这一绺数据一直有效。

## 字符串切片 `&str`

字符串切片的写法是：`&字符串[起始..结束]`，表示"借用从起始位到结束位之间的内容"，**包含起始、不包含结束**（左闭右开）。

```rust
fn main() {
    let s = String::from("hello world");

    let hello = &s[0..5];    // 第 0 到 4 个字节 → "hello"
    let world = &s[6..11];   // 第 6 到 10 个字节 → "world"

    println!("{} | {}", hello, world);
}
```

区间语法还有几种简写：

```rust
let s = String::from("hello");

let a = &s[0..5];    // 完整写法
let b = &s[..5];     // 起始是 0 时，可以省略 → "hello"
let c = &s[0..];     // 结束到最后，可以省略 → "hello"
let d = &s[..];      // 两头都省 → 整个字符串 "hello"
```

> 切片的类型是 `&str`（注意：不是 `&String`）。`&str` 是"字符串切片"，`String` 是"拥有所有权的字符串"。这俩关系明天 Day13 还会细讲。

## 一个经典例子：找第一个单词

切片最常见的用途是处理字符串的一部分。比如给定 `"hello world"`，取出第一个单词（空格之前的部分）：

```rust
fn first_word(s: &String) -> &str {
    let bytes = s.as_bytes();              // 把字符串当成字节数组来逐个找
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {                  // 找到空格的位置（b' ' 是空格的字节）
            return &s[0..i];               // 返回从开头到空格的切片
        }
    }
    &s[..]                                 // 没空格，整个字符串就是一个单词
}

fn main() {
    let s = String::from("hello world");
    let word = first_word(&s);
    println!("第一个单词是：{}", word);     // hello
}
```

这里函数返回 `&str`（一个切片引用），因为它不拥有字符串，只是借用了其中一段。

### 切片让编译器帮你防止 bug

如果没有切片，以前我们可能返回一个"结尾的索引数字"。一旦原字符串被改掉、清空，这个索引就指向了错误的位置。而用切片时，只要这个切片还在用，Rust 就不允许你修改原字符串——因为借用规则不允许。这就是借用检查器在默默保护你。

## 数组切片

切片不只能切字符串，也能切数组：

```rust
fn main() {
    let numbers = [1, 2, 3, 4, 5];

    let middle = &numbers[1..4];   // 切出第 1、2、3 个 → [2, 3, 4]
    println!("{:?}", middle);     // [2, 3, 4]

    // 数组切片的类型是 &[i32]
    print_slice(middle);
}

fn print_slice(slice: &[i32]) {   // &[i32]：i32 数组的切片
    for n in slice {
        println!("{}", n);
    }
}
```

| 类型 | 含义 |
|---|---|
| `&str` | 字符串切片（借用一段字符串） |
| `&[T]` | 元素类型为 T 的数组切片，比如 `&[i32]` |

> 可以把 `&[T]` 理解成"某种数组的一绺"，它不知道、也不关心背后那个数组到底有多长，只知道自己这一段从哪到哪。

## 字符串字面量就是切片

有个冷知识：你写在代码里的字符串字面量 `"hello"`，类型其实就是 `&str`：

```rust
let s: &str = "hello";   // 字符串字面量存在二进制里，是一个不可变的 &str
```

这也是为什么函数参数用 `&str` 时，字面量和 `String` 都能传进去，兼容性很好。

## 今日小结

- 切片是借用集合中一段连续数据的引用，不拥有数据。
- 字符串切片：`&s[起始..结束]`，左闭右开；`..` 可省略两端；类型是 `&str`。
- 数组切片：`&数组[..]`，类型是 `&[T]`。
- 用切片代替传索引，能让借用检查器在编译期防止"数据改了、索引却过期"的 bug。
- 字符串字面量 `"..."` 的类型就是 `&str`。
