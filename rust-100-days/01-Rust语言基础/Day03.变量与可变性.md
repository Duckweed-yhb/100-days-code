# Day03 变量与可变性

> 目标：学会用 `let` 声明变量，理解 Rust"默认不可变"的设计，掌握 `mut`、常量和变量遮蔽。

## 用 `let` 声明变量

在 Rust 里，**创建一个变量必须用 `let` 关键字**：

```rust
fn main() {
    let x = 5;        // 声明变量 x，绑定值 5
    println!("x = {}", x);
}
```

这和很多语言不一样：你不能上来就写 `x = 5;`，Rust 会直接报错——它要求你先"声明"再使用。这个设计是为了让每个变量的来源清清楚楚。

> Rust 是**静态强类型**语言：每个变量在编译时就有确定类型。但大多数时候编译器能根据右边的值**自动推断**类型，所以我们先不用手写类型。

## Rust 变量默认不可变

这是 Rust 最有个性的一点：**用 `let` 声明的变量，默认是不可变（immutable）的**，一旦绑定了值，就不能再改。

```rust
fn main() {
    let x = 5;
    x = 6;              // ❌ 编译错误：cannot assign twice to immutable variable
    println!("{}", x);
}
```

试着编译一下，你会看到编译器非常友好地提示：`x` 不可变，问你是不是想加 `mut`。

为什么默认不可变？因为不可变的东西更容易推理：变量值一旦定下，就不用担心它在别处被偷偷改掉，写出安全、易维护的代码。这也是 Rust 鼓励的思维方式。

## 想改值就加 `mut`

如果确实需要让变量变化，在 `let` 后面加 `mut`（mutable，可变的）：

```rust
fn main() {
    let mut x = 5;
    println!("改之前：{}", x);
    x = 6;              // ✅ 加了 mut，就可以重新赋值
    println!("改之后：{}", x);
}
```

运行下面命令看看输出：

```powershell
cargo run
```

> 原则：**能不用 `mut` 就不用**。需要改的时候才加，这样编译器会帮你抓住很多"不该改却改了"的 bug。

## 变量使用前必须有值

Rust 不允许使用一个还没赋值的变量：

```rust
fn main() {
    let x: i32;        // 只声明了类型，没给值
    println!("{}", x); // ❌ 错误：使用了未初始化的变量
}
```

直接在声明时给值最省事：`let x: i32 = 0;`。这种"未初始化就用"的错误，在 C 里可能跑出随机值，Rust 直接在编译期拦住。

## 变量遮蔽（shadowing）

Rust 有个特别好用的特性：你可以用 `let` **重新声明一个同名变量**，新变量会"遮蔽（shadow）"掉旧的。

```rust
fn main() {
    let x = 5;
    let x = x + 1;      // 用 let 重新声明，遮蔽旧的 x
    let x = x * 2;      // 再遮蔽一次
    println!("x = {}", x);  // 输出 12
}
```

更妙的是：**遮蔽出来的新变量可以是不同类型**，而 `mut` 不行。

```rust
fn main() {
    let spaces = "    ";        // spaces 是字符串（注意类型）
    let spaces = spaces.len();  // 遮蔽成一个数字（空格个数）
    println!("空格数：{}", spaces);
}
```

如果只用 `mut`，下面这种写法就会报错，因为同一个变量不能换类型：

```rust
let mut spaces = "    ";
spaces = spaces.len();   // ❌ 类型不匹配：字符串不能直接变成数字
```

### `mut` 和遮蔽的区别

| | `let mut x` | `let x = ...`（遮蔽） |
|---|---|---|
| 本质 | 同一个变量，改它的值 | **新建**一个同名变量 |
| 能否换类型 | 不能，类型必须一致 | 能，新旧类型随意 |
| 是否需要 `let` | 只在第一次写 | 每次遮蔽都要写 `let` |

## 常量 `const`

**常量（constant）**用 `const` 声明，而不是 `let`：

```rust
const MAX_POINTS: i32 = 100_000;
```

它和变量的区别：

| 特性 | `let` 变量 | `const` 常量 |
|---|---|---|
| 可变性 | 默认不可变，可加 `mut` | **永远不可变**，不能加 `mut` |
| 类型标注 | 通常可省略（编译器推断） | **必须显式标注类型** |
| 命名习惯 | 随便 | 全大写 + 下划线，如 `MAX_POINTS` |
| 能在哪用 | 函数里等局部作用域 | 可以在任何作用域，包括全局 |

> 注意常量声明里类型标注 `: i32` 是**必须**的，不能省。另外 Rust 允许用下划线 `_` 分隔数字，`100_000` 就等于 `100000`，读起来更清楚。

## 类型标注怎么写

当编译器无法推断类型时，你要手动标注，写法是变量名后面加冒号和类型：

```rust
let guess: u32 = "42".parse().expect("不是数字！");
//      ^^^^ 类型标注
```

这里 `parse()` 能转成多种整数类型，编译器不知道你要哪种，必须靠 `: u32` 告诉它。常见类型名（明天详讲）：`i32`（默认整数）、`f64`（默认小数）、`bool`、`char`。

## 今日小结

- 创建变量用 `let`；Rust 变量**默认不可变**，需要改时加 `mut`。
- 变量在使用前必须赋值，未初始化就用会编译报错。
- 可以用 `let` 重复声明同名变量来**遮蔽**它，遮蔽还能换类型，`mut` 不能。
- 常量用 `const 名字: 类型 = 值;` 声明，全大写命名，永远不可变、必须标注类型。
- 编译器推断不出类型时，手动写 `let x: 类型 = 值;`。
