# Day06 函数

> 目标：学会定义和调用函数，理解 Rust 里"语句"和"表达式"的区别，掌握返回值怎么写。

## 什么是函数

函数就是把一段**常用的、有名字的代码**打包起来，反复调用。你已经见过 `main` 函数了，今天自己造几个。

## 定义函数

用 `fn` 关键字定义函数，写法是：

```rust
fn 函数名(参数: 类型, ...) -> 返回类型 {
    // 函数体
}
```

先看一个无参数、无返回值的例子：

```rust
fn main() {
    greet();                 // 调用函数
    greet();
}

// 定义一个打招呼的函数
fn greet() {
    println!("你好，Rust！");
}
```

要点：

- **调用**：写函数名加括号 `greet();`。
- **定义位置无所谓**：`greet` 写在 `main` 上面或下面都行，Rust 不挑顺序。
- 函数名习惯用**小写字母加下划线**（snake_case），比如 `calculate_price`。

## 参数必须标注类型

这是 Rust 和很多语言的不同：**每个函数参数都必须写明类型**，用冒号隔开参数名和类型。

```rust
fn main() {
    print_number(5);
}

fn print_number(n: i32) {      // 参数 n 的类型是 i32，不能省
    println!("数字是 {}", n);
}
```

多个参数用逗号隔开：

```rust
fn add(a: i32, b: i32) {
    println!("{} + {} = {}", a, b, a + b);
}
```

> 为什么这么严？因为函数是独立的"模块"，Rust 希望每个函数的输入输出类型都白纸黑字写清楚，读代码时一眼就知道它吃什么、吐什么。

### 调用时传参数量要对

定义了几个参数，调用时就得传几个，多一个少一个都不行：

```rust
fn print_num(n: i32) {}

print_num(3);     // ✅ 传 1 个
print_num();       // ❌ 缺参数
print_num(1, 2);   // ❌ 多参数
```

## 返回值

函数可以把结果"返回"给调用者。在参数列表后面用 `-> 类型` 声明返回类型。

```rust
fn main() {
    let result = add(3, 5);
    println!("3 + 5 = {}", result);
}

fn add(a: i32, b: i32) -> i32 {   // -> i32 表示返回一个 i32
    a + b                          // 注意：行尾没有分号！
}
```

这里出现了 Rust 一个**核心且反直觉**的规则：**函数的返回值 = 函数体里最后一个"不带分号"的表达式的值。**

## 语句 vs 表达式（重点）

这是新手最容易栽跟头的地方，务必搞懂：

- **语句（statement）**：做事情的动作，**以分号结尾**，不返回值。比如 `let x = 5;`、`println!("hi");`。
- **表达式（expression）**：会**产生一个值**的东西，**不能以分号结尾**。比如 `5 + 3`、`a + b`。

```rust
fn square(num: i32) -> i32 {
    num * num        // ✅ 没有分号 → 这是表达式，值就是返回值
}
```

```rust
fn square(num: i32) -> i32 {
    num * num;       // ❌ 加了分号 → 变成语句，不产生值
}                    //    于是函数返回了"空"()，和声明的 i32 对不上，报错
```

> 记忆口诀：**加分号 = "这是一句话，说完了"；不加分号 = "把这个值交出去"。** 函数要返回值，就把最后一行的分号去掉。

### 也可以用 `return` 提前返回

如果想在函数中间就返回（比如出错时），用 `return`：

```rust
fn divide(a: i32, b: i32) -> i32 {
    if b == 0 {
        println!("除数不能为 0");
        return 0;            // 提前返回
    }
    a / b                    // 正常走到最后，返回 a / b
}
```

多数情况下，Rust 风格倾向于**靠最后一个表达式返回**，少写 `return`。

## 没有返回值的函数

如果函数不返回任何东西，就不写 `-> 返回类型`。它实际上返回的是"空元组" `()`（读作 unit），类似 C 语言里的 `void`。

```rust
fn say_hello() {          // 没有 -> ，返回类型就是 ()
    println!("hello");
}
```

`()` 你可以理解为"什么都没有"。之前见到的没有 `->` 的 `main` 函数，返回的就是它。

## 一个完整的例子

把今天学的串起来：

```rust
fn main() {
    let price = 80;
    let final_price = sale_price(price);
    println!("原价 {}，折后 {}", price, final_price);
}

// 偶数价格减 10，奇数价格减 3
fn sale_price(price: i32) -> i32 {
    if is_even(price) {
        price - 10        // 表达式，返回
    } else {
        price - 3         // 表达式，返回
    }
}

fn is_even(num: i32) -> bool {
    num % 2 == 0          // 比较表达式，结果是 bool
}
```

运行下面命令看看输出：

```powershell
cargo run
```

## 今日小结

- 用 `fn 名(参数: 类型) -> 返回类型 { ... }` 定义函数；函数名用 snake_case。
- **每个参数都必须标注类型**，调用时数量要对。
- 返回值用 `-> 类型` 声明；函数体最后一个**不带分号**的表达式就是返回值。
- 语句以 `;` 结尾、不产生值；表达式不写分号、会产生值。
- 不写 `->` 的函数返回空元组 `()`（unit）；提前返回用 `return`。
