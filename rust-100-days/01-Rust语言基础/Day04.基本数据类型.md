# Day04 基本数据类型

> **前置知识**：Day03（`let`、`mut`、`const`、类型标注 `: i32`）
> **难度**：入门
> **预计阅读时间**：20 分钟
> **代码说明**：本章每块代码都是一个完整的 `main.rs`，替换进去直接跑。
> 每块前面标了 `📦`（能单独跑）。

> 目标：认识 Rust 最常用的几种内置类型（整数、浮点数、布尔、字符、元组和数组），知道什么时候该用哪个。

---

## 类型是「标签」

前面说过，Rust 是静态强类型语言：每个值都有确定类型。类型像贴在盒子上的标签，告诉编译器这盒东西是整数还是小数、能不能放负数。好在大多数时候编译器能自己推断，你不用每个都写。

今天过一遍常见的内置类型。它们分两组：

- **标量类型（scalar）**：一个值就是一个，比如一个整数、一个小数、一个 `true`。
- **复合类型（compound）**：把多个值装进一个，比如元组、数组。

## 整数类型

整数就是**没有小数点**的数，比如 `42`、`-7`、`0`。Rust 的整数类型按「有无符号」和「位数」两个维度划分：

- **有符号（`i` 开头）**：能存正数也能存负数，`i` 是 integer。
- **无符号（`u` 开头）**：只能存 0 和正数，`u` 是 unsigned。
- **位数**：8 / 16 / 32 / 64 / 128，位数决定能表示的数值范围。

| 类型 | 含义 | 大致范围 |
|---|---|---|
| `i8` | 8 位有符号 | -128 ~ 127 |
| `i16` | 16 位有符号 | -32768 ~ 32767 |
| **`i32`** | 32 位有符号（**默认**） | 约 -21 亿 ~ 21 亿 |
| `i64` | 64 位有符号 | 极大 |
| `isize` | 位数跟随系统（64 位系统上就是 64 位） | 看系统 |
| `u8` | 8 位无符号 | 0 ~ 255 |
| `u32` | 32 位无符号 | 0 ~ 约 42 亿 |
| `u64` | 64 位无符号 | 极大 |
| `usize` | 位数跟随系统 | 看系统 |

**记忆要点**：你写一个 `5`，Rust 默认当成 `i32`，所以初学阶段基本只用 `i32` 就够。`usize` 和 `isize` 在跟「索引、数组长度」打交道时会自然遇到，因为 `usize` 是专门用来表示长度和下标的类型。

📦 本块能单独跑：

```rust
fn main() {
    let a: i32 = -10;      // 有符号，可以是负的
    let b: u32 = 100;      // 无符号，只能 >= 0
    let c = 255;           // 不写类型，默认推断为 i32
    println!("{} {} {}", a, b, c);
}
```

> **整数溢出（overflow）**：比如 `u8` 最大 255，你给它 `256`，调试模式下程序会 panic（崩溃），发布模式下则「环绕」，256 变回 0。初学先有个印象，以后讲错误处理再深入。

### 数字字面量的写法

为了方便读，Rust 允许用下划线分隔数字，还能直接写进制。字面量就是写在代码里的那个具体的数：

📦 本块能单独跑：

```rust
fn main() {
    let one_million = 1_000_000;   // 1000000，下划线纯粹为了好读
    let hex = 0xff;                // 十六进制，255
    let oct = 0o77;                // 八进制，63
    let bin = 0b1010;              // 二进制，10
    let byte = b'A';               // u8 字节字面量，等于 65
    println!("{} {} {} {} {}", one_million, hex, oct, bin, byte);
}
```

## 浮点类型

带小数点的数叫浮点数，Rust 有两种：

| 类型 | 说明 |
|---|---|
| `f32` | 单精度，精度低、占空间小 |
| **`f64`** | 双精度（**默认**），精度更高，现代 CPU 上和 `f32` 差不多快 |

📦 本块能单独跑：

```rust
fn main() {
    let x = 2.0;          // 默认 f64
    let y: f32 = 3.0;     // 显式指定 f32
    println!("{} {}", x, y);
}
```

> 整数和浮点数**不能直接混算**。`5 + 2.0` 会报错，编译器说 `cannot add a float to an integer`。要转换得用 `as`，Day05 讲。

## 布尔类型 `bool`

布尔值只有两个：`true`（真）和 `false`（假），主要用在条件判断里。注意 `if` 后面直接跟表达式，不用加小括号：

📦 本块能单独跑：

```rust
fn main() {
    let is_big = 100 > 50;        // 比较的结果就是 bool
    println!("100 > 50 吗？{}", is_big);

    if is_big {
        println!("确实很大");
    }
}
```

## 字符类型 `char`

Rust 的 `char` 表示**单个 Unicode 字符**，用**单引号** `'...'` 包起来：

📦 本块能单独跑：

```rust
fn main() {
    let letter = 'R';
    let chinese = '中';        // 一个中文字也是一个 char
    let emoji = '🦀';         // emoji 也可以
    println!("{} {} {}", letter, chinese, emoji);
}
```

特点：

- `char` 固定占 **4 字节**。英文字母一个字节就够，但要保证中文、emoji 都能装下，所以统一给 4 字节。
- 单引号包**一个字符**；双引号 `"..."` 包的是**字符串**（类型是 `&str`），两者不能混用。

常用方法（后面会反复用）：

📦 本块能单独跑：

```rust
fn main() {
    let c = 'A';
    println!("{}", c.is_alphabetic());      // true，是不是字母
    println!("{}", c.is_numeric());         // false，是不是数字字符
    println!("{:?}", '7'.to_digit(10));     // Some(7)，把数字字符转成数值
}
```

`{:?}` 是另一个占位符，叫调试格式，能把值连结构一起打印出来。`to_digit` 的行为是「是数字就给你数字，不是就告诉你没有」，所以这里打印出来是 `Some(7)` 而不是光秃秃的 `7`。`Some(...)` 这个包装 Day18 讲 `Option` 时细说，今天看输出就行。

## 元组（tuple）

元组是**能装不同类型**值的组合，用圆括号 `(...)` 包起来，元素之间用逗号隔开。长度在创建后就固定，不能增删。

取出元组里的值有两种方式。第一种叫**解构（destructure）**，一次把元组拆开，分别绑到几个变量上：

📦 本块能单独跑：

```rust
fn main() {
    let person = ("小明", 18, 175.5);   // 字符串 + 整数 + 小数
    let (name, age, height) = person;   // 解构
    println!("{} 今年 {} 岁，身高 {}", name, age, height);
}
```

第二种是点号加下标。下标从 `0` 开始，用 `.0`、`.1` 这样访问：

📦 本块能单独跑：

```rust
fn main() {
    let numbers = (1, 2, 3);
    let second = numbers.1;              // 取第 2 个 → 2
    println!("{}", second);
}
```

> 有一种特殊的元组叫「空元组」，写作 `()`，表示「没有值」。函数不写返回值时，返回的就是它（类似 C 的 `void`），Day06 讲函数会见到。

## 数组（array）

数组是**同一类型**、**定长**的一组值，用方括号 `[...]` 包起来：

📦 本块能单独跑：

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];        // 5 个 i32
    let first = a[0];               // 方括号里写下标取值，从 0 开始
    println!("{}", first);
}
```

还有一种「批量初始化」的写法：`[值; 个数]`，表示把同一个值重复 N 次。注意中间是分号，不是逗号：

📦 本块能单独跑：

```rust
fn main() {
    let zeros = [0; 1000];           // 1000 个 0
    println!("{}", zeros.len());     // 1000
}
```

常用操作：

📦 本块能单独跑：

```rust
fn main() {
    let a = [10, 20, 30, 40];
    println!("{}", a.len());   // 4，长度，类型是 usize
    println!("{}", a[0]);      // 10，第一个元素
}
```

> **越界会 panic**。你写 `a[100]` 而数组只有 4 个元素时，结果分两种：下标写死成 `100`，编译器当场就拦下，报 `index out of bounds: the length is 4 but the index is 100`；下标是运行时才算出来的，程序会 panic 退出，报 `index out of bounds: the len is 4 but the index is 100`。两种情况都不会让你读到乱七八糟的内存，这是 Rust 内存安全的一部分。数组定长、不能增删，以后讲 `Vec`（可变长的数组）时会对比着学。

## 一张表速查

| 类型 | 写法 | 特点 |
|---|---|---|
| 整数 | `i32` / `u32` / `usize` | `i` 有符号、`u` 无符号；默认 `i32` |
| 浮点 | `f64` / `f32` | 默认 `f64` |
| 布尔 | `true` / `false` | 条件判断 |
| 字符 | `'x'` / `'中'` | 单引号，Unicode，4 字节 |
| 元组 | `("小明", 18)` | 可混类型，解构或 `.0` 取值 |
| 数组 | `[1,2,3]` / `[0;100]` | 同类型定长，`[0]` 取元素 |

## 今日小结

- 整数默认 `i32`，浮点默认 `f64`；`i` 能存负数，`u` 只能存非负。
- `bool` 只有 `true` / `false`；`char` 用单引号，一个 Unicode 字符占 4 字节。
- 元组 `(...)` 能混装不同类型，用解构 `(a,b,c)` 或 `.0` 取值。
- 数组 `[1,2,3]` 同类型定长，批量写法是 `[值; 个数]`，用索引 `a[0]` 取值，越界会 panic。
- 数字里可以用 `_` 分隔提高可读性（`1_000_000`）。

## 动手任务

1. 定义一个元组 `("Ferris", 5, 3.14)`，用解构拆出三个变量并打印。
2. 声明一个长度为 5 的数组，元素是你最近 5 天的学习时长（小时，可用小数），用 `.len()` 打印长度。
3. 试着手写一个 `let x: u8 = 300;`，编译。会看到 `error: literal out of range for u8`，意思是这个数超出了 `u8` 能表示的范围（0 ~ 255）。把 300 改成 255 以内再跑一次。
