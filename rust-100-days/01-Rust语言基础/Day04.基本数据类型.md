# Day04 基本数据类型

> 目标：认识 Rust 最常用的几种内置类型——整数、浮点数、布尔、字符、元组和数组，知道什么时候该用哪个。

## 类型是"标签"

前面我们说过，Rust 是静态强类型语言：每个值都有确定类型。类型就像贴在盒子上的标签，告诉编译器这盒东西是整数还是小数、能不能放负数。好在大多数时候编译器能自己推断，你不用每个都写。

今天把常见的内置（标量 + 复合）类型过一遍。

## 整数类型

整数就是**没有小数点**的数，比如 `42`、`-7`、`0`。Rust 的整数类型按"有无符号"和"位数"两个维度划分：

- **有符号（`i` 开头）**：能存正数也能存负数，`i` = integer。
- **无符号（`u` 开头）**：只能存 0 和正数，`u` = unsigned。
- **位数**：8 / 16 / 32 / 64 / 128，决定能表示的范围大小。

| 类型 | 含义 | 大致范围 |
|---|---|---|
| `i8` | 8 位有符号 | -128 ~ 127 |
| `i16` | 16 位有符号 | -32768 ~ 32767 |
| **`i32`** | 32 位有符号（**默认**） | 约 -21 亿 ~ 21 亿 |
| `i64` | 64 位有符号 | 极大 |
| `isize` | 位数随操作系统（64 位系统上是 64 位） | 看系统 |
| `u8` | 8 位无符号 | 0 ~ 255 |
| `u32` | 32 位无符号 | 0 ~ 约 42 亿 |
| `u64` | 64 位无符号 | 极大 |
| `usize` | 位数随操作系统 | 看系统 |

**记忆要点**：你写一个 `5`，Rust 默认当成 `i32`，所以初学阶段基本只用 `i32` 就够了。`usize`/`isize` 跟"索引、数组长度"打交道时自然会遇到。

```rust
fn main() {
    let a: i32 = -10;      // 有符号，可以是负的
    let b: u32 = 100;      // 无符号，只能 >= 0
    let c = 255;           // 默认推断为 i32
    println!("{} {} {}", a, b, c);
}
```

> **整数溢出（overflow）**：比如 `u8` 最大 255，你给它 `256`，调试模式下程序会 panic（崩溃），发布模式下则"环绕"（256 变 0）。初学先有个印象即可，以后讲错误处理会再深入。

### 数字字面量的写法

为了方便读，Rust 允许用下划线分隔数字，还可以直接标注进制：

```rust
fn main() {
    let one_million = 1_000_000;   // 1000000，下划线纯粹为了可读
    let hex = 0xff;                // 十六进制
    let oct = 0o77;                // 八进制
    let bin = 0b1010;              // 二进制
    let byte = b'A';               // u8 字节字面量（等于 65）
    println!("{} {} {} {} {}", one_million, hex, oct, bin, byte);
}
```

## 浮点类型

带小数点的数叫浮点数，Rust 有两种：

| 类型 | 说明 |
|---|---|
| `f32` | 单精度，精度低、占空间小 |
| **`f64`** | 双精度（**默认**），精度更高，现代 CPU 上和 `f32` 差不多快 |

```rust
fn main() {
    let x = 2.0;          // 默认 f64
    let y: f32 = 3.0;     // 显式指定 f32
    println!("{} {}", x, y);
}
```

> 注意：整数和浮点数**不能直接相加**，类型不同。比如 `5 + 2.0` 会报错，需要用 `as` 转换（明天讲运算符会碰到）。

## 布尔类型 `bool`

布尔值只有两个：`true`（真）和 `false`（假），主要用在条件判断里。

```rust
fn main() {
    let is_big = 100 > 50;        // 比较的结果就是 bool
    println!("100 > 50 吗？{}", is_big);

    if is_big {
        println!("确实很大");
    }
}
```

## 字符类型 `char`

Rust 的 `char` 表示**单个 Unicode 字符**，用**单引号** `'...'`（注意和字符串的双引号区分）：

```rust
fn main() {
    let letter = 'R';
    let chinese = '中';        // 一个中文字也是一个 char
    let emoji = '🦀';         // emoji 也可以
    println!("{} {} {}", letter, chinese, emoji);
}
```

特点：

- `char` 固定占 **4 字节**，所以英文字母、中文、emoji 都能装下。
- 单引号包**一个字符**；双引号 `"..."` 包的是**字符串**（`&str`），两者不能混。

常用方法（后面会反复用）：

```rust
let c = 'A';
c.is_alphabetic();   // 是否是字母 → true
c.is_numeric();      // 是否是数字字符 → false
c.to_digit(10);      // 如果是数字字符，转成数值
```

## 元组（tuple）

元组是一个**能装不同类型**值的组合，用圆括号 `(...)` 包起来，元素之间用逗号隔开：

```rust
fn main() {
    let person = ("小明", 18, 175.5);   // 字符串 + 整数 + 小数
}
```

它的长度在创建后就固定了，不能增删。取出元组里的值有两种方式：

### 1. 解构（destructure）

一次性把元组拆开，分别绑定到几个变量上：

```rust
fn main() {
    let person = ("小明", 18, 175.5);
    let (name, age, height) = person;   // 解构
    println!("{} 今年 {} 岁，身高 {}", name, age, height);
}
```

### 2. 用点号加索引

下标从 `0` 开始，用 `.0`、`.1` 这样访问：

```rust
fn main() {
    let numbers = (1, 2, 3);
    let second = numbers.1;              // 取第 2 个 → 2
    println!("{}", second);
}
```

> 有一种特殊的元组叫"空元组"，写作 `()`，它表示"没有值"。函数不写返回值时，返回的就是它（类似 C 的 `void`），明天讲函数会见到。

## 数组（array）

数组是**同一类型**、**定长**的一组值，用方括号 `[...]` 包起来：

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];        // 5 个 i32
    let first = a[0];               // 用方括号按索引取值，下标从 0 开始
    println!("{}", first);
}
```

还有一种"批量初始化"的写法：`[值; 个数]`，表示"重复 N 次同一个值"：

```rust
let zeros = [0; 1000];   // 1000 个 0
```

常用操作：

```rust
let a = [10, 20, 30, 40];
a.len();                  // 数组长度 → 4
a[0];                     // 取第一个元素 → 10
```

> **越界会 panic**：如果你写 `a[100]` 而数组只有 4 个元素，Rust 在运行时会直接报错退出，不会让你读到乱七八糟的内存。这正是它内存安全的体现。数组定长、不能增删，以后讲 `Vec`（可变长的数组）时会对比着学。

## 一张表速查

| 类型 | 写法 | 特点 |
|---|---|---|
| 整数 | `i32` / `u32` / `usize` | `i` 有符号、`u` 无符号；默认 `i32` |
| 浮点 | `f64` / `f32` | 默认 `f64` |
| 布尔 | `true` / `false` | 条件判断 |
| 字符 | `'x'` / `'中'` | 单引号，Unicode，4 字节 |
| 元组 | `("小明", 18)` | 可混类型，解构或 `.0` 取值 |
| 数组 | `[1,2,3]` / `[0;100]` | 同类型定长，`[0]` 取元素 |

## 今日小结

- 整数默认 `i32`，浮点默认 `f64`；`i` 能存负数，`u` 只能存非负。
- `bool` 只有 `true`/`false`；`char` 用单引号，一个 Unicode 字符占 4 字节。
- 元组 `(...)` 能混装不同类型，用解构 `(a,b,c)` 或 `.0` 取值。
- 数组 `[...; N]` 同类型定长，用索引 `a[0]` 取值，越界会 panic。
- 数字里可以用 `_` 分隔提高可读性（`1_000_000`）。
