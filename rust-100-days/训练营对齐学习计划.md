# 训练营对齐学习计划（重要）

> 目标：在训练营**项目阶段（2026-11-29 开始，约一个月）**之前，攒够做 OS 项目所需的 Rust 与系统知识。
>
> **关键结论**：匀速"一天一篇"走 100 天会到 2027-01-06，**对不上训练营**。但你做项目前**不需要学完 100 天**——只需在 11-29 前掌握 **Day01~80 的核心**，且前 3 周要**加速冲刺**。Day81~100（生态方向 / 综合大项目）放在项目期间及之后。

## 关键节点对齐表

| 训练营节点 | 日期 | 距今天数 | 届时必须完成 | 节奏 |
|---|---|---:|---|---|
| **专业阶段：rCore 开始** | 10-19 | 21 天 | **Day01~30**（Rust 基础 + 核心机制） | 约 1.5 篇/天，最紧 |
| **项目基础阶段开始** | 11-09 | 42 天 | **Day31~45**（进阶）+ 跟 rCore 课 | 约 0.7 篇/天 |

| 结营 | 12-27 | 90 天 | 完成项目；Day81~100 选学 | — |

> Day61~80（no_std / 裸机 / 上下文切换 / 中断 / 页表 / rCore / 进程 / 文件系统 / 线程 / 同步 / unikernel / Hypervisor）**基本就是训练营第 1~9 周的课程内容**——跟着课走、用笔记对照即可，不用额外硬啃。

## 三段冲刺安排

### 冲刺一（最关键）：9-28 ~ 10-18，21 天拿下 Day01~30

这是压力最大的一段，决定你能不能跟上 rCore。

- 工作日（15 天）：每天 1 篇
- 周末（6 天）：每天约 2.5 篇
- **每天投入 2.5~3 小时**（看 + 敲代码）
- 重点中的重点（必须真懂，不能"快速过"）：
  - Day10~12 所有权 / 借用 / 切片
  - Day16~20 结构体 / 枚举 / Option / match
  - Day25~28 错误处理 / 泛型 / Trait / 生命周期
- Day30 猜数字游戏作为阶段验收，独立敲完

> 若时间紧张，优先级：所有权借用 > 枚举/match > trait/泛型 > 生命周期（生命周期可先会用、后深入）。

### 冲刺二：10-19 ~ 11-08，21 天，边跟 rCore 边补 Day31~45

- 训练营专业阶段教 rCore（对应 Day71~78），**跟课 + 跑通实验**为主
- 同步完成 Day31~45：闭包、迭代器、智能指针、多线程、消息传递、Mutex、异步、面向对象、高级类型、unsafe、宏
- 15 篇 / 21 天，约 0.7 篇/天，**每天 1.5~2 小时**
- rCore 大实验是晋级硬门槛，务必完成

### 冲刺三：11-09 ~ 11-28，20 天，完成 Day46~80 缺口

- 训练营项目基础阶段教 unikernel / 宏内核 / Hypervisor（Day79~80 及 Day61~70）
- 补齐 Day46~60 工程化部分（Cargo 工作空间、文件 IO、serde、网络、grep、Web 服务器、测试、调优），可挑与项目相关的优先
- **每天 1.5~2 小时**
- 11-29 起进入项目选题与一个月项目实践

## 11-29 之后：Day81~100

- Day81~90 生态方向（Web / 数据库 / WASM / 嵌入式 / CLI / 数据 / 图形 / Tauri / AI / 分布式）按兴趣与项目需要选学
- Day91~100（开源贡献 / Git 协作 / 设计模式 / 重构 / 面试 / 综合大项目 / 总结）项目期间穿插，结营后继续

## 风险与降级

- **前 3 周是最大风险点**：若 Day01~30 没赶完，rCore 会非常吃力。建议这 3 周减少其它安排，优先 Rust。
- 实在赶不上：基础阶段的并发 / no_std / 异步课先"听个大概"，把 Rust 核心语法（Day01~30）保到 rCore 开课前。
- 训练营是淘汰晋级制：专业阶段需完成 rCore 大实验、拿到足够分数才能进项目阶段。
