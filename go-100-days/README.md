# Go - 100天从新手到大师

> 这是一套为零基础到能独立写后端服务的学习者自编的 Go 语言学习路线，从环境安装一路走到并发、标准库、Web 框架、微服务与综合项目。建议节奏：工作日每天投入 1～1.5 小时看内容并动手敲代码，周末用来复盘本周知识点并完成阶段小项目，不要只看不练。

## 阶段总览

| 阶段 | 天数 | 主题 |
|---|---|---|
| 01-Go基础 | Day01~13 | Go 介绍、环境、Hello World、变量常量、基本类型、运算符、流程控制、函数、数组切片、map、字符串 |
| 02-函数与面向对象 | Day14~25 | 函数进阶、结构体、方法、接口、包与可见性、错误处理 |
| 03-并发编程 | Day26~37 | goroutine、channel、select、sync、并发模式、原子操作、context |
| 04-标准库深入 | Day38~50 | fmt、strings、time、文件 IO、JSON、正则、flag、log |
| 05-包模块与测试 | Day51~63 | go mod、单元测试、基准测试、泛型、反射、文档 |
| 06-网络与数据库 | Day64~75 | TCP、HTTP、database/sql、WebSocket、RPC |
| 07-Web框架与微服务 | Day76~88 | net/http 深入、gin、中间件、模板、鉴权、微服务、gRPC、工程化 |
| 08-综合项目 | Day89~100 | 综合项目实战、测试压测、Docker 部署、总结复盘 |

## 怎么用

1. 按文件夹顺序从 `01-Go基础` 开始，一天只看一个 `DayNN` 文件，不要跳着学。
2. 每个文件先读"今日目标"，再跟着"学习内容"敲一遍示例代码，最后完成"练习/任务"并勾选"打卡清单"。
3. 从 Day25 起每天有"今日刷题"，用 Go 写一到两题，巩固当天语法。
4. 每个阶段最后一天是阶段练习/小项目，务必动手做完再进下一阶段。
5. 遇到报错先读错误信息，再回当天内容对照，别复制粘贴不求甚解。

## 目录约定

- 仓库根目录下有 8 个阶段文件夹，命名为 `NN-主题`（`NN` 为两位阶段序号），例如 `01-Go基础`。
- 每个阶段文件夹内是当天笔记，文件命名为 `DayNN.主题.md`，其中 `NN` 为两位天数（01~100），主题为当天内容的一句话概括。
- Day 文件统一包含这些小节：`今日目标`、`学习内容`、`核心重点`、`练习/任务`、`打卡清单`；从 Day25 起额外包含 `今日刷题`。
- 所有代码示例均以 Go 1.21~1.24 稳定语法编写，以标准库为主。

## 为什么学 Go

Go 由 Google 于 2007 年设计、2012 年正式发布，主打"简单、高效、自带并发"。它语法精简、编译快、标准库强大，是云原生时代的主力语言：Docker、Kubernetes、etcd、Prometheus、Terraform 都用 Go 写成。学完这套路线，你将具备独立开发后端 API 服务并部署上线的能力。
