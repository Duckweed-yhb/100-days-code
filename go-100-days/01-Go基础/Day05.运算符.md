# Day 05 · 运算符

## 今日目标
- 掌握算术、赋值、比较、逻辑运算符
- 了解位运算及其典型用途
- 注意 Go 没有前置/后置自增表达式

## 学习内容

### 算术运算符

```go
a + b      // 加
a - b      // 减
a * b      // 乘
a / b      // 整除（两个整数相除取整）
a % b      // 取余
```

Go **没有** `++i`、`--i`，只有语句 `i++`、`i--`，且不能用在表达式里：

```go
i := 0
i++          // 合法，是语句
// j := i++  // 编译错误
```

### 比较与逻辑

```go
a == b   a != b   a < b   a <= b   a > b   a >= b
!a        // 非
a && b    // 与（短路）
a || b    // 或（短路）
```

### 位运算（常用于权限、位图）

```go
a & b     // 按位与
a | b     // 按位或
a ^ b     // 按位异或
a &^ b    // 按位清零（AND NOT）
a << n    // 左移 n 位（×2^n）
a >> n    // 右移 n 位（÷2^n）
```

典型例子：用位掩码表示权限。

```go
const (
    Read   = 1 << 0   // 001
    Write  = 1 << 1   // 010
    Exec   = 1 << 2   // 100
)
perm := Read | Write        // 011，同时有读和写
canRead := perm & Read != 0 // true
```

### 赋值运算符

`= += -= *= /= %= &= |= ^= <<= >>=` 都可用。

### 注意点

- 整数除零直接 panic；浮点除零得到 `+Inf`/`NaN`。
- 不同类型不能直接运算：`var x int = 1; var y int64 = 2; x + y` 编译报错，要先转换。

## 核心重点
- Go 没有前置 `++`，`i++` 只是语句不是表达式
- 整数除法向零取整；不同类型必须先转换再运算
- `&&` `||` 有短路效果
- 位运算 `& | ^ << >>` 适合做权限位图、标志位
- `&^` 是 Go 特有的按位清零
