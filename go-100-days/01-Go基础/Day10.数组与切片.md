# Day 10 · 数组与切片

## 今日目标
- 理解固定长度数组与动态切片的区别
- 熟练使用切片的增删改查、截取、append
- 知道切片底层结构与常见坑

## 学习内容

### 数组（很少直接用）

数组长度是类型的一部分，`[3]int` 和 `[5]int` 是不同类型：

```go
var a [5]int            // 长度 5，零值全 0
b := [3]int{1, 2, 3}
c := [...]int{1, 2, 3}  // 编译器自动数长度
```

数组是值类型，赋值和传参会**整块拷贝**，所以业务里几乎都用切片。

### 切片 slice（高频使用）

切片是动态长度、引用底层数组的视图：

```go
s := []int{1, 2, 3}          // 字面量
s2 := make([]int, 3, 10)     // len=3, cap=10
var s3 []int                 // nil 切片，len=0 cap=0
```

| 操作 | 说明 |
|---|---|
| `len(s)` | 当前元素个数 |
| `cap(s)` | 底层数组从切片起点能容纳的元素数 |
| `s[i]` | 读写第 i 个元素 |
| `s[i:j]` | 切片左闭右开 |
| `append(s, x)` | 末尾追加，可能分配新底层数组 |

### append 是最常用操作

```go
s := []int{1, 2}
s = append(s, 3)            // [1 2 3]
s = append(s, 4, 5)         // [1 2 3 4 5]
t := []int{6, 7}
s = append(s, t...)         // 展开另一个切片
```

**必须接收 append 返回值**：`append(s, x)` 若容量不足会分配新数组，不写回 `s` 就丢了。

### 截取与共享底层数组

```go
a := []int{0, 1, 2, 3, 4}
b := a[1:3]        // [1 2]
b[0] = 99
fmt.Println(a)    // [0 99 2 3 4]——a 和 b 共享底层数组
```

这是切片最大的坑：多个切片互相影响。需要独立副本用 `copy`：

```go
src := []int{1, 2, 3}
dst := make([]int, len(src))
copy(dst, src)
```

### 常见模式

```go
var s []int
for i := 0; i < 5; i++ {
    s = append(s, i*i)
}
```

## 核心重点
- 数组长度是类型一部分，业务几乎不用；切片才是主力
- `len` 看长度，`cap` 看容量
- `append` 必须用 `s = append(s, ...)` 接收返回值
- 切片截取共享底层数组，改一个会影响另一个
- 空切片 `[]int{}` vs nil 切片 `var s []int`，len/cap 都是 0，但语义不同
