# Day 09 · 指针入门

## 今日目标
- 理解指针是什么、`*` 与 `&` 的含义
- 学会用指针修改函数外的变量
- 知道什么时候该用指针

## 学习内容

### 指针基础

指针就是内存地址。`&x` 取变量地址，`*p` 按地址取值：

```go
x := 10
p := &x          // p 是 *int 类型，指向 x
fmt.Println(p)  // 类似 0xc0000180a0（地址）
fmt.Println(*p)  // 10，按地址读
*p = 20          // 按地址写，x 变成 20
fmt.Println(x)   // 20
```

### 类型表示

`*int` 表示"指向 int 的指针"。指针的零值是 `nil`。

### 用指针修改外部变量

值传递下，函数改不了外面的变量：

```go
func bad(n int) { n = 0 }          // 改的是副本

func good(n *int) { *n = 0 }       // 通过指针改原变量

x := 5
bad(x)
fmt.Println(x)   // 还是 5
good(&x)
fmt.Println(x)   // 变成 0
```

### new 函数

```go
p := new(int)    // 分配一个 int，返回 *int，零值 0
*p = 42
```

日常更常用结构体字面量取址，`new` 用得少。

### 什么时候用指针

| 场景 | 是否用指针 |
|---|---|
| 需要在函数内修改调用方变量 | 用指针 |
| 传大结构体避免拷贝 | 用指针 |
| 表示"可选值/nil" | 用指针 |
| 小类型（int、string、bool）简单传值 | 传值即可 |

不要一上来什么都用指针，Go 社区风格是按需使用。

## 核心重点
- `&变量` 取地址，`*指针` 取值
- `*int` 是"指向 int 的指针"类型，零值 nil
- 函数要改外部变量就传指针
- 大结构体传指针避免拷贝
- Go 没有指针运算（不能 p+1），比 C 安全
