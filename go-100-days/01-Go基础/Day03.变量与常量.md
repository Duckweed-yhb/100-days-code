# Day 03 · 变量与常量

## 今日目标
- 掌握变量声明的四种写法
- 理解 `:=` 短变量声明的限制
- 学会常量与 iota 枚举

## 学习内容

### 变量声明

Go 是静态类型语言，但多数情况下类型可由编译器推断。

```go
var a int                // 声明变量，零值为 0
var b int = 10           // 声明并赋值
var c = 20               // 类型由右边推断为 int
var d, e = 30, "hello"   // 多变量不同类型同时声明

var (                    // 批量声明
    name string = "Go"
    age  int    = 15
)
```

**零值机制**：Go 没有未初始化的"野变量"。数值类型零值是 `0`，字符串是 `""`，布尔是 `false`，指针/切片/map/函数/接口/nil 指针是 `nil`。

### 短变量声明

函数内部最常用 `:=`：

```go
func main() {
    x := 1            // 等价于 var x int = 1
    y, s := 2, "hi"
    _ = y
    _ = s
}
```

注意：
- `:=` 只能在**函数内部**用，包级变量只能用 `var`。
- `:=` 至少要有一个新变量在左边，否则编译报错。
- `_` 是空白标识符，用来"扔掉"不想要的值。

### 常量

```go
const Pi = 3.14159          // 无类型常量
const Mode string = "dev"   // 带类型
const (
    OK    = 0
    FAIL  = 1
)
```

常量在编译期确定，不能取地址，不能用 `:=`。

### iota 枚举

`iota` 在 `const` 块里从 0 逐行递增：

```go
const (
    Sunday    = iota   // 0
    Monday             // 1，自动沿用上面的表达式
    Tuesday            // 2
)

const (
    KB = 1 << (10 * (iota + 1))  // 1<<10 = 1024
    MB                            // 1<<20
    GB                            // 1<<30
)
```

## 核心重点
- `var 名 类型` 声明变量；函数内可用 `:=` 短声明
- 每个类型都有合理零值，不存在未初始化垃圾
- 未使用的变量、未使用的导入都会编译报错
- `const` 声明编译期常量；`iota` 在 const 块内从 0 逐行递增
- `_` 用来丢弃不需要的值
