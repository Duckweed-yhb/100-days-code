## 一、技术栈学习路线（按依赖排序）

零基础起点，严格按顺序，后面的建立在前面的上面：

1. **Python 基础**：运行 .py、变量、类型、函数、模块（课 01-02）
2. **HTTP 请求**：用 `httpx` 调公开 API、解析 JSON（课 02）
3. **数据模型**：`dataclass` / Pydantic 结构化数据（课 03）
4. **Polymarket API**：真实市场数据接入（课 03，M1 交付）
5. **列表/字典/循环**：批量处理（课 04）
6. **Kalshi API**：第二个数据源 + 统一接口（课 04）
7. **SQLite**：数据落地（课 05）
8. **数据分析**：筛选/排序/趋势/异常（课 06-07）
9. **pytest**：测试（课 07）
10. **LLM API + 结构化输出**：Agent 判断层（课 08）
11. **整合 + 文档 + 发布 + 简历**（课 09-11）

## 五、学习方法（行动-感知-反思-调整）

每课不是"看完"，是：**动手做 → 看它实际跑了什么 / 哪里坏了 → 想为什么 → 改下一步**。

- 卡住了：先读报错信息，按课里"常见坑"排查，再问。
- 别跳课：课 03 依赖课 01-02，跳过会卡。
- 每课验收标准打勾才算完成。
