## 最小知识
- **概率变化追踪**：对每个市场，取它的历史 `probability` 序列，算一段时间的变化量（如 24h 变化）和变化速度。
- **异常信号**：常见启发式——
  - **急变**：单次采集间隔内概率跳变超过阈值（如 > 5 个百分点）
  - **成交量异常**：某市场成交量突然放大
  - **背离**：概率与成交量方向不一致
  先用一种（急变检测）做通，够面试讲。
- **pytest**：写 `test_xxx.py`，用 `assert` 断言，运行 `pytest` 自动发现。

## 动手任务
1. 建 `odds_pulse/analysis/trend.py`：`compute_change(history, window)` 返回市场最近 window 内的概率变化。

4. 装 pytest，跑 `pytest`，全绿。

## 常见坑
- 历史数据太少（只拉了两次）→ 变化检测要有"数据不足就不报"的兜底，测试里也覆盖。
- 阈值拍脑袋没关系，但**要写进配置/常量并在 README 说明**。
- 测试别连真实网络 → 全用假数据构造 `Market` 和历史序列。
