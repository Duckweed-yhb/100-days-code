# 第 01 课：环境搭建与第一次运行

## 学习目标
- 装好 Python、创建虚拟环境、安装项目依赖
- 建好 OddsPulse 项目目录结构，跑通第一个 Python 程序
- 在 GitHub 仓库留下第一个能运行的骨架（不算作业完成，只是起步）

## 前置要求
- 已 clone 仓库到 `E:\future\yhb\04-项目与开源\OddsPulse`
- 本课是第 1 课，无其他前置

## 最小知识
- **Python 解释器**：`.py` 文件用 `python 文件名.py` 运行。
- **虚拟环境（venv）**：给每个项目装独立的包，不污染系统。`.venv` 是约定目录名。
- **requirements.txt**：声明项目要装的第三方包。
- **包结构**：`odds_pulse/` 是代码包，`python -m odds_pulse.cli` 是从命令行运行包内模块。

## 动手任务
1. **确认 Python**：终端执行 `python --version`，确认 ≥ 3.10。
2. **进仓库并建 venv**：
   ```
   cd E:\future\yhb\04-项目与开源\OddsPulse
   python -m venv .venv
   .venv\Scripts\activate        # Windows 激活虚拟环境
   ```
3. **建包目录**：在仓库里创建 `odds_pulse/` 文件夹，里面放一个空的 `__init__.py`。
4. **写第一个程序**：`odds_pulse/cli.py`：
   ```python
   def main():
       print("OddsPulse: 预测市场数据源 + 分析框架")
       print("Python 运行成功 ✅")

   if __name__ == "__main__":
       main()
   ```
5. **运行**：`.venv\Scripts\python -m odds_pulse.cli`
6. **提交**：`git add -A` → `git commit -m "feat: init project skeleton"` → `git push`

## 验收标准

- [ ] 仓库 main 分支已推送这个骨架 commit

## 常见坑
- 忘记 `activate`，用的还是系统 Python → 每次装包/运行都先 `.venv\Scripts\activate`，或直接写 `.venv\Scripts\python`。
- Windows 上 `.venv\Scripts\activate` 报"禁止运行脚本" → 用 `.venv\Scripts\python.exe` 代替 activate。
- `__init__.py` 忘建 → `import` 包会失败。
