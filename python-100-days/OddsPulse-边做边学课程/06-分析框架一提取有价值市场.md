# 第 06 课：分析框架一——提取有价值市场

## 学习目标
- 用列表推导、排序、过滤实现"从一堆市场里挑出值得看的"
- 把分析逻辑封装成独立模块（分析框架的第一步）

## 前置要求
- 完成课 05（能从库/数据源拿到 `list[Market]`）

## 最小知识
- **什么是有价值的市场**（预测市场语境）：通常看三个信号——
  1. **流动性/成交量**高（volume 大，价格可信）
  2. **概率接近 0.5**（结果不确定，讨论空间大；太确定没意思）
  3. **近期有变化**（说明有新信息）
- **打分思路**：给每个市场算一个 `interest_score`（如：volume 归一化 × 权重 + 远离 0.5 的惩罚），排序取 top N。这就是一个可讲、可复现的分析方法。

## 动手任务
1. 建 `odds_pulse/analysis/extract.py`，实现 `select_interesting_markets(markets, top_n=20) -> list[Market]`：
   - 过滤：排除无概率/无成交量的
   - 打分：设计 `interest_score(market)`（你自己定权重，README 里写清楚公式）
   - 排序取 top N
2. 建 `odds_pulse/analysis/__init__.py` 导出。
3. 在 `cli.py` 加 `extract` 子命令：拉数据 → 分析 → 打印 top 市场。
4. 用真实数据跑通，观察 top 结果是否符合直觉。
5. commit + push。

## 验收标准
- [ ] `python -m odds_pulse.cli extract` 打印出 top 市场及各自分数
- [ ] `select_interesting_markets` 是纯函数（不依赖网络/库，传市场列表就能算）——后面好测试
- [ ] README 里能写清你的打分公式

## 常见坑
- 归一化要防除以 0 → volume 全是 0 时给个兜底。
- 打分权重拍脑袋没关系，但**要在 README 写明并说明理由**，面试才讲得清。
- 纯函数里别做网络请求 → 数据由调用方传入。
